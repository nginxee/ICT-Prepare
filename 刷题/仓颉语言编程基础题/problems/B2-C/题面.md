# B2-C · 字符与字符串统计

**关卡**：B2 · 变量与基本数据类型
**对应博客**：《跟我一起学“仓颉”编程语言》第 02·03 篇
**提交文件**：`answers/B2-C.cj`

> 读入一行文本，输出它的字符数、字节数与大写形式。

## 知识点

- String 类型
- Rune 与字符数（toRuneArray）
- UTF-8 字节数（size）
- 大小写转换

## 输入

一行文本 s（不含空格，长度 1..12 个字符，可含中文）。

**数据范围**：s 不含空格；字符数 1..12

## 输出

三行：`chars=<字符数>`、`bytes=<UTF-8 字节数>`、`upper=<转成 ASCII 大写后的文本>`。

## 样例

**样例 1**

```
输入：
abc
输出：
chars=3
bytes=3
upper=ABC
```

**样例 2**

```
输入：
汉字
输出：
chars=2
bytes=6
upper=汉字
```

## 提示

`.size` 是 **UTF-8 字节数**，字符数要用 `.toRuneArray().size`；`toAsciiUpper()` 只影响 ASCII 字母。
