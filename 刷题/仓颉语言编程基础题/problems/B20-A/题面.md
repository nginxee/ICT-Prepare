# B20-A · spawn 与 Future.get

**关卡**：B20 · 并发
**对应博客**：《跟我一起学“仓颉”编程语言》第 60·61·62·63·64·65·66·67·68·69·70 篇
**提交文件**：`answers/B20-A.cj`

> 给每个数开一个线程算平方，按输入顺序取回结果；再演示 tryGet 与 cancel 的行为。

## 知识点

- spawn 创建线程
- Future<T> 作为线程句柄
- get() 阻塞等待结果
- tryGet() 非阻塞地取已完成线程的结果
- cancel() 只是协作式取消请求
- 用 ArrayList<Future> 管理多个线程
- 收齐后再输出保证确定性

## 输入

第一行一个整数 n。接下来 n 行，每行一个整数 x。

**数据范围**：1 ≤ n ≤ 50；-1000 ≤ x ≤ 1000

## 输出

按输入顺序每行输出 `序号: <x 的平方>`（序号从 1 开始）；然后输出 `sum=<所有平方之和>`；再额外开一个线程计算 1+2+…+n，对它调用一次 cancel() 之后再 get()，输出 `cancelled=<该线程最终返回的值>`；最后对第一个线程用 tryGet() 取结果，输出 `first=<tryGet 得到的 Option 值>`。所有输出都必须在取回线程结果之后进行。

## 样例

**样例 1**

```
输入：
3
2
3
4
输出：
1: 4
2: 9
3: 16
sum=29
cancelled=6
first=Some(4)
```

**样例 2**

```
输入：
1
5
输出：
1: 25
sum=25
cancelled=1
first=Some(25)
```

## 提示

`spawn { ... }` 的返回值类型由代码块决定，这里是 `Future<Int64>`；把它存进 ArrayList，再按顺序 `get()`。`cancel()` 只是发个请求，线程没主动检查取消就不会被强制停掉。
