# B22-D · ★ 写一个宏包

**关卡**：B22 · 元编程与互操作  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 71·72·73·74·75·76·77·83·84 篇
**提交文件**：`answers/B22-D.cj`

> 写一个宏包：包名 B22D，导出两个宏 —— `zero` 展开成整数 0，`twice` 把它收到的代码片段包成 `(片段) * 2`。

## 知识点

- macro package 声明
- public macro 与 Tokens 形参
- quote 表达式与插值 $(...)
- cjc --compile-macro 编译宏包

## 输入

无输入（本题不读 stdin）。

**数据范围**：包名必须是 B22D；两个宏都必须 public；文件必须以 `macro package B22D` 开头

## 输出

无输出（本题不产生 stdout）。

## 提示

宏是「输入代码片段、输出代码片段」的特殊函数：`public macro 名字(input: Tokens): Tokens`，函数体用 `return quote(...)` 返回一段代码。要把传进来的片段嵌进结果里，在 quote 里用 `$(input)` 插值。别忘 `import std.ast.*`。

## 判题方式（本关特殊）

本题**只判编译**：答案文件必须是一个 `macro package` 宏包，能被 `cjc --compile-macro` 编译通过即算完成。（宏的调用侧需要另一个包并链接宏包，单文件判题做不到，所以判题不看输出。）
