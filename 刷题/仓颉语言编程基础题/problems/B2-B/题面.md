# B2-B · 元组交换与区间长度

**关卡**：B2 · 变量与基本数据类型
**对应博客**：《跟我一起学“仓颉”编程语言》第 02·03 篇
**提交文件**：`answers/B2-B.cj`

> 读入两个整数 a b，用元组交换它们，并输出闭区间 [a, b] 的长度。

## 知识点

- 元组类型
- 元组解构/交换
- 区间类型 1..=n
- 整数计算

## 输入

一行，两个整数 a b（满足 a ≤ b，单个空格分隔）。

**数据范围**：-10^6 ≤ a ≤ b ≤ 10^6

## 输出

两行：`after= <b> <a>`（交换后的值，空格分隔）、`count=<b-a+1>`。

## 样例

**样例 1**

```
输入：
1 5
输出：
after= 5 1
count=5
```

**样例 2**

```
输入：
7 7
输出：
after= 7 7
count=1
```

## 提示

元组可以写成 `let (a, b) = (b, a)`；区间 1..=n 是**闭**区间，元素个数是 n。
