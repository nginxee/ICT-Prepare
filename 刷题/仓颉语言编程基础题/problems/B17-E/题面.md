# B17-E · ★ 班级成绩汇总

**关卡**：B17 · 集合  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 42·43·44·45·46·47 篇
**提交文件**：`answers/B17-E.cj`

> 读入若干条成绩记录，按班级汇总人数、总分和最高分，并统计出现过的学生人数。

## 知识点

- HashMap 分组统计（人数/总分/最高分）
- HashSet 统计不同学生数
- ArrayList 收集键并排序
- 解构遍历 HashMap
- HashMap 顺序不稳定，必须排序后输出
- 空输入的处理

## 输入

第一行一个整数 n（可以为 0）。接下来 n 行，每行 `班级 学生 分数`（单个空格分隔）。

**数据范围**：0 ≤ n ≤ 100；班级、学生只含小写字母且长度 1..10；0 ≤ 分数 ≤ 100

## 输出

第一行 `classes=<不同班级数>`；第二行 `students=<不同学生数>`；接下来按班级名字典序升序，每行 `<班级> 人数=<人数> 总分=<总分> 最高分=<最高分>`；最后一行 `合计 人数=<记录条数> 总分=<所有分数之和>`。

## 样例

**样例 1**

```
输入：
3
a tom 90
a amy 80
b tom 70
输出：
classes=2
students=2
a 人数=2 总分=170 最高分=90
b 人数=1 总分=70 最高分=70
合计 人数=3 总分=240
```

**样例 2**

```
输入：
0
输出：
classes=0
students=0
合计 人数=0 总分=0
```

## 提示

用三个 `HashMap<String, Int64>` 分别记人数、总分、最高分，再用一个 `HashSet<String>` 记学生名去重；最高分可以用 `top.get(c) ?? -1` 当初始值再比较。输出前把班级名收集到 `ArrayList<String>` 排序，千万别按 HashMap 的遍历顺序打印。
