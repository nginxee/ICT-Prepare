# B13-B · 读到文件结尾的累计

**关卡**：B13 · 模式匹配
**对应博客**：《跟我一起学“仓颉”编程语言》第 28·29·30·31 篇
**提交文件**：`answers/B13-B.cj`

> 不断读入 `姓名 分数` 直到输入结束，按人累计分数，最后给出人数、总分与单人最高分。

## 知识点

- while-let 解构 Option
- 读到 EOF 的循环
- for ((k, v) in ...) 解构遍历
- HashMap 基础 API
- ?? 提供默认值

## 输入

若干行（至少 1 行），每行 `姓名 分数`，用单个空格分隔，读到输入结束为止。同一个姓名可以出现多次，表示该人的多笔分数。

**数据范围**：行数 1..100；姓名只含小写字母且长度 1..10；每个分数是 0..100 的整数

## 输出

三行：`people=<不同姓名数>`、`total=<所有分数之和>`、`top=<单人累计分数的最大值>`。

## 样例

**样例 1**

```
输入：
tom 90
amy 80
输出：
people=2
total=170
top=90
```

**样例 2**

```
输入：
bob 10
bob 20
输出：
people=1
total=30
top=30
```

## 提示

用 `while (let Some(line) <- ...)` 反复取下一行，取到 `None` 循环自然结束；累计时把姓名当键放进 HashMap（同名要累加，取不到就当成 0），最后用解构遍历把每个键值对拆成两个变量来求总和与最大值。
