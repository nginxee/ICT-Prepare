# B13-C · 点在哪一区

**关卡**：B13 · 模式匹配
**对应博客**：《跟我一起学“仓颉”编程语言》第 28·29·30·31 篇
**提交文件**：`answers/B13-C.cj`

> 读入 n 个平面上的整数坐标点，逐行输出每个点的位置分类。

## 知识点

- 元组模式
- 元组里嵌通配符
- 元组解构 let (x, y) = ...
- 常量模式与 where 守卫
- 按行读入多个整数

## 输入

第一行一个整数 n；接下来 n 行，每行两个整数 `x y`，用单个空格分隔。

**数据范围**：1 ≤ n ≤ 100；-1000 ≤ x, y ≤ 1000

## 输出

n 行，每行 `(<x>,<y>) <区域>`。区域取 `ORIGIN`（原点）、`X_AXIS`（x 轴上非原点）、`Y_AXIS`（y 轴上非原点）、`Q1`~`Q4`（第一至第四象限，逆时针编号，Q1 为 x>0 且 y>0）。

## 样例

**样例 1**

```
输入：
1
3 4
输出：
(3,4) Q1
```

**样例 2**

```
输入：
2
0 0
-5 0
输出：
(0,0) ORIGIN
(-5,0) X_AXIS
```

## 提示

把一行里的两个整数先合成一个元组，再交给 match：元组模式能一次匹配多个位置，不关心的位置用 `_`，需要额外条件时在模式后面加 `where`；也可以直接用 `let (x, y) = ...` 把元组拆开。
