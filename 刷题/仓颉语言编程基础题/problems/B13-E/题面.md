# B13-E · ★ 混合数据统计

**关卡**：B13 · 模式匹配  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 28·29·30·31 篇
**提交文件**：`answers/B13-E.cj`

> 读入 n 行数据，每行可能是整数也可能是单词；把它们统一收集起来，用类型模式分别处理并汇总。

## 知识点

- 类型模式（id: Type）
- 类型模式与继承配合
- Option 判类型
- match 在分支里追加语句
- 元组/列表遍历与聚合

## 输入

第一行一个整数 n；接下来 n 行，每行一个记号：整数（可带负号）或只含小写字母的单词。

**数据范围**：1 ≤ n ≤ 100；整数在 -1000..1000 之间；单词只含小写字母且长度 1..10

## 输出

先按输入顺序输出 n 行 `<下标>: <描述>`，下标从 0 开始；整数输出 `NUM <值>`，单词输出 `WORD <单词>`。然后输出一行 `ints=<整数个数> sum=<整数之和> words=<单词个数>`。最后输出一行 `longest=<出现过的单词中字符数最多的那个，没有单词时输出 none>`；字符数相同时取先出现的那个。

## 样例

**样例 1**

```
输入：
3
12
apple
7
输出：
0: NUM 12
1: WORD apple
2: NUM 7
ints=2 sum=19 words=1
longest=apple
```

**样例 2**

```
输入：
4
go
-3
go
x
输出：
0: WORD go
1: NUM -3
2: WORD go
3: WORD x
ints=1 sum=-3 words=3
longest=go
```

## 提示

整数和单词没法放进同一种具体类型，所以先给它们定义一个公共父类，各自再带自己的成员；收集到列表后用 `case 变量: 类型 =>` 形式的分支分辨它们，取成员时就是各自子类型里的字段。
