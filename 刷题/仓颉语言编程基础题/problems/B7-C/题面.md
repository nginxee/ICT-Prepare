# B7-C · ★ 别名导入与多成员导入

**关卡**：B7 · 包与导入  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 14 篇
**提交文件**：`answers/B7-C.cj`

> 本题要求：文件第一行必须是 `package B7C`；读取器的类型必须用别名导入（`as CR`），`sqrt` 与 `abs` 必须用花括号一次导入。处理一批带符号整数并统计。

## 知识点

- 别名导入 import 包名.成员名 as 别名
- 花括号多成员导入 import 包名.{a, b}
- 多个标准库子包协作
- 综合：读入、计算、格式化输出

## 输入

第一行一个整数 n。接下来 n 行，每行一个整数 x。

**数据范围**：1 ≤ n ≤ 100；-1000000 ≤ x ≤ 1000000

## 输出

每行输出 `x=<x> abs=<|x|> sqrt=<|x| 的平方根，保留 3 位小数>`；最后两行：`sumAbs=<|x| 的总和>`、`maxAbs=<|x| 的最大值>`。

## 样例

**样例 1**

```
输入：
2
-4
9
输出：
x=-4 abs=4 sqrt=2.000
x=9 abs=9 sqrt=3.000
sumAbs=13
maxAbs=9
```

**样例 2**

```
输入：
1
0
输出：
x=0 abs=0 sqrt=0.000
sumAbs=0
maxAbs=0
```

## 提示

别名导入写成 `import 包名.成员名 as 别名`，之后代码里只能用别名；花括号写法 `import 包名.{a, b}` 能一次引入多个成员。`getStdIn()` 的返回值类型是 `ConsoleReader`，用它声明变量时就写你的别名。
