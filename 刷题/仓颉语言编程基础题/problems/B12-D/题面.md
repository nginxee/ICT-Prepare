# B12-D · ★ 学生成绩册

**关卡**：B12 · 枚举与 Option  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 25·26·27 篇
**提交文件**：`answers/B12-D.cj`

> 读入一批学生成绩（可能缺考），算出等级并支持按姓名查询，最后统计及格人数。

## 知识点

- 枚举与 Option 综合
- tryParse 得到 ?Int64
- isNone() 与 getOrThrow()
- 枚举的穷尽 match
- HashMap 取值得到 ?Level
- 缺失字段的处理

## 输入

第一行一个整数 n；接下来 n 行，每行 `姓名 分数`（单个空格分隔），分数是 0..100 的整数，或者 `-` 表示缺考。接下来一行一个整数 m；再接下来 m 行，每行一个要查询的姓名。

**数据范围**：1 ≤ n ≤ 100；0 ≤ m ≤ 100；姓名只含小写字母且长度 1..10；分数是 0..100 的整数或 `-`；姓名不重复

## 输出

先按输入顺序输出 n 行 `<姓名> <等级>`，等级为 `A`（分数 ≥ 90）、`B`（分数 ≥ 60）、`C`（分数 < 60）、`ABSENT`（缺考）。再按查询顺序输出 m 行 `<姓名>=<等级>`；查不到该姓名时输出 `<姓名>=NOTFOUND`。最后一行 `pass=<及格人数>`（等级为 A 或 B 的人数）。

## 样例

**样例 1**

```
输入：
3
tom 95
amy 58
bob -
0
输出：
tom A
amy C
bob ABSENT
pass=1
```

**样例 2**

```
输入：
2
cat 90
dog 60
2
cat
zoe
输出：
cat A
dog B
cat=A
zoe=NOTFOUND
pass=2
```

## 提示

先把分数（含 `-`）变成 `?Int64`，再把分数映射成枚举等级；把姓名到等级的对照放进 HashMap，取出来的是 `?Level`，用 match 分别处理查到与查不到。
