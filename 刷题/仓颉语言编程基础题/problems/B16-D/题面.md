# B16-D · ★ 扩展工具箱：四种扩展一起用

**关卡**：B16 · 扩展 extension  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 48·49·50 篇
**提交文件**：`answers/B16-D.cj`

> 给整数加「夹取到区间」的能力，给泛型盒子加「贴标签」和「翻倍」的能力，再用接口扩展把记录变成可渲染的行，最后汇总账目。

## 知识点

- 直接扩展 Int64 做区间夹取
- 泛型扩展与 where 约束 extend<T> Box<T>
- 对具体实例化的特化扩展 extend Box<Int64>
- 接口扩展 + 接口集合遍历
- 综合：夹取、翻倍、汇总、选最大

## 输入

第一行一个整数 n（可以为 0）。接下来 n 行，每行 `标签 数量`：标签只含小写字母，数量是整数（可能为负，也可能很大）。

**数据范围**：0 ≤ n ≤ 100；标签只含小写字母且长度 ≤ 10；-1000 ≤ 数量 ≤ 10000；夹取区间为 [0, 1000]

## 输出

前 n 行：`<标签的大写形式，用尖括号包住>:<夹取后的数量 × 2>`；倒数第二行：`total=<夹取后的数量之和>`；最后一行：`top=<夹取后数量最大者的大写标签（并列取最先出现的），n = 0 时输出 none>`。

## 样例

**样例 1**

```
输入：
2
pen 1500
book -20
输出：
<PEN>:2000
<BOOK>:0
total=1000
top=PEN
```

**样例 2**

```
输入：
0
输出：
total=0
top=none
```

## 提示

四种扩展各有写法：`extend Int64 { ... }` 直接扩展；`extend<T> Box<T> where T <: ToString { ... }` 是带约束的泛型扩展（泛型扩展必须写成 `extend<T> 类型<T>`）；`extend Box<Int64> { ... }` 只给某一个具体实例化加成员；`extend 类型 <: 接口` 是接口扩展，实现成员记得加 `public`。
