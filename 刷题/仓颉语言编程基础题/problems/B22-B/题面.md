# B22-B · 注解 + 反射

**关卡**：B22 · 元编程与互操作
**对应博客**：《跟我一起学“仓颉”编程语言》第 71·72·73·74·75·76·77·83·84 篇
**提交文件**：`answers/B22-B.cj`

> 定义一个只能挂在成员变量上的自定义注解，给三个字段各挂一个中文标签；运行时遍历字段，把注解里的标签和字段的值一起输出。

## 知识点

- @Annotation 自定义注解并限定 target
- 注解类的常量构造函数与成员读取
- 把注解挂到成员变量上
- findAnnotation<T>() 读取成员上的注解
- 反射读成员值并与注解信息配对输出

## 输入

一行，`姓名 分数`，单个空格分隔。

**数据范围**：姓名只含小写字母且长度 1..10；0 ≤ 分数 ≤ 100

## 输出

三行，按**字段名 ASCII 升序**排列（依次是 level、name、score 三个字段的标签）：`<标签>=<字段值>`。其中「状态」字段的值按分数算：分数 ≥ 60 是 `pass`，否则是 `fail`。

## 样例

**样例 1**

```
输入：
tom 88
输出：
状态=pass
姓名=tom
分数=88
```

**样例 2**

```
输入：
amy 59
输出：
状态=fail
姓名=amy
分数=59
```

## 提示

自定义注解就是一个类：类上加 `@Annotation[target: [MemberVariable]]` 说明它能挂在成员变量上，再写一个 `public const init(value: String)` 让它能写成 `@标签["文字"]`。遍历 `instanceVariables` 时**顺序不稳定**，所以先把成员名排序；取注解用 `member.findAnnotation<注解类>()`，它返回 Option，取出来的对象上能读到注解里存的字符串。
