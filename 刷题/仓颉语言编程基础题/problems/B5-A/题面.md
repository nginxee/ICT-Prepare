# B5-A · 三个小函数

**关卡**：B5 · 函数基础
**对应博客**：《跟我一起学“仓颉”编程语言》第 10·11·12 篇
**提交文件**：`answers/B5-A.cj`

> 自己定义三个小函数：求两个整数的较大者、求一个整数的绝对值、判断一个整数是否为偶数，然后在主函数里调用它们。

## 知识点

- func 定义与参数列表
- 声明返回类型
- 函数调用与返回值参与运算
- 函数体最后一个表达式作为返回值

## 输入

一行，两个整数 a b（单个空格分隔）。

**数据范围**：-1000000 ≤ a, b ≤ 1000000

## 输出

三行：`max=<a 与 b 中的较大者>`、`absSum=<a 的绝对值加 b 的绝对值>`、`bothEven=true` 或 `bothEven=false`（a 与 b 是否都是偶数）。

## 样例

**样例 1**

```
输入：
3 5
输出：
max=5
absSum=8
bothEven=false
```

**样例 2**

```
输入：
-4 2
输出：
max=2
absSum=6
bothEven=true
```

**样例 3**

```
输入：
-7 -3
输出：
max=-3
absSum=10
bothEven=false
```

## 提示

函数的返回类型写在参数列表后面，用 `:` 引出。函数体最后一个表达式的值可以直接作为返回值，这时不必写 `return`；但如果中途要提前结束，还是要 `return`。判断偶数可以用 `% 2 == 0`。
