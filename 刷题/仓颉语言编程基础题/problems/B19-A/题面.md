# B19-A · 解析失败不崩溃

**关卡**：B19 · 异常处理
**对应博客**：《跟我一起学“仓颉”编程语言》第 51·52·53 篇
**提交文件**：`answers/B19-A.cj`

> 逐行尝试把输入解析成整数，成功输出结果、失败输出标注，最后报告处理条数。

## 知识点

- Int64.parse 失败会抛异常
- try / catch 捕获异常
- finally 块无论成败都执行
- 按行处理的容错模式
- parse 抛异常与 tryParse 返回 ?Int64 的取舍

## 输入

第一行一个整数 n。接下来 n 行，每行一个不含空格的字符串（可能是合法整数，也可能是别的文本）。

**数据范围**：1 ≤ n ≤ 10；每行长度 1..10 且不含空格

## 输出

按输入顺序每行输出一条结果：解析成功输出 `ok <解析出的整数>`，解析失败输出 `bad <该行原文>`；最后一行输出 `done <处理过的行数>`。

## 样例

**样例 1**

```
输入：
3
12
abc
-5
输出：
ok 12
bad abc
ok -5
done 3
```

**样例 2**

```
输入：
1
abc
输出：
bad abc
done 1
```

## 提示

`Int64.parse` 遇到非法文本会抛异常，所以它必须写在 `try` 里；`catch` 只负责输出失败信息，别让程序中断。本题要求用 try / catch 实现；如果只是想知道「能不能解析」，`Int64.tryParse` 会返回 `?Int64`，那是另一种风格。
