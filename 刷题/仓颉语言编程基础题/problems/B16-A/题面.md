# B16-A · 给标准类型加方法

**关卡**：B16 · 扩展 extension
**对应博客**：《跟我一起学“仓颉”编程语言》第 48·49·50 篇
**提交文件**：`answers/B16-A.cj`

> 用自己写的扩展方法，把读入的整数平方、把单词变成大写形式，然后拼成一行输出。

## 知识点

- extend Int64 直接扩展
- extend String 直接扩展
- 扩展方法中的 this
- 扩展方法的调用方式与普通方法一致
- 字符串插值

## 输入

第一行一个整数 n。接下来 n 行，每行 `k w`：k 是整数，w 是只含小写字母的单词。

**数据范围**：1 ≤ n ≤ 100；-1000 ≤ k ≤ 1000；w 只含小写字母且长度 ≤ 10

## 输出

n 行，每行 `<w 的 ASCII 大写形式> -> <k 的平方>`，顺序与输入一致。

## 样例

**样例 1**

```
输入：
2
3 abc
-4 zz
输出：
ABC -> 9
ZZ -> 16
```

**样例 2**

```
输入：
1
0 q
输出：
Q -> 0
```

## 提示

用 `extend Int64 { ... }` 把新方法挂在标准类型上，扩展体里的 `this` 就是被扩展的那个值；给 String 加方法同理。加完之后，调用方式和调用标准库方法完全一样。
