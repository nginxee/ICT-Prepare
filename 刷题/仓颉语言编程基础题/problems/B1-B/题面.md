# B1-B · 信息卡片

**关卡**：B1 · 环境 · 编译 · 输出
**对应博客**：《跟我一起学“仓颉”编程语言》第 01·85 篇
**提交文件**：`answers/B1-B.cj`

> 读入一行三个字段，按固定格式打印一张卡片。

## 知识点

- 多次 println
- 字符串插值
- 固定文本与输入的拼接

## 输入

一行，三个字段：`名字 年龄 城市`，单个空格分隔。名字与城市只含小写字母。

**数据范围**：年龄是 0..150 的整数；名字、城市长度 1..15

## 输出

四行：`==== 卡片 ====`、`姓名: <名字>`、`年龄: <年龄>`、`城市: <城市>`。

## 样例

**样例 1**

```
输入：
tom 18 beijing
输出：
==== 卡片 ====
姓名: tom
年龄: 18
城市: beijing
```

**样例 2**

```
输入：
amy 0 x
输出：
==== 卡片 ====
姓名: amy
年龄: 0
城市: x
```

## 提示

用 `split(" ")` 切分后按位置取，注意下标从 0 开始。
