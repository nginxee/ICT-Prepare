# B11-D · ★ 含税价结算

**关卡**：B11 · 抽象类与接口  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 22·23·24 篇
**提交文件**：`answers/B11-D.cj`

> 抽象类 Goods 同时实现「可计税」和「有标签」两个接口，图书与玩具给出各自的售价与税率，最后统一结算。

## 知识点

- abstract class 同时实现多个接口
- 抽象成员与接口成员的对应关系
- 接口默认实现里的整数计算
- 抽象类引用调用接口方法（多态）
- 接口作为函数参数
- ArrayList 存放抽象类对象

## 输入

第一行一个整数 n；接下来 n 行，每行 `类型 名称 标价`，类型是 `book` 或 `toy`。

**数据范围**：1 ≤ n ≤ 100；0 ≤ 标价 ≤ 1000000；名称只含小写字母，长度 1..10；book 的售价 = 标价 × 9 ÷ 10，税率 5%；toy 的售价 = 标价，税率 10%；税额 = 售价 × 税率 ÷ 100，含税价 = 售价 + 税额，除法都向下取整；标签形如 `[名称-类型]`

## 输出

n 行 `<类型>:<名称> price=<售价> tax=<税额> net=<含税价>`（顺序与输入一致）；随后两行 `sum=<含税价总和>`、`tags=<所有标签首尾相接>`。

## 样例

**样例 1**

```
输入：
2
book cj 100
toy ball 55
输出：
book:cj price=90 tax=4 net=94
toy:ball price=55 tax=5 net=60
sum=154
tags=[cj-book][ball-toy]
```

**样例 2**

```
输入：
1
toy z 1
输出：
toy:z price=1 tax=0 net=1
sum=1
tags=[z-toy]
```

## 提示

抽象类也可以写在 `<:` 后面继承接口：抽象类里只留签名的成员正好满足接口要求，已经写好的成员则直接复用；把接口名写成函数参数类型，抽象类引用就能直接传进去。
