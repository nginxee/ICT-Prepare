# B17-D · HashMap 词频统计

**关卡**：B17 · 集合
**对应博客**：《跟我一起学“仓颉”编程语言》第 42·43·44·45·46·47 篇
**提交文件**：`answers/B17-D.cj`

> 统计每个单词出现的次数，按单词字典序输出词频表。

## 知识点

- HashMap<K, V> 创建
- get 取旧值配合 ?? 默认值
- 下标赋值写入计数
- for ((k, v) in m) 解构遍历
- 按键排序后输出（不依赖哈希顺序）

## 输入

第一行一个整数 n。接下来 n 行，每行一个单词（只含小写字母）。

**数据范围**：1 ≤ n ≤ 100；单词只含小写字母且长度 1..10

## 输出

第一行 `words=<不同单词数>`；第二行 `max=<出现次数最多的次数>`；接下来按单词字典序升序，每行 `<单词> <次数>`（半角空格分隔）。

## 样例

**样例 1**

```
输入：
3
cat
dog
cat
输出：
words=2
max=2
cat 2
dog 1
```

**样例 2**

```
输入：
1
a
输出：
words=1
max=1
a 1
```

## 提示

读到单词先用 `m.get(w) ?? 0` 拿到旧计数，再把 `旧计数 + 1` 写回去；遍历 `HashMap` 时顺序不稳定，要按字典序输出就得先把键收集到 `ArrayList<String>` 里排序。
