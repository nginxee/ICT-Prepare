# L2-B · 逐行相加（读到 EOF）

**关卡**：二 · 读到 EOF（命门）
**提交文件**：`answers/L2-B.cj`

## 输入

**若干行**，每行两个整数 a、b，单个空格分隔，读到输入结束为止。
行数 1..1000，|a|、|b| ≤ 10⁹。

## 输出

**每行输出一个数**，即该行两数之和；共输出与输入行数相同行。

## 样例

**样例 1**

```
输入：
1 2
10 -4
0 0
-5 -5
输出：
3
6
0
-10
```

**样例 2**

```
输入：
7 8
输出：
15
```

**样例 3**

```
输入：
1000000000 1000000000
输出：
2000000000
```

**样例 4**

```
输入：
-3 3
4 -4
输出：
0
0
```
