# L4-A · 组结构 + EOF

**关卡**：四 · 组结构与合流
**提交文件**：`answers/L4-A.cj`

## 输入

输入包含**若干组**数据，读到输入结束为止（组数不定）。
每组为**两行**：
- 第一行：一个整数 n（1 ≤ n ≤ 100）
- 第二行：n 个整数，单个空格分隔，每个绝对值 ≤ 10⁹

## 输出

每组输出**一行**：该组 n 个整数之和。

> 组数没告诉你 —— 你必须靠读到结束来判断还有没有下一组。

## 样例

**样例 1**

```
输入：
3
1 2 3
2
10 20
输出：
6
30
```

**样例 2**

```
输入：
1
5
输出：
5
```

**样例 3**

```
输入：
2
-1 -2
3
1 1 1
输出：
-3
3
```

**样例 4**

```
输入：
4
1 1 1 1
1
-9
输出：
4
-9
```
