# L7-B · 区间加（差分）

**关卡**：七 · 新概念：从编排到算法
**提交文件**：`ict-oj/answers/L7-B.cj`

## 考察概念：**差分数组**

本机知识库**不含算法专题**（计划 §0-B）—— 这一关开始，题目要你自己**想出做法**，
而不是"读进来排个序"。判题**单用例上限 5 秒**。

**朴素做法**（每次操作都循环区间内每个元素）最坏是 O(n·m) ≈ 4×10¹⁰ —— **必然超时**。
**思考方向**：不要记录「每个位置的值」，试试记录「**相邻位置的差**」。
一次区间加，在这个差数组上只改动几个位置？

## 输入

第一行两个整数 ``n m``（1 ≤ n, m ≤ 2×10⁵）。
第二行 n 个整数 a[1..n]，单个空格分隔，|a[i]| ≤ 10⁹。
接下来 m 行，每行三个整数 ``l r v``：把区间 [l, r] 里的**每个数都加上 v**（|v| ≤ 10⁹）。

## 输出

一行，n 个整数：全部操作做完后的最终数组，单个空格分隔。

## 样例

**样例 1**

```
输入：
5 2
1 2 3 4 5
1 3 10
2 5 -1
输出：
11 11 12 3 4
```

**样例 2**

```
输入：
3 3
0 0 0
1 3 5
2 2 -10
1 1 1
输出：
6 -5 5
```
