# L3-B · 一行求和（脏空格）★

**关卡**：三 · 一行 N 个数（读法①） ★挑战
**提交文件**：`ict-oj/answers/L3-B.cj`

## 输入

**一行**，若干个整数。⚠️ 注意空格：
- 数字之间可能有 **1 个或多个**空格；
- **行首、行尾也可能有空格**。

个数 1..1000，每个整数绝对值 ≤ 10⁹。

## 输出

一行，这些整数的和。

> 本题明说会有多余空格——不是陷阱，是规格。

## 样例

**样例 1**

```
输入：
  1   2  3  
输出：
6
```

**样例 2**

```
输入：
1 2 3
输出：
6
```

**样例 3**

```
输入：
    42
输出：
42
```

**样例 4**

```
输入：
7     8
输出：
15
```

**样例 5**

```
输入：
-5   -6
输出：
-11
```
