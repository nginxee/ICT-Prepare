# L1-A · 甲加乙（热身）

**关卡**：一 · 基础读入与格式化输出
**提交文件**：`answers/L1-A.cj`

## 输入

一行，两个整数 a、b，单个空格分隔。|a|、|b| ≤ 10⁹。

## 输出

一行，输出 a + b 的值。

## 样例

**样例 1**

```
输入：
3 5
输出：
8
```

**样例 2**

```
输入：
-7 2
输出：
-5
```

**样例 3**

```
输入：
0 0
输出：
0
```

**样例 4**

```
输入：
1000000000 -1000000000
输出：
0
```
