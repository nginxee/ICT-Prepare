# L1-C · 三位小数

**关卡**：一 · 基础读入与格式化输出
**提交文件**：`ict-oj/answers/L1-C.cj`

## 输入

一行，一个实数 x（可能是 `2.5` 这样的形式，也可能是 `0` 这样的整数形式）。
x 最多 6 位小数，|x| ≤ 10⁴。

## 输出

一行，x 保留 **3 位**小数。
⚠️ 该行**不允许出现任何前导空格**（首字符必须是数字或负号），也不允许科学计数法。

## 样例

**样例 1**

```
输入：
3.14159
输出：
3.142
```

**样例 2**

```
输入：
2.5
输出：
2.500
```

**样例 3**

```
输入：
0
输出：
0.000
```

**样例 4**

```
输入：
-7.7777
输出：
-7.778
```

**样例 5**

```
输入：
1234.5
输出：
1234.500
```
