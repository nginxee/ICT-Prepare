# L4-B · 逐行统计：个数与最大值

**关卡**：四 · 组结构与合流
**提交文件**：`ict-oj/answers/L4-B.cj`

## 输入

**若干行**，每行若干个整数（个数不定，≥ 1），读到输入结束为止。
行数 1..1000，每行个数 1..100。

## 输出

每行按 ``个数 最大值`` 输出：先输出该行整数的个数，一个空格，再输出该行最大值。

> 输出里那个空格是格式的一部分，别多别少。

## 样例

**样例 1**

```
输入：
1 2 3
-5
4 4
输出：
3 3
1 -5
2 4
```

**样例 2**

```
输入：
7 7 7 7
输出：
4 7
```

**样例 3**

```
输入：
-1 -2 -3
0
输出：
3 -1
1 0
```
