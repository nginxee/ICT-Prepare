# L5-B · 排序去重

**关卡**：五 · W2 集合与排序（用库，别手写）
**提交文件**：`ict-oj/answers/L5-B.cj`

## 输入

第一行一个整数 n（1 ≤ n ≤ 10⁵）。
第二行 n 个整数，单个空格分隔，每个绝对值 ≤ 10⁹。**可能有重复。**

## 输出

两行：
1. **不同值**的个数
2. 所有不同值按**升序**输出，单个空格分隔，一行

> 先想清楚：你需要一个集合，还是需要先排序？还是两个都要？

## 样例

**样例 1**

```
输入：
5
3 1 2 3 1
输出：
3
1 2 3
```

**样例 2**

```
输入：
1
5
输出：
1
5
```

**样例 3**

```
输入：
4
-1 -1 -1 -1
输出：
1
-1
```

**样例 4**

```
输入：
6
5 4 3 2 1 0
输出：
6
0 1 2 3 4 5
```
