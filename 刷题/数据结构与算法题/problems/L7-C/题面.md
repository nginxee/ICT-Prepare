# L7-C · 有序数组两数之和（双指针）

**关卡**：七 · 新概念：从编排到算法
**提交文件**：`ict-oj/answers/L7-C.cj`

## 考察概念：**双指针**

本机知识库**不含算法专题**（计划 §0-B）—— 这一关开始，题目要你自己**想出做法**，
而不是"读进来排个序"。判题**单用例上限 5 秒**。

**朴素做法**（两层循环枚举所有数对）是 O(n²) ≈ 2×10¹⁰ —— **必然超时**。
注意数组**已经升序**。
**思考方向**：从两端各放一个指针。如果两数之和**偏大**，应该移动哪一个？
**偏小**呢？为什么这样移动不会漏掉解？

## 输入

第一行两个整数 ``n t``（1 ≤ n ≤ 2×10⁵，|t| ≤ 2×10⁹）。
第二行 n 个整数，**已按升序排列**，可能为负，相邻元素可相等。
**数据保证：若存在解，则解唯一。**

## 输出

若存在 1 ≤ i < j ≤ n 使 a[i] + a[j] = t，输出 ``i j``（一行，空格分隔）；
否则输出 ``-1``。

## 样例

**样例 1**

```
输入：
5 9
1 2 3 4 5
输出：
4 5
```

**样例 2**

```
输入：
4 10
1 2 3 7
输出：
3 4
```

**样例 3**

```
输入：
3 100
1 2 3
输出：
-1
```
