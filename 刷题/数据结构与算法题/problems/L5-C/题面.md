# L5-C · ★多键排序：分数降序 + 姓名升序

**关卡**：五 · W2 集合与排序（用库，别手写） ★挑战
**提交文件**：`ict-oj/answers/L5-C.cj`

## 输入

第一行一个整数 n（1 ≤ n ≤ 10⁴）。
接下来 n 行，每行 ``姓名 分数``，单个空格分隔。
姓名只含小写字母、长度 ≤ 20、**互不重复**；分数 0..100。

## 输出

按**分数降序**输出这 n 行；**分数相同时按姓名升序**。
每行 ``姓名 分数``。

> 两个键、方向相反 —— 这是 `std.sort` 自定义比较器的典型场景。

## 样例

**样例 1**

```
输入：
5
tom 88
amy 95
bob 88
cat 70
dan 95
输出：
amy 95
dan 95
bob 88
tom 88
cat 70
```

**样例 2**

```
输入：
3
a 1
b 2
c 3
输出：
c 3
b 2
a 1
```

**样例 3**

```
输入：
2
z 50
a 50
输出：
a 50
z 50
```

**样例 4**

```
输入：
1
q 0
输出：
q 0
```
