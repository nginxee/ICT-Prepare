# L1-B · 竖式

**关卡**：一 · 基础读入与格式化输出
**提交文件**：`answers/L1-B.cj`

## 输入

一行，两个整数 a、b，单个空格分隔。|a|、|b| ≤ 10⁹。

## 输出

一行，**格式严格**为：`a + b = c`
其中 a、b 按读入时的十进制写法原样输出（负号带出），运算符与数字之间各一个空格。

## 样例

**样例 1**

```
输入：
3 5
输出：
3 + 5 = 8
```

**样例 2**

```
输入：
12 30
输出：
12 + 30 = 42
```

**样例 3**

```
输入：
-7 2
输出：
-7 + 2 = -5
```

**样例 4**

```
输入：
0 -1000000000
输出：
0 + -1000000000 = -1000000000
```
