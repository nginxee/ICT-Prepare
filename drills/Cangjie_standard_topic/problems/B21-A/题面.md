# B21-A · 地址与端口

**关卡**：B21 · 网络编程
**对应博客**：《跟我一起学“仓颉”编程语言》第 78·79·80·81·82 篇
**提交文件**：`answers/B21-A.cj`

> 读入一个 IP 地址和端口号，构造 Socket 地址对象并输出它的各个属性（只做解析，不建立连接）。

## 知识点

- IPAddress.parse 解析 IP 地址
- IPSocketAddress 构造（IP + 端口）
- port 属性读取端口
- isIPv4 判断地址族
- Socket 地址的字符串表示

## 输入

一行，`IP地址 端口`，单个空格分隔。IP 地址是点分十进制的 IPv4，端口是十进制整数。

**数据范围**：IP 只取 127.0.0.0/8 网段的合法 IPv4；0 ≤ 端口 ≤ 65535

## 输出

五行：`host=<IP 地址字符串>`、`port=<端口>`、`ipv4=<该地址是否为 IPv4>`、`zero=<端口是否为 0>`、`text=<地址对象的字符串表示，形如 IP:端口>`。布尔值输出 `true` 或 `false`。

## 样例

**样例 1**

```
输入：
127.0.0.1 8080
输出：
host=127.0.0.1
port=8080
ipv4=true
zero=false
text=127.0.0.1:8080
```

**样例 2**

```
输入：
127.0.0.2 0
输出：
host=127.0.0.2
port=0
ipv4=true
zero=true
text=127.0.0.2:0
```

## 提示

`IPAddress.parse` 把字符串变成 IP 地址；`IPSocketAddress(ip, port)` 拼成地址对象，端口参数是 UInt16，可以直接用 `UInt16.parse` 得到；地址对象能直接插值输出。
