# B14-B · 会记账的闭包

**关卡**：B14 · 函数进阶（lambda/闭包/操作符重载/语法糖）
**对应博客**：《跟我一起学“仓颉”编程语言》第 32·33·34·35·36·37·38 篇
**提交文件**：`answers/B14-B.cj`

> 用「工厂函数」造出记住某个数的加法器和乘法器，再用它们对输入做组合计算。

## 知识点

- 闭包捕获外部变量
- 函数作为返回值
- 返回函数的类型标注
- 捕获参数与捕获局部 let

## 输入

一行，两个整数 `k n`，用单个空格分隔。

**数据范围**：1 ≤ k ≤ 100；0 ≤ n ≤ 1000

## 输出

四行：`add=<n + k>`（用捕获了 k 的加法闭包）、`mul=<n * k>`（用捕获了 k 的乘法闭包）、`chain=<n * k + k>`（先把 n 交给乘法闭包，结果再交给加法闭包）、`local=<n + (n + 1)>`（用捕获了局部量 n+1 的闭包再算一次）。

## 样例

**样例 1**

```
输入：
3 4
输出：
add=7
mul=12
chain=15
local=9
```

**样例 2**

```
输入：
1 0
输出：
add=1
mul=0
chain=1
local=1
```

## 提示

在一个函数里直接 `return` 一个 lambda，这个 lambda 会「记住」它出生时能看到的变量；函数返回类型要写成函数类型，比如 `(Int64) -> Int64`。
