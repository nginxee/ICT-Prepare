# B19-D · ★ 配置解析与错误报告

**关卡**：B19 · 异常处理  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 51·52·53 篇
**提交文件**：`answers/B19-D.cj`

> 把配置写进文件读回来逐行解析，用自定义异常分类错误，并在资源关闭时把统计结果写成报告文件。

## 知识点

- 自定义异常携带错误码
- try 表达式 + throw 组合
- try-with-resources 管理自定义资源
- 资源在 close 时落盘写文件
- File 读写与 StringReader 逐行解析
- 私有目录的先删后建与收尾清理

## 输入

第一行一个整数 n。接下来 n 行，每行一条配置（可能形如 `key=value`，也可能缺少等号）。

**数据范围**：1 ≤ n ≤ 8；key 只含小写字母，长度 1..8；原始行长度 1..12 且不含空格

## 输出

程序在 `./.scratch-B19-D/`（先删后建）下操作：把 n 行原文写进 `config.txt`，再用 try-with-resources 打开一个自定义的统计资源，在块内读回文件内容并逐行解析。每行用 `=` 切分：不是恰好两段就输出 `skip 1`；第二段不是合法整数就输出 `skip 2`；否则输出 `set <key> <数值>`。资源关闭时把统计写成 `report.txt`，内容为三行 `ok=<成功条数>`、`err=<失败条数>`、`sum=<成功数值之和>`。离开 try 块后把 `report.txt` 的内容原样逐行输出，最后输出 `cleaned=<结束前删除目录并返回是否删除成功>`。

## 样例

**样例 1**

```
输入：
3
a=3
b=x
c
输出：
set a 3
skip 2
skip 1
ok=1
err=2
sum=3
cleaned=true
```

**样例 2**

```
输入：
2
x=10
y=20
输出：
set x 10
set y 20
ok=2
err=0
sum=30
cleaned=true
```

## 提示

自定义资源实现 `Resource`，在 `close()` 里用 `File.writeTo` 落盘；解析函数里 `throw` 自己的异常，外面 `catch` 到就计数。
