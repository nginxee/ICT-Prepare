# B3-A · 算术与整除取余

**关卡**：B3 · 操作符与表达式
**对应博客**：《跟我一起学“仓颉”编程语言》第 04·05 篇
**提交文件**：`answers/B3-A.cj`

> 读入两个整数，输出它们的和、差、积、商和余数，重点体会整数除法和取余的符号规则。

## 知识点

- 算术操作符 + - * /
- 整数除法向零截断
- 取模 % 的符号规则
- 多行输出

## 输入

一行，两个整数 a b（单个空格分隔）。

**数据范围**：-1000 ≤ a, b ≤ 1000，且 b 不为 0

## 输出

五行：`a+b=<和>`、`a-b=<差>`、`a*b=<积>`、`a/b=<商>`、`a%b=<余数>`。商按整数除法向零截断，余数满足 a = b*(a/b) + a%b。

## 样例

**样例 1**

```
输入：
7 3
输出：
a+b=10
a-b=4
a*b=21
a/b=2
a%b=1
```

**样例 2**

```
输入：
-7 3
输出：
a+b=-4
a-b=-10
a*b=-21
a/b=-2
a%b=-1
```

**样例 3**

```
输入：
7 -3
输出：
a+b=4
a-b=10
a*b=-21
a/b=-2
a%b=1
```

## 提示

两个整数做 `/` 得到的仍是整数，并且**向零截断**（-7/3 得 -2，不是 -3）。余数用 `a - b*(a/b)` 理解，所以 -7%3 得 -1、7%-3 得 1。
