# B23-C · ★ 成绩管理系统

**关卡**：B23 · 综合应用  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 58·59 篇
**提交文件**：`answers/B23-C.cj`

> 实现一个小型成绩管理程序：按顺序执行若干条命令，维护「姓名 + 科目 + 分数」记录，支持增改、删除、查单科最高分和整表统计。

## 知识点

- ArrayList 存记录 + HashMap 做分组统计
- add / del / top / report 多命令分派
- 输入校验（分数 0..100）
- 函数拆分：findAt / doTop / doReport
- 同名同科目重复录入要覆盖
- 删除后下标失效的处理
- HashMap 遍历顺序不稳定 —— 键要先排序

## 输入

第一行一个整数 n；随后 n 行命令，每行是下面四种之一（字段之间用空格分隔）：
- `add <姓名> <科目> <分数>`
- `del <姓名> <科目>`
- `top <科目>`
- `report`

**数据范围**：0 ≤ n ≤ 60；姓名、科目只含小写字母且长度 1..10；分数是 0..100 的整数

## 输出

每条命令输出如下（科目名、姓名原样输出）：
- `add` 新记录：`add <姓名> <科目> <分数>`
- `add` 时该「姓名 + 科目」已存在：覆盖旧分数并输出 `update <姓名> <科目> <分数>`
- `add` 的分数不是 0..100 的整数：`error score`
- `del` 删除成功：`del <姓名> <科目>`；记录不存在：`miss <姓名> <科目>`
- `top`：`top <科目> <姓名> <分数>`（该科目最高分，同分取姓名 ASCII 字典序最小的）；该科目没有任何记录时输出 `top <科目> none`
- `report`：没有任何记录时输出 `report empty`；否则按科目名 ASCII 升序，每个科目一行 `report <科目> count=<该科目记录数> sum=<该科目分数总和>`
- 命令名不认识或字段个数不对：`error command`

## 样例

**样例 1**

```
输入：
6
add amy math 90
add bob math 80
top math
add amy math 95
report
del bob math
输出：
add amy math 90
add bob math 80
top math amy 90
update amy math 95
report math count=2 sum=175
del bob math
```

**样例 2**

```
输入：
4
report
top math
foo bar
add zoe math 101
输出：
report empty
top math none
error command
error score
```

## 提示

记录用 ArrayList 存，`findAt` 线性查找「姓名 + 科目」对应的下标：找得到就是覆盖，返回 -1 就是新增。`del` 用 `list.remove(at: at)`，删完不用管下标 —— 下次再查就行。`top` 边遍历边比：分数更大就换，分数相同且姓名更小也换，可以用 -1 当「还没找到」的哨兵。`report` 用两个 HashMap 分别累计每个科目的 count 和 sum，注意 **HashMap 的遍历顺序不稳定**，要把科目名收集到 ArrayList 里 `sort` 之后再输出。
