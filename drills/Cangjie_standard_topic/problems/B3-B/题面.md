# B3-B · 关系判断与逻辑运算

**关卡**：B3 · 操作符与表达式
**对应博客**：《跟我一起学“仓颉”编程语言》第 04·05 篇
**提交文件**：`answers/B3-B.cj`

> 读入三个整数，输出五个用关系与逻辑操作符组合出来的判断结果。

## 知识点

- 关系操作符 == != < <= > >=
- 逻辑操作符 ! && ||
- 短路求值
- Bool 值的输出

## 输入

一行，三个整数 a b c（单个空格分隔）。

**数据范围**：-1000 ≤ a, b, c ≤ 1000

## 输出

五行，每行形如 `名称=true` 或 `名称=false`：`sorted`（a ≤ b 且 b ≤ c）、`inRange`（a 落在 0..100 闭区间内）、`allEqual`（a、b、c 三者相等）、`hasZero`（a、b、c 中至少有一个为 0）、`strictMax`（a 同时严格大于 b 和 c）。

## 样例

**样例 1**

```
输入：
1 2 3
输出：
sorted=true
inRange=true
allEqual=false
hasZero=false
strictMax=false
```

**样例 2**

```
输入：
50 50 50
输出：
sorted=true
inRange=true
allEqual=true
hasZero=false
strictMax=false
```

**样例 3**

```
输入：
300 2 3
输出：
sorted=false
inRange=false
allEqual=false
hasZero=false
strictMax=true
```

## 提示

关系运算的结果是 `Bool`，可以直接插进字符串。`&&` 和 `||` 有短路特性：左边已经能定结果时右边不求值。多个条件要用括号想清楚结合顺序。
