# B9-D · ★ 成绩册

**关卡**：B9 · 类与封装  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 18·21 篇
**提交文件**：`answers/B9-D.cj`

> 用 Student 与 ScoreBook 两个类实现一本成绩册：登记分数、评定等级、统计平均分与最高分。

## 知识点

- class + init + this 综合
- private 字段与 mut prop 属性
- static let / static func 静态成员
- ArrayList 存放自定义类对象
- 跨类调用静态方法
- 用方法把遍历与统计封装起来

## 输入

第一行一个整数 n；接下来 n 行，每行 `姓名 分数`，单个空格分隔。

**数据范围**：1 ≤ n ≤ 100；姓名只含小写字母，长度 1..10；0 ≤ 分数 ≤ 100

## 输出

n 行 `<姓名> <分数> <等级>`（等级：分数 ≥ 90 为 A，≥ 80 为 B，≥ 70 为 C，≥ 60 为 D，其余为 F）；随后三行 `average=<总分整除 n>`、`top=<姓名> <分数>`（并列时取最早出现的那个）、`pass=<及格人数>`。

## 样例

**样例 1**

```
输入：
3
tom 90
amy 55
bob 73
输出：
tom 90 A
amy 55 F
bob 73 C
average=72
top=tom 90
pass=2
```

**样例 2**

```
输入：
1
z 0
输出：
z 0 F
average=0
top=z 0
pass=0
```

## 提示

分数设为 `private`，用 `mut prop` 提供读写；等级判断放进 ScoreBook 的 `static func`，平均分、最高分、及格人数交给 ScoreBook 的成员方法，对外只暴露「取所有行」的方法。
