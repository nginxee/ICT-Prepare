# B5-C · 递归三连

**关卡**：B5 · 函数基础
**对应博客**：《跟我一起学“仓颉”编程语言》第 10·11·12 篇
**提交文件**：`answers/B5-C.cj`

> 用递归实现三个函数：阶乘、斐波那契数列第 k 项、两数的最大公约数。

## 知识点

- 递归函数
- 递归终止条件
- 递归调用自身
- 递归求最大公约数
- 把递归结果作为返回值

## 输入

一行，两个非负整数 n k（单个空格分隔）。

**数据范围**：0 ≤ n ≤ 20；0 ≤ k ≤ 30

## 输出

三行：`fact=<n 的阶乘，规定 0 的阶乘为 1>`、`fib=<斐波那契数列第 k 项，规定第 0 项为 0、第 1 项为 1>`、`gcd=<n 与 k 的最大公约数，规定 gcd(a, 0) = a>`。

## 样例

**样例 1**

```
输入：
5 12
输出：
fact=120
fib=144
gcd=1
```

**样例 2**

```
输入：
0 1
输出：
fact=1
fib=1
gcd=1
```

**样例 3**

```
输入：
4 10
输出：
fact=24
fib=55
gcd=2
```

## 提示

递归函数必须有一条「不再递归、直接给答案」的终止分支，否则会无限递归。阶乘和斐波那契用 `n` 或 `k` 变小来逼近终止条件；最大公约数用辗转相除：`gcd(a, b)` 在 `b` 为 0 时直接返回 a，否则递归到 `gcd(b, a % b)`。
