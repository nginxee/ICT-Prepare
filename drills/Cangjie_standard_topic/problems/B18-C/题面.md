# B18-C · 内存流：StringWriter 与 StringReader

**关卡**：B18 · 文件与 I/O 流
**对应博客**：《跟我一起学“仓颉”编程语言》第 54·55·56·57 篇
**提交文件**：`answers/B18-C.cj`

> 用内存输出流拼出文本，再从内存输入流里按行读回来解析。

## 知识点

- ByteBuffer 内存字节流
- StringWriter 写入
- flush 与 bytes()
- StringReader 按行读取
- readln 返回 Option<String>

## 输入

第一行一个整数 n。接下来 n 行，每行 `key value`，单个空格分隔。

**数据范围**：1 ≤ n ≤ 8；key 只含小写字母，长度 1..8；-1000 ≤ value ≤ 1000

## 输出

把每条记录按 `key=value` 写进内存输出流（每条一行），flush 之后取出全部字节。输出：第一行 `raw=<写入的总字节数>`；接下来 n 行 `pair <key> -> <value>`（按读回顺序）；最后一行 `sum=<所有 value 之和>`。

## 样例

**样例 1**

```
输入：
2
a 3
bb 4
输出：
raw=9
pair a -> 3
pair bb -> 4
sum=7
```

**样例 2**

```
输入：
1
k 0
输出：
raw=4
pair k -> 0
sum=0
```

## 提示

输出流用 `StringWriter(ByteBuffer())`，记得 `flush()` 之后用 `buf.bytes()` 取字节；输入流用 `StringReader(ByteBuffer(bytes))`，`readln()` 返回 `Option<String>`。
