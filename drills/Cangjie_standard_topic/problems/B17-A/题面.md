# B17-A · Array 的创建、切片与克隆

**关卡**：B17 · 集合
**对应博客**：《跟我一起学“仓颉”编程语言》第 42·43·44·45·46·47 篇
**提交文件**：`answers/B17-A.cj`

> 读入 n 个整数和一个目标值，输出数组的规模、首尾元素、中间切片、是否包含目标值，以及升序副本。

## 知识点

- Array<Int64>(n, repeat: x) 创建定长数组
- 下标读写与 size
- slice(start, len) 切片
- clone 深拷贝
- contains 查找
- 配合 sort 输出升序副本

## 输入

第一行一个整数 n。第二行 n 个整数（单个空格分隔）。第三行一个整数 t（要查找的目标值）。

**数据范围**：1 ≤ n ≤ 100；-10^6 ≤ 每个元素, t ≤ 10^6

## 输出

六行：`size=<元素个数>`、`first=<第一个元素>`、`last=<最后一个元素>`、`mid=<去掉首尾后的元素，半角逗号分隔；n < 3 时输出 none>`、`has=<是否包含 t：true 或 false>`、`sorted=<升序副本，半角逗号分隔>`。

## 样例

**样例 1**

```
输入：
3
1 2 3
2
输出：
size=3
first=1
last=3
mid=2
has=true
sorted=1,2,3
```

**样例 2**

```
输入：
1
5
9
输出：
size=1
first=5
last=5
mid=none
has=false
sorted=5
```

## 提示

用 `Array<Int64>(n, repeat: 0)` 开一个定长数组再逐个赋值；`arr.slice(start, len)` 的第二个参数是**长度**而不是结束下标；排序要留一份原数组，就先把 `arr.clone()` 出来再 `sort`。
