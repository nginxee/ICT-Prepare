# B8-B · 固定种子的随机数

**关卡**：B8 · 标准库基础（随机/数学/格式化/字符串）
**对应博客**：《跟我一起学“仓颉”编程语言》第 15·16 篇
**提交文件**：`answers/B8-B.cj`

> 用固定种子的随机数生成器产生 n 个 0..99 的整数，统计首尾、最值、总和与平均值。

## 知识点

- std.random 的 Random 类型
- 固定种子保证结果可复现
- nextInt64(upper) 的左闭右开区间
- 最值与平均值统计
- 浮点格式化

## 输入

一行，两个整数 `seed n`，单个空格分隔。

**数据范围**：0 ≤ seed ≤ 1000000；1 ≤ n ≤ 200。必须用 `Random(UInt64(seed))` 创建生成器、用 `nextInt64(100)` 依次取数，结果完全由 seed 决定

## 输出

六行：`first=<第 1 个数>`、`last=<第 n 个数>`、`min=<最小值>`、`max=<最大值>`、`sum=<总和>`、`avg=<平均值，保留 2 位小数>`。

## 样例

**样例 1**

```
输入：
42 5
输出：
first=62
last=57
min=28
max=62
sum=241
avg=48.20
```

**样例 2**

```
输入：
42 1
输出：
first=62
last=62
min=62
max=62
sum=62
avg=62.00
```

## 提示

`Random(UInt64(seed))` 用固定种子创建生成器，同一个种子每跑一次得到的序列完全一样；`nextInt64(100)` 的范围是 0 到 99。注意第 1 个数既是 first，也要参与最值和求和；最小值、最大值可以用第 1 个数来初始化。
