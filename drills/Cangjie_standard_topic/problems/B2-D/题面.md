# B2-D · ★ 类型转换擂台

**关卡**：B2 · 变量与基本数据类型  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 02·03 篇
**提交文件**：`answers/B2-D.cj`

> 读入一行 `整数 浮点 布尔文本`，输出四种类型转换的结果。

## 知识点

- Int64/Float64 显式转换
- 截断而非四舍五入
- Bool.tryParse
- 浮点格式化

## 输入

一行，三个字段：`n f b`，单个空格分隔。n 是整数，f 是带小数点的浮点，b 是 `true`/`false`/其他文本。

**数据范围**：-10^6 ≤ n ≤ 10^6；f 的绝对值 ≤ 10^6 且小数位数 ≤ 3

## 输出

四行：`asFloat=<n 转 Float64 后保留 1 位小数>`、`asInt=<f 转 Int64（截断）>`、`asBool=<b 解析结果，成功输出 true/false，失败输出 none>`、`sum=<n + f 保留 1 位小数>`。

## 样例

**样例 1**

```
输入：
42 3.9 true
输出：
asFloat=42.0
asInt=3
asBool=true
sum=45.9
```

**样例 2**

```
输入：
7 0.5 false
输出：
asFloat=7.0
asInt=0
asBool=false
sum=7.5
```

## 提示

`Float64(n)` 与 `Int64(f)` 是显式转换；`Int64(3.9)` 得到 3（截断）。`Bool.tryParse` 返回 `?Bool`，失败用 `match` 输出 `none`。求和用浮点做，避免整数除法丢掉小数。
