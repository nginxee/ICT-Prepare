# B12-B · 带参数的图形枚举

**关卡**：B12 · 枚举与 Option
**对应博客**：《跟我一起学“仓颉”编程语言》第 25·26·27 篇
**提交文件**：`answers/B12-B.cj`

> 读入一个图形的描述，用带参数的枚举表示它，再输出图形名与面积。

## 知识点

- 带参数的枚举构造器
- match 解构枚举的负载
- 枚举与元组返回值的配合

## 输入

一行，三种形式之一：`dot`、`square <边长>`、`rect <宽> <高>`，字段之间用单个空格分隔。

**数据范围**：边长、宽、高都是 1..1000 的整数；面积不超过 10^6

## 输出

两行：`shape=<DOT|SQUARE|RECT>`、`area=<面积>`。`dot` 的面积记为 0。

## 样例

**样例 1**

```
输入：
square 3
输出：
shape=SQUARE
area=9
```

**样例 2**

```
输入：
rect 4 5
输出：
shape=RECT
area=20
```

**样例 3**

```
输入：
dot
输出：
shape=DOT
area=0
```

## 提示

枚举的构造器可以带「负载」，比如装一个或两个整数；用 match 把负载绑定到变量上，就能像普通整数一样参与计算。
