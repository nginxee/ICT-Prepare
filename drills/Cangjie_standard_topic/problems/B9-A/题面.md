# B9-A · 计数器对象

**关卡**：B9 · 类与封装
**对应博客**：《跟我一起学“仓颉”编程语言》第 18·21 篇
**提交文件**：`answers/B9-A.cj`

> 定义一个计数器类，读入名字与初始值，依次演示累加与重置。

## 知识点

- class 定义
- init 构造函数
- 成员变量 let 与 var
- this 引用成员
- 成员函数

## 输入

两行。第一行 `名字 初始值`，单个空格分隔，名字只含小写字母；第二行一个整数 d。

**数据范围**：0 ≤ 初始值 ≤ 1000000；-1000000 ≤ d ≤ 1000000；名字长度 1..10

## 输出

三行：`init: <名字>=<初始值>`、`after add: <名字>=<初始值+d>`、`after reset: <名字>=0`。

## 样例

**样例 1**

```
输入：
c 5
3
输出：
init: c=5
after add: c=8
after reset: c=0
```

**样例 2**

```
输入：
x 0
0
输出：
init: x=0
after add: x=0
after reset: x=0
```

## 提示

用 `class` 定义类型，在 `init` 里写成 `this.<成员> = <参数>` 把数据存进对象；不会被改的名字用 `let`，会被改的计数用 `var`。
