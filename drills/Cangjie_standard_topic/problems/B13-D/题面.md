# B13-D · 记号识别器

**关卡**：B13 · 模式匹配
**对应博客**：《跟我一起学“仓颉”编程语言》第 28·29·30·31 篇
**提交文件**：`answers/B13-D.cj`

> 读入一行用空格分隔的记号，把每个记号识别成枚举值，再逐行描述它们。

## 知识点

- 带参数枚举模式
- 枚举模式的穷尽匹配
- if-let 解构 Option
- 下标与遍历、字符串拼接

## 输入

一行，若干个用单个空格分隔的记号（1..10 个）。每个记号是：整数（可带负号）、`+`、`-`、`*`，或一个小写单词。

**数据范围**：记号个数 1..10；整数在 -1000..1000 之间；单词只含小写字母且长度 1..10

## 输出

每个记号输出一行 `<下标> <描述>`，下标从 0 开始。描述规则：整数 → `NUM(<值>)`，`+` → `PLUS`，`-` → `MINUS`，`*` → `STAR`，其他单词 → `OTHER(<原文>)`。

## 样例

**样例 1**

```
输入：
1 + 2
输出：
0 NUM(1)
1 PLUS
2 NUM(2)
```

**样例 2**

```
输入：
-3 * x
输出：
0 NUM(-3)
1 STAR
2 OTHER(x)
```

## 提示

先用 `if (let Some(v) <- Int64.tryParse(记号))` 判断它是不是整数，不是再依次比对符号；识别出的枚举值交给一个没有通配分支的 match 生成描述 —— 枚举的每个构造器都要有对应的 case。
