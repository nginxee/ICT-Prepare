# B16-B · 给自定义结构体加方法

**关卡**：B16 · 扩展 extension
**对应博客**：《跟我一起学“仓颉”编程语言》第 48·49·50 篇
**提交文件**：`answers/B16-B.cj`

> 定义平面上的点，再用扩展给它加上「曼哈顿距离」方法，输出每个点的距离与总距离。

## 知识点

- 给自定义 struct 写 extension
- 扩展中访问 this 的成员
- 扩展方法返回值参与累加
- 扩展方法与结构体定义分离

## 输入

第一行一个整数 n。接下来 n 行，每行两个整数 `x y`（单个空格分隔）。

**数据范围**：1 ≤ n ≤ 100；-1000 ≤ x, y ≤ 1000

## 输出

前 n 行：`d=<|x| + |y|>`；最后一行：`sum=<所有 d 之和>`。

## 样例

**样例 1**

```
输入：
2
3 -4
0 0
输出：
d=7
d=0
sum=7
```

**样例 2**

```
输入：
1
-5 -6
输出：
d=11
sum=11
```

## 提示

结构体还是在 `struct Point { ... }` 里定义，方法写在后面的 `extend Point { ... }` 里；扩展内部可以直接用 `this.x`、`this.y`。取绝对值可以自己用 if 判断正负，也可以 `import std.math.*` 之后用 `abs(this.x)`。
