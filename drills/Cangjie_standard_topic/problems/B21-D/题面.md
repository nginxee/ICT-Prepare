> 起一个 TCP 计算服务：客户端把 n 条算式一次性发过去，再发一个结束标记 `bye`；服务端逐行读、逐条算出结果回发，读到 `bye` 时回一个 `bye` 并结束。

## 知识点

- TcpServerSocket / TcpSocket 的收发循环
- 按换行分帧：一次读一个字节拼出一行
- 自定义协议：读到结束标记 bye 就收工
- 服务端逐条回复并计数
- ArrayList 收集请求与回复
- spawn + get 收齐计数后再输出

## 输入

第一行一个整数 n；随后 n 行，每行一条算式 `a op b`，单个空格分隔，op 是 `+`、`-` 或 `*`。

**数据范围**：0 ≤ n ≤ 20；0 ≤ a, b ≤ 1000；结果与中间过程都在 Int64 范围内；只用 127.0.0.1；服务端绑定端口 0

## 输出

前 n 行：`r<i>=<服务端算出的结果>`，i 从 1 开始、顺序与输入一致；最后一行：`count=<服务端真正处理并回复的算式条数>`。

## 样例

**样例 1**

```
输入：
2
3 + 4
5 * 6
输出：
r1=7
r2=30
count=2
```

**样例 2**

```
输入：
0
输出：
count=0
```

## 提示

TCP 是字节流，没有「一行」的概念：写一个小函数，用 `read` 一次读一个字节，攒到换行为止再拼成字符串，服务端才能一行一行地处理。客户端可以把所有请求和 `bye` 拼成一个大字符串一次 `write` 出去，然后按 n+1 行读回复（最后一行是服务端的 `bye`）；服务端的计数由线程返回，`get()` 之后才打印，顺序才稳定。
