# B10-C · 向下转型与类型判断

**关卡**：B10 · 继承与多态
**对应博客**：《跟我一起学“仓颉”编程语言》第 19·20 篇
**提交文件**：`answers/B10-C.cj`

> 把不同图形存进父类容器，遍历时判断真实类型，转型后输出子类特有的字段。

## 知识点

- is 判断运行时类型
- as 向下转型并得到 Option
- getOrThrow 取出转换结果
- 在父类引用上访问子类特有成员

## 输入

第一行一个整数 n；接下来 n 行，每行 `形状 参数…`：`rect 宽 高` 或 `square 边长`。

**数据范围**：1 ≤ n ≤ 100；0 ≤ 宽, 高, 边长 ≤ 1000

## 输出

按输入顺序，矩形输出 `rect w=<宽> h=<高> area=<面积>`，正方形输出 `square s=<边长> area=<面积>`；最后一行为 `rect=<矩形个数> square=<正方形个数> rectWidth=<所有矩形宽度之和>`。

## 样例

**样例 1**

```
输入：
2
rect 2 3
square 4
输出：
rect w=2 h=3 area=6
square s=4 area=16
rect=1 square=1 rectWidth=2
```

**样例 2**

```
输入：
3
square 1
rect 5 2
square 6
输出：
square s=1 area=1
rect w=5 h=2 area=10
square s=6 area=36
rect=1 square=2 rectWidth=5
```

## 提示

`x is 类型` 返回 Bool；`x as 类型` 得到的是 `Option`，用 `is` 判断过之后还要用 `getOrThrow()` 把对象取出来才能访问子类特有的成员。
