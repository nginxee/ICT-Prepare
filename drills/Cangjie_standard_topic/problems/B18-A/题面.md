# B18-A · 写入文件再读回

**关卡**：B18 · 文件与 I/O 流
**对应博客**：《跟我一起学“仓颉”编程语言》第 54·55·56·57 篇
**提交文件**：`answers/B18-A.cj`

> 把读入的若干行写进私有目录里的文本文件，再读回来打印，并报告文件字节数。

## 知识点

- Directory.create 创建目录
- removeIfExists 清理目录
- File.writeTo 写文件
- File.readFrom 读回字节
- String.fromUtf8 字节转字符串
- FileInfo.size 文件字节数

## 输入

第一行一个整数 n。接下来 n 行，每行一个只含小写字母的单词。

**数据范围**：1 ≤ n ≤ 10；单词只含小写字母，长度 1..10；只用相对路径，不要碰私有目录以外的任何文件

## 输出

程序必须在**当前目录**下使用私有目录 `./.scratch-B18-A/`：开始时删除同名目录并重建，把 n 行单词写进 `data.txt`（每行单词后跟一个换行符），结束前删除该目录。输出三部分：第一行 `count=<n>`；接下来 n 行 `序号: <单词>`（序号从 1 开始）；最后一行 `bytes=<data.txt 的字节数>`。

## 样例

**样例 1**

```
输入：
2
ab
cde
输出：
count=2
1: ab
2: cde
bytes=7
```

**样例 2**

```
输入：
1
z
输出：
count=1
1: z
bytes=2
```

## 提示

先 `removeIfExists(dir, recursive: true)` 再 `Directory.create(dir, recursive: true)`；写用 `File.writeTo(path, s.toArray())`，读用 `File.readFrom(path)`。
