# B20-D · ThreadLocal 线程局部变量

**关卡**：B20 · 并发
**对应博客**：《跟我一起学“仓颉”编程语言》第 60·61·62·63·64·65·66·67·68·69·70 篇
**提交文件**：`answers/B20-D.cj`

> 同一个 ThreadLocal 变量，每个线程各写各读，主线程的值不受影响。

## 知识点

- ThreadLocal 线程局部变量
- set / get 的 ?T 语义
- 每个线程各有一份副本
- 主线程与子线程互不影响

## 输入

第一行一个整数 k。接下来 k 行，每行一个整数 v。

**数据范围**：1 ≤ k ≤ 6；-100 ≤ v ≤ 100

## 输出

主线程先把线程局部变量设为 999。然后启动 k 个线程，第 i 个线程把该变量设为 `v_i × 10` 并读回自己的值。输出：第一行 `main=<主线程此刻读到的值>`；接下来 k 行 `thread <序号> <该线程读回的值>`（序号从 1 开始）；然后 `sum=<k 个线程读回值之和>`；最后 `mainAfter=<收齐后主线程再次读到的值>`。

## 样例

**样例 1**

```
输入：
2
3
4
输出：
main=999
thread 1 30
thread 2 40
sum=70
mainAfter=999
```

**样例 2**

```
输入：
1
0
输出：
main=999
thread 1 0
sum=0
mainAfter=999
```

## 提示

`ThreadLocal<T>` 用 `set(值)` 写、`get()` 读，`get()` 返回 `?T`，可以用 `??` 给默认值。
