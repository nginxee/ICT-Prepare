# B6-A · 矩形信息卡

**关卡**：B6 · 结构体 struct

> 定义一个矩形结构体，读入若干个矩形的宽和高，输出每个矩形的面积与周长。

## 知识点

- struct 定义
- 自定义构造函数
- 成员访问 this.字段
- 成员函数

## 输入

第一行一个整数 n。接下来 n 行，每行 `宽 高`，单个空格分隔。

**数据范围**：1 ≤ n ≤ 100；1 ≤ 宽, 高 ≤ 1000

## 输出

按输入顺序每行输出 `w=<宽> h=<高> area=<面积> perimeter=<周长>`。

## 样例

**样例 1**

```
输入：
2
3 4
5 5
输出：
w=3 h=4 area=12 perimeter=14
w=5 h=5 area=25 perimeter=20
```

**样例 2**

```
输入：
1
1 1
输出：
w=1 h=1 area=1 perimeter=4
```

## 提示

先用 `struct` 声明类型，字段写在类型体里；再写一个与结构体同名的构造函数，把参数存进字段；面积和周长各写一个成员函数，函数里用 `this.宽` 访问字段。
