# B22-C · 词法与语法分析

**关卡**：B22 · 元编程与互操作
**对应博客**：《跟我一起学“仓颉”编程语言》第 71·72·73·74·75·76·77·83·84 篇
**提交文件**：`answers/B22-C.cj`

> 读入一个算术表达式：先用词法分析统计词法单元和左括号个数，再把它解析成语法树并遍历，统计加法和乘法节点的个数。

## 知识点

- cangjieLex 把源码字符串转成 Tokens
- Tokens 的 size 与下标访问
- Token 的 kind（TokenKind 枚举）与 value
- parseExpr 把 Tokens 解析成 AST（Expr 节点）
- 继承 Visitor 覆盖 visit(BinaryExpr) 遍历语法树
- 按运算符分类统计语法树节点

## 输入

一行算术表达式，只含非负整数、`+`、`*`、圆括号 `(` `)`，没有空格，长度 1..40。

**数据范围**：表达式合法（括号配对、运算符两侧都有操作数）；整数只由数字组成；长度 ≤ 40

## 输出

四行：`tokens=<词法单元个数>`、`lparen=<左括号的个数>`、`add=<语法树中加法节点的个数>`、`mul=<语法树中乘法节点的个数>`。

## 样例

**样例 1**

```
输入：
1+2*3
输出：
tokens=5
lparen=0
add=1
mul=1
```

**样例 2**

```
输入：
(1+2)*3
输出：
tokens=7
lparen=1
add=1
mul=1
```

**样例 3**

```
输入：
7
输出：
tokens=1
lparen=0
add=0
mul=0
```

## 提示

`std.ast` 的 `cangjieLex(字符串)` 得到 `Tokens`：`size` 是词法单元个数，`tokens[i].kind` 是 `TokenKind` 枚举（左括号就是 `TokenKind.LPAREN`），`value` 是原文。`parseExpr(tokens)` 得到表达式节点；写一个 `class X <: Visitor` 覆盖 `visit(b: BinaryExpr)`，在里面对 `b.op.value` 分类计数，再调用节点的 `traverse(visitor)` 遍历 —— 遍历会依次走到每个二元运算节点。
