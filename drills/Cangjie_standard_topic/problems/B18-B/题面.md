# B18-B · 目录清单与文件信息

**关卡**：B18 · 文件与 I/O 流
**对应博客**：《跟我一起学“仓颉”编程语言》第 54·55·56·57 篇
**提交文件**：`answers/B18-B.cj`

> 按输入造出一批文件和一个子目录，再列出目录清单。

## 知识点

- Directory.readFrom 列目录
- FileInfo.name / size / isDirectory
- Directory.create 建子目录
- ArrayList + sort 排序

## 输入

第一行一个整数 n。接下来 n 行，每行 `名字 长度`，单个空格分隔。

**数据范围**：1 ≤ n ≤ 6；名字只含小写字母，长度 1..8，不会叫 `sub0`；0 ≤ 长度 ≤ 20

## 输出

程序在 `./.scratch-B18-B/`（先删后建）里为每条记录创建一个同名文件，文件内容是`长度` 个字符 `x`；再创建一个名为 `sub0` 的子目录。然后用 Directory.readFrom 列出该目录的全部条目，按名称升序每行输出 `名称 类型`（类型是 `file` 或 `dir`）；最后一行输出 `files=<文件个数> dirs=<目录个数> totalBytes=<所有文件的字节数之和>`；结束前删除该目录。

## 样例

**样例 1**

```
输入：
2
b 3
a 0
输出：
a file
b file
sub0 dir
files=2 dirs=1 totalBytes=3
```

**样例 2**

```
输入：
1
zz 5
输出：
sub0 dir
zz file
files=1 dirs=1 totalBytes=5
```

## 提示

名字收集到 ArrayList 之后用 `sort(names)` 排序；类型判断用 `FileInfo(path).isDirectory()`。
