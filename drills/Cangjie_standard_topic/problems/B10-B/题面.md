# B10-B · 向上转型与多态

**关卡**：B10 · 继承与多态
**对应博客**：《跟我一起学“仓颉”编程语言》第 19·20 篇
**提交文件**：`answers/B10-B.cj`

> 读入若干图形，统一用父类引用保存，遍历输出每个图形的面积并求和。

## 知识点

- 子类对象赋给父类引用（向上转型）
- 父类引用调用被重写的方法
- ArrayList<父类> 存放不同子类对象
- 遍历时的动态绑定

## 输入

第一行一个整数 n；接下来 n 行，每行 `形状 参数…`：`rect 宽 高` 或 `square 边长`。

**数据范围**：1 ≤ n ≤ 100；0 ≤ 宽, 高, 边长 ≤ 1000

## 输出

n 行 `<形状> area=<面积>`（顺序与输入一致），最后一行 `total=<面积总和>`。

## 样例

**样例 1**

```
输入：
3
rect 2 3
square 4
rect 1 1
输出：
rect area=6
square area=16
rect area=1
total=23
```

**样例 2**

```
输入：
1
square 0
输出：
square area=0
total=0
```

## 提示

把子类对象 `add` 进 `ArrayList<形状父类>` 就是向上转型；遍历时变量类型是父类，但实际调用的是子类重写过的方法。
