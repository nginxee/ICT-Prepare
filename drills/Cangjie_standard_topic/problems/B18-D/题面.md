# B18-D · ★ 成绩文件报告

**关卡**：B18 · 文件与 I/O 流  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 54·55·56·57 篇
**提交文件**：`answers/B18-D.cj`

> 把成绩记录写成文件、把不及格的追加到另一个文件，再读回来统计并输出报告。

## 知识点

- BufferedOutputStream 缓冲写入
- File.appendTo 追加写
- File(path, OpenMode.Write) 与 close
- Path.fileName / extensionName
- StringReader 从文件内容逐行解析
- 私有目录的先删后建与收尾清理

## 输入

第一行一个整数 n。接下来 n 行，每行 `姓名 分数`，单个空格分隔。

**数据范围**：1 ≤ n ≤ 20；姓名只含小写字母，长度 1..10；0 ≤ 分数 ≤ 100

## 输出

程序在 `./.scratch-B18-D/`（先删后建）下操作两个文件：① `all.txt`：用缓冲输出流把 n 条记录按 `姓名 分数` 逐行写入；② `fail.txt`：先建成空文件，再把分数小于 60 的记录用追加方式写入。然后读回 `all.txt`，用内存输入流逐行解析。输出固定 8 行：`file=<all.txt 的文件名>`、`ext=<扩展名>`、`lines=<读回的行数>`、`pass=<分数 ≥ 60 的条数>`、`fail=<分数 < 60 的条数>`、`total=<读回后重新累加的分数总和>`、`failBytes=<fail.txt 的字节数>`、`cleaned=<结束前删除目录并返回是否删除成功>`。

## 样例

**样例 1**

```
输入：
3
tom 80
amy 59
bob 60
输出：
file=all.txt
ext=txt
lines=3
pass=2
fail=1
total=199
failBytes=7
cleaned=true
```

**样例 2**

```
输入：
1
z 100
输出：
file=all.txt
ext=txt
lines=1
pass=1
fail=0
total=100
failBytes=0
cleaned=true
```

## 提示

缓冲流写法是 `File(path, OpenMode.Write)` 再用 `BufferedOutputStream(file)` 包一层，写完 `flush()` 再 `close()`；追加用 `File.appendTo(path, bytes)`；路径信息取自 `Path(path)`。
