# B11-C · 多接口与接口参数

**关卡**：B11 · 抽象类与接口
**对应博客**：《跟我一起学“仓颉”编程语言》第 22·23·24 篇
**提交文件**：`answers/B11-C.cj`

> 一个学生同时实现「有名字」和「有分数」两个接口，再分别用两个接口类型的函数处理它。

## 知识点

- 一个类用 & 同时实现多个接口
- 把接口类型写成函数参数类型
- 同一个对象传给不同接口参数
- 接口的默认实现调用接口自己的方法

## 输入

第一行一个整数 n；接下来 n 行，每行 `姓名 分数`，单个空格分隔。

**数据范围**：1 ≤ n ≤ 100；0 ≤ 分数 ≤ 100；姓名只含小写字母，长度 1..10

## 输出

n 行 `== Hi, <姓名> == <pass 或 fail>`；分数 ≥ 60 为 `pass`，否则为 `fail`。

## 样例

**样例 1**

```
输入：
2
tom 60
amy 59
输出：
== Hi, tom == pass
== Hi, amy == fail
```

**样例 2**

```
输入：
1
z 100
输出：
== Hi, z == pass
```

## 提示

继承列表里用 `&` 可以把多个接口串起来；函数的参数类型写成接口名，就能接收任何实现了该接口的对象。
