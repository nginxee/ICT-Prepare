# B14-A · 函数当参数用

**关卡**：B14 · 函数进阶（lambda/闭包/操作符重载/语法糖）
**对应博客**：《跟我一起学“仓颉”编程语言》第 32·33·34·35·36·37·38 篇
**提交文件**：`answers/B14-A.cj`

> 把「要做的变换」写成 lambda 传给同一个函数，对输入整数做三种变换。

## 知识点

- 函数类型 (Int64) -> Int64
- 函数作为参数
- lambda 表达式
- 尾随 lambda

## 输入

一行，一个整数 n。

**数据范围**：-100 ≤ n ≤ 100；结果在 Int64 范围内

## 输出

三行：`double=<n 的 2 倍>`、`square=<n 的平方>`、`neg=<n 的相反数>`。

## 样例

**样例 1**

```
输入：
3
输出：
double=6
square=9
neg=-3
```

**样例 2**

```
输入：
0
输出：
double=0
square=0
neg=0
```

## 提示

把变换写成 `{ x => ... }` 这样的 lambda，它本身就是个值；接收函数参数的那个函数里只要调用 `f(...)` 即可。当 lambda 是最后一个实参时，可以搬到括号外面写。
