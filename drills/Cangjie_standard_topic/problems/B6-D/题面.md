# B6-D · ★ 全班加分统计

**关卡**：B6 · 结构体 struct  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 13·17 篇
**提交文件**：`answers/B6-D.cj`

> 给全班每人加同样的分数（总分封顶 100），输出每人的结果与全班统计。

## 知识点

- struct 定义与构造函数
- let 字段与 var 字段的区别
- mut 函数修改字段
- 静态成员做全班共享统计
- 静态函数汇报
- 成员函数与条件判断

## 输入

第一行两个整数 `n d`，单个空格分隔：n 是学生数，d 是加分值。接下来 n 行，每行 `姓名 分数`，单个空格分隔。

**数据范围**：1 ≤ n ≤ 100；0 ≤ d ≤ 20；0 ≤ 分数 ≤ 100；姓名只含小写字母，长度 1..10；调整后分数 = 分数 + d，超过 100 分的按 100 分记

## 输出

前 n 行：`<姓名> <调整后分数> <PASS 或 FAIL>`，调整后分数 ≥ 60 记 `PASS`，否则记 `FAIL`；第 n+1 行：`avg=<调整后分数的平均值，保留 2 位小数>`；第 n+2 行：`stats=pass=<及格人数>,sum=<调整后分数总和>,best=<最高分>`。

## 样例

**样例 1**

```
输入：
2 5
amy 58
bob 98
输出：
amy 63 PASS
bob 100 PASS
avg=81.50
stats=pass=2,sum=163,best=100
```

**样例 2**

```
输入：
1 0
z 59
输出：
z 59 FAIL
avg=59.00
stats=pass=0,sum=59,best=59
```

## 提示

分数要被 mut 函数改动，所以字段用 `var` 声明、保存它的变量用 `var`；姓名和原始分数读完就不会变，用 `let` 字段更合适。全班共享的及格人数、总分、最高分适合做成静态变量，交给静态函数统一汇报。
