# B19-B · 自定义异常与错误码

**关卡**：B19 · 异常处理
**对应博客**：《跟我一起学“仓颉”编程语言》第 51·52·53 篇
**提交文件**：`answers/B19-B.cj`

> 校验读入的成绩，用自带错误码的自定义异常区分「不是数字」和「超出范围」。

## 知识点

- class 继承 Exception
- 构造函数调用 super(message)
- throw 抛出自己的异常
- catch 具体异常类型并读取字段
- 用 try 表达式包住可能失败的转换

## 输入

第一行一个整数 n。接下来 n 行，每行 `姓名 分数文本`，单个空格分隔。分数文本可能是合法整数，也可能是别的文本。

**数据范围**：1 ≤ n ≤ 10；姓名只含小写字母，长度 1..8；分数文本长度 1..10

## 输出

按输入顺序每行输出一条：校验通过输出 `ok <姓名> <分数>`；失败输出 `error <错误码> <姓名>`（错误码 1 表示分数文本不是整数，2 表示分数不在 0..100 内）。最后一行输出 `e1=<错误码 1 的次数> e2=<错误码 2 的次数>`。

## 样例

**样例 1**

```
输入：
3
tom 80
amy xx
bob 120
输出：
ok tom 80
error 1 amy
error 2 bob
e1=1 e2=1
```

**样例 2**

```
输入：
1
z 0
输出：
ok z 0
e1=0 e2=0
```

## 提示

自定义异常写成 `class 你的异常 <: Exception`，构造函数里先 `super(message)`，再存自己的错误码字段；抛出后用 `catch (e: 你的异常)` 取字段。
