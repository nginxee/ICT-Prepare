# B13-A · 字符分诊台

**关卡**：B13 · 模式匹配

**提交文件**：`answers/B13-A.cj`

> 读入一个字符，判断它属于元音、数字、辅音还是其他符号。

## 知识点

- match 表达式
- 常量模式
- 用 | 合并多个常量
- 绑定模式 + where 守卫
- 通配符模式 _

## 输入

一行，一个 ASCII 可打印字符：小写字母、数字 0-9 或符号（不含空格）。

**数据范围**：输入恰好一个字符；只可能是小写字母、数字或常见符号

## 输出

一行 `kind=<分类>`：元音字母（a e i o u）输出 `vowel`，数字输出 `digit`，其余小写字母输出 `consonant`，其他字符输出 `other`。

## 样例

**样例 1**

```
输入：
a
输出：
kind=vowel
```

**样例 2**

```
输入：
z
输出：
kind=consonant
```

## 提示

常量模式可以一次列出多个值，用 `|` 隔开；如果某个分支还要附加条件，就把值绑定到变量再用 `where` 写条件；最后一个分支用通配符兜底。
