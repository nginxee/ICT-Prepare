# B20-E · 两阶段工人流水线

**关卡**：B20 · 并发
**对应博客**：《跟我一起学“仓颉”编程语言》第 60·61·62·63·64·65·66·67·68·69·70 篇
**提交文件**：`answers/B20-E.cj`

> 工人线程先各自累加，在 Barrier 处对齐，用信号量互斥读取总量，再通过条件变量向主线程汇报。

## 知识点

- Barrier 让所有线程对齐到同一程序点
- AtomicInt64 累加阶段一结果
- Semaphore 互斥读取共享数据
- Mutex 条件变量 wait / notifyAll 汇报完成
- SyncCounter 等待全部线程结束
- Future.get 收集每个线程的结果
- 先收齐再输出保证确定性

## 输入

一行两个整数 k step，单个空格分隔。

**数据范围**：2 ≤ k ≤ 6；1 ≤ step ≤ 10；保证 k × step ≤ 60

## 输出

启动 k 个工人线程：第 i 个线程（i 从 1 开始）先把 `i × step` 累加到共享的原子总量上；所有线程在同一个 Barrier 上对齐之后，再用只有 1 个许可证的信号量互斥地读取总量，把读到的值作为自己的结果返回。每个工人读完后再在一把互斥锁保护下把「已汇报人数」加一，并通知绑定在这把锁上的条件变量；随后让完成计数器减一。主线程先用 `while` 循环加 `wait()` 等到已汇报人数达到 k，再用倒数计数器等到全部线程结束，最后取回全部线程的结果并输出五行：`total=<总量>`、`after=<k 个线程读到的值之和>`、`workers=<k>`、`stage1sum=<所有线程阶段一累加量之和>`、`consistent=<after 是否等于 total × k>`。

## 样例

**样例 1**

```
输入：
2 1
输出：
total=3
after=6
workers=2
stage1sum=3
consistent=true
```

**样例 2**

```
输入：
3 2
输出：
total=12
after=36
workers=3
stage1sum=12
consistent=true
```

## 提示

Barrier 的构造参数是「要等几个线程」，每个工人调用一次 `wait()`；信号量 `acquire()` / `release()` 要成对；条件变量必须先在持锁状态下用 `mtx.condition()` 创建，`wait()` 一定包在 `while` 里防虚假唤醒。
