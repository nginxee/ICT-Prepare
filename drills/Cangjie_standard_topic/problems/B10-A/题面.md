# B10-A · 父类与子类

**关卡**：B10 · 继承与多态
**对应博客**：《跟我一起学“仓颉”编程语言》第 19·20 篇
**提交文件**：`answers/B10-A.cj`

> 定义动物父类与两个子类，读入类型和名字，分别用父类对象与子类对象输出叫声。

## 知识点

- open class 定义可继承的父类
- <: 继承
- init 中调用 super(...)
- override 重写方法
- this 访问继承来的成员

## 输入

一行，`类型 名字`，单个空格分隔；类型是 `dog` 或 `cat`，名字只含小写字母。

**数据范围**：名字长度 1..10；类型只可能是 dog 或 cat

## 输出

两行：第一行 `animal: <名字> says ...`（父类的默认叫声是三个点）；第二行 `<类型>: <名字> says <叫声>`（dog 是 `woof`，cat 是 `meow`）。

## 样例

**样例 1**

```
输入：
dog tom
输出：
animal: tom says ...
dog: tom says woof
```

**样例 2**

```
输入：
cat amy
输出：
animal: amy says ...
cat: amy says meow
```

## 提示

父类要用 `open class` 声明，可被重写的方法要写成 `public open func`；子类构造时先 `super(名字)`，再用 `override` 给出自己的实现。
