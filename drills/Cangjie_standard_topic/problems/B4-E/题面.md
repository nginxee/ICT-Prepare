# B4-E · ★ 数字三角与乘法表

**关卡**：B4 · 流程控制  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 06·07·08·09 篇
**提交文件**：`answers/B4-E.cj`

> 读入行数 n，打印数字直角三角形，再打印下三角九九乘法表，并统计乘积总和与首次超过 n*n 的累加次数。

## 知识点

- 嵌套 for-in 循环
- 外层控行内层控列
- 行尾不留多余空格
- 跨循环累加器
- while 循环与阈值判断
- 输出格式逐字符对齐

## 输入

一行，一个整数 n。

**数据范围**：1 ≤ n ≤ 9

## 输出

依次输出：前 n 行，第 i 行是 1 到 i，数字之间用一个半角空格分隔，行尾不留空格；接着一行 `---`；再 n 行，第 i 行是 `i*j=<i*j>`（j 从 1 到 i），各段之间用一个半角空格分隔，行尾不留空格；接着一行 `productSum=<第二部分所有乘积的总和>`；最后两行 `k=<最小的使 1+2+...+k 严格大于 n*n 的 k>` 与 `reach=<此时 1 到 k 的和>`。

## 样例

**样例 1**

```
输入：
1
输出：
1
---
1*1=1
productSum=1
k=2
reach=3
```

**样例 2**

```
输入：
2
输出：
1
1 2
---
1*1=1
2*1=2 2*2=4
productSum=7
k=3
reach=6
```

**样例 3**

```
输入：
3
输出：
1
1 2
1 2 3
---
1*1=1
2*1=2 2*2=4
3*1=3 3*2=6 3*3=9
productSum=25
k=4
reach=10
```

## 提示

每一行先用一个局部字符串拼好再整体打印：内层第一次循环不加空格，从第二次开始先追加一个空格再追加内容。乘积总和用一个在外层循环之前声明的变量，两层循环里都能改到它。最后一段是「边加边比」的 while：把 k 从 1 往上加进累加和，直到和严格超过 n*n 为止，注意此时的 k 是已经加进去的那个。
