# B8-C · 字符串体检

**关卡**：B8 · 标准库基础（随机/数学/格式化/字符串）
**对应博客**：《跟我一起学“仓颉”编程语言》第 15·16 篇
**提交文件**：`answers/B8-C.cj`

> 读入一行文本，输出它的字符数、字节数，以及几个字符串方法的处理结果。

## 知识点

- String.size 是 UTF-8 字节数
- toRuneArray().size 是字符数
- count 统计子串出现次数
- indexOf 返回 Option 且下标按字节计
- replace 批量替换
- trim 去首尾空白（std.unicode）

## 输入

一行文本 s（1..60 个字符，可以含空格、小写字母和汉字）。

**数据范围**：s 的字符数 1..60；`x` 与 `ab` 都指半角英文字符；`pos` 按 UTF-8 字节下标计（和 bytes 同一套计数），不是字符下标

## 输出

六行：`chars=<字符数>`、`bytes=<字节数>`、`x=<半角字符 x 出现的次数>`、`pos=<子串 ab 第一次出现的下标，没有则 -1>`、`replaced=<把 ab 全部替换成 AB 之后的全文>`、`trimmed=<去掉首尾空白之后的全文>`。

## 样例

**样例 1**

```
输入：
ab x ab
输出：
chars=7
bytes=7
x=1
pos=0
replaced=AB x AB
trimmed=ab x ab
```

**样例 2**

```
输入：
汉ab
输出：
chars=3
bytes=5
x=0
pos=3
replaced=汉AB
trimmed=汉ab
```

## 提示

`.size` 数的是 UTF-8 字节，字符数要先 `toRuneArray()` 再取 `.size`；`trim()` 不在 String 本体里，需要 `import std.unicode.*`；`indexOf` 返回 `?Int64`，用 `?? -1` 给个默认值最省事。
