# B15-B · 泛型结构体：键值对

**关卡**：B15 · 泛型
**对应博客**：《跟我一起学“仓颉”编程语言》第 39·40·41 篇
**提交文件**：`answers/B15-B.cj`

> 读入若干条「名称 分数」记录，用泛型结构体保存，先按原样输出，再输出调换键值后的形式。

## 知识点

- 泛型结构体 struct Pair<A, B>
- 两个类型参数
- 泛型成员函数返回另一种类型组合
- 构造函数与成员访问
- 用 ArrayList 存泛型对象

## 输入

第一行一个整数 n。接下来 n 行，每行 `名称 分数`（单个空格分隔）。

**数据范围**：1 ≤ n ≤ 100；名称只含小写字母且长度 ≤ 10；0 ≤ 分数 ≤ 1000

## 输出

前 n 行：`<名称>=<分数>`（顺序与输入一致）；后 n 行：`<分数>:<名称>`（同样按输入顺序）。

## 样例

**样例 1**

```
输入：
2
tom 90
amy 85
输出：
tom=90
amy=85
90:tom
85:amy
```

**样例 2**

```
输入：
1
z 0
输出：
z=0
0:z
```

## 提示

`struct Pair<A, B>` 的两个类型参数可以不同，例如 `Pair<String, Int64>`；成员函数里再用 `Pair<B, A>(...)` 造一个键值调换的新对象返回。
