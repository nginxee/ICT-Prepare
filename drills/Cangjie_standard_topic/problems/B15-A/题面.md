# B15-A · 同一个泛型函数，两种类型

**关卡**：B15 · 泛型
**对应博客**：《跟我一起学“仓颉”编程语言》第 39·40·41 篇
**提交文件**：`answers/B15-A.cj`

> 读入若干条「二选一」记录，用同一个泛型函数挑出左边或右边的值，再统一包装输出。

## 知识点

- 泛型函数定义 func f<T>(...)
- 类型参数自动推导
- 同一个泛型函数实例化为 Int64 与 String
- where T <: ToString 约束
- 字符串插值

## 输入

第一行一个整数 n。接下来 n 行，每行四个字段 `类型 左值 右值 方向`（单个空格分隔）：类型为 `i`（左右值都是整数）或 `s`（左右值都是单词）；方向为 `L`（取左值）或 `R`（取右值）。

**数据范围**：1 ≤ n ≤ 100；t 为 `i` 时 -10^6 ≤ a, b ≤ 10^6；t 为 `s` 时 a、b 只含小写字母且长度 ≤ 10

## 输出

n 行，每行是挑中值的包装形式 `[值]`。

## 样例

**样例 1**

```
输入：
2
i 3 7 R
s ab cd L
输出：
[7]
[ab]
```

**样例 2**

```
输入：
1
i 5 5 L
输出：
[5]
```

## 提示

关键是写一个泛型函数，让它对 Int64 和 String 两种实参都能用（类型参数由实参自动推导）；再写第二个泛型函数负责拼成 `[值]` —— 想让 `T` 直接放进 `${}` 插值里，必须给它加上 `where T <: ToString` 约束。
