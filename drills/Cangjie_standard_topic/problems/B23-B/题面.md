# B23-B · 成绩单报表

**关卡**：B23 · 综合应用
**对应博客**：《跟我一起学“仓颉”编程语言》第 58·59 篇
**提交文件**：`answers/B23-B.cj`

> 读入 n 条 `姓名 分数`，输出一份统计报表：人数、总分、平均分、及格人数、最高分学生和排序后的名单。

## 知识点

- struct 组织记录
- ArrayList 收集数据
- 累加器统计总分与及格人数
- sort 自定义比较（分数降序、同分姓名升序）
- String.join 拼接一行
- 整数除法求平均分

## 输入

第一行一个整数 n；随后 n 行，每行 `姓名 分数`，单个空格分隔。

**数据范围**：1 ≤ n ≤ 50；姓名只含小写字母且长度 1..10；0 ≤ 分数 ≤ 100

## 输出

六行：`count=<人数>`、`total=<总分>`、`avg=<总分整除人数>`、`pass=<分数 ≥ 60 的人数>`、`best=<分数最高的学生姓名，同分时取姓名 ASCII 字典序最小的>`、`list=<按分数降序、同分按姓名升序排列的「姓名:分数」，用半角逗号连接，无空格>`。

## 样例

**样例 1**

```
输入：
3
amy 100
bob 80
cat 70
输出：
count=3
total=250
avg=83
pass=3
best=amy
list=amy:100,bob:80,cat:70
```

**样例 2**

```
输入：
2
zoe 60
ann 60
输出：
count=2
total=120
avg=60
pass=2
best=ann
list=ann:60,zoe:60
```

## 提示

用 struct 存一条记录，读入时顺手累加总分和及格人数。排序用 `sort(list, lessThan: {a, b => ...})`：先比分数，分数不同时分数高的排前面，分数相同时姓名小的排前面 —— 排完之后第一个就是 `best`。名单用 `ArrayList<String>` 收集 `姓名:分数`，再用 `String.join(..., delimiter: ",")` 拼成一行。
