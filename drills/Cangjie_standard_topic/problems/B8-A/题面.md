# B8-A · 数学函数小测

**关卡**：B8 · 标准库基础（随机/数学/格式化/字符串）
**对应博客**：《跟我一起学“仓颉”编程语言》第 15·16 篇
**提交文件**：`answers/B8-A.cj`

> 读入一个小数 x 和一个整数 k，用标准库数学函数依次算出六项结果，并按指定位数输出。

## 知识点

- std.math 的 ceil / floor / round / sqrt / abs
- Float64.getPI() 取圆周率
- std.convert 的 format 控制小数位数
- Float64.parse 解析小数

## 输入

一行，两个字段 `x k`，单个空格分隔。x 是带小数点的非负数（小数部分只能是 .0、.25 或 .75），k 是整数。

**数据范围**：0 ≤ x ≤ 1000，x 的小数部分只能是 .0 / .25 / .75；1 ≤ k ≤ 10

## 输出

六行：`ceil=<ceil(x)，保留 1 位小数>`、`floor=<floor(x)，保留 1 位小数>`、`round=<round(x)，保留 1 位小数>`、`sqrt=<sqrt(x)，保留 2 位小数>`、`abs=<abs(x - k)，保留 2 位小数>`、`pi=<圆周率 × k，保留 4 位小数>`。

## 样例

**样例 1**

```
输入：
2.75 2
输出：
ceil=3.0
floor=2.0
round=3.0
sqrt=1.66
abs=0.75
pi=6.2832
```

**样例 2**

```
输入：
16.0 1
输出：
ceil=16.0
floor=16.0
round=16.0
sqrt=4.00
abs=15.00
pi=3.1416
```

## 提示

数学函数都在 `std.math` 里；圆周率没有现成常量，要用 `Float64.getPI()`。保留小数位用 `.format(".1")` 这样的精度串（小数点后直接跟位数），**不要**写 `.1f`。
