# B11-A · 抽象类与抽象成员

**关卡**：B11 · 抽象类与接口
**对应博客**：《跟我一起学“仓颉”编程语言》第 22·23·24 篇
**提交文件**：`answers/B11-A.cj`

> 定义图形抽象类，读入半径与长宽，输出圆形、长方形各自的面积与总和。

## 知识点

- abstract class 声明
- 只有签名没有函数体的抽象成员
- 子类必须 override 实现抽象成员
- 抽象类里已经写好的具体方法
- 通过抽象类引用调用多态

## 输入

一行三个整数 `r w h`，单个空格分隔：r 是圆半径，w 和 h 是长方形的宽与高。

**数据范围**：0 ≤ r, w, h ≤ 1000；圆周率取 3

## 输出

三行：`circle area=<3*r*r>`、`box area=<w*h>`、`total=<两个面积之和>`。

## 样例

**样例 1**

```
输入：
2 3 4
输出：
circle area=12
box area=12
total=24
```

**样例 2**

```
输入：
0 5 0
输出：
circle area=0
box area=0
total=0
```

## 提示

抽象类用 `abstract class` 声明；抽象成员只写 `public func 名字(): 类型`（不写函数体），非抽象子类必须用 `override` 补上。
