# B4-D · 区间里找倍数

**关卡**：B4 · 流程控制
**对应博客**：《跟我一起学“仓颉”编程语言》第 06·07·08·09 篇
**提交文件**：`answers/B4-D.cj`

> 读入 n 与 d，在 1 到 n 的闭区间里先找出最小的 d 的倍数，再统计一共有多少个 d 的倍数以及它们的总和。

## 知识点

- for-in 遍历闭区间 ..=
- break 提前退出
- continue 跳过本次迭代
- 累加器统计个数与总和
- 找不到时的退化输出

## 输入

一行，两个正整数 n d（单个空格分隔）。

**数据范围**：1 ≤ n ≤ 10000；1 ≤ d ≤ 10000

## 输出

三行：`first=<1..n 中最小的能被 d 整除的数，没有则输出 none>`、`count=<1..n 中能被 d 整除的数的个数>`、`sum=<这些数的总和>`。

## 样例

**样例 1**

```
输入：
10 3
输出：
first=3
count=3
sum=18
```

**样例 2**

```
输入：
5 7
输出：
first=none
count=0
sum=0
```

**样例 3**

```
输入：
10 1
输出：
first=1
count=10
sum=55
```

## 提示

找第一个数时，一旦命中就可以 `break` 跳出，不用继续扫；统计个数和总和时则是每个数都要看一眼，不能被整除就 `continue` 跳过。区间 `1..=n` 是**闭区间**，包含 n。可以用一个哨兵值表示「还没找到」。
