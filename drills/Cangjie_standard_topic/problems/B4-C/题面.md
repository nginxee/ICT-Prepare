# B4-C · 对折到超过

**关卡**：B4 · 流程控制
**对应博客**：《跟我一起学“仓颉”编程语言》第 06·07·08·09 篇
**提交文件**：`answers/B4-C.cj`

> 一张纸厚度初始为 1，每对折一次厚度翻倍。读入目标厚度，用 do-while 反复对折，直到厚度严格大于目标为止。

## 知识点

- do-while 循环
- 循环体至少执行一次
- 末尾判断条件
- 与 while 的区别

## 输入

一行，一个整数 n，表示目标厚度。

**数据范围**：0 ≤ n ≤ 1000000000

## 输出

两行：`folds=<对折次数>`、`thickness=<对折结束后的厚度>`。注意 n 为 0 时纸张初始厚度已经大于目标，但 do-while 仍会先执行一次循环体，因此对折次数为 1。

## 样例

**样例 1**

```
输入：
0
输出：
folds=1
thickness=2
```

**样例 2**

```
输入：
1000
输出：
folds=10
thickness=1024
```

**样例 3**

```
输入：
1024
输出：
folds=11
thickness=2048
```

## 提示

`do { ... } while (条件)` 是**先执行一次循环体，再判断条件**。本题里「先翻倍、再检查是否已经超过目标」正好是这个顺序；如果把条件写反（写成厚度小于目标就继续），n 为 0 时就会多折一次。
