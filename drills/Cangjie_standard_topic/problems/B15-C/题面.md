# B15-C · 泛型约束与类型别名

**关卡**：B15 · 泛型
**对应博客**：《跟我一起学“仓颉”编程语言》第 39·40·41 篇
**提交文件**：`answers/B15-C.cj`

> 读入若干组分数对，用带约束的泛型函数取每组的较大者，并汇总所有较大者。

## 知识点

- 类型别名 type Score = Int64
- where T <: Comparable<T> 约束
- 约束支撑下的比较运算
- 泛型函数与别名配合
- 累加汇总

## 输入

第一行一个整数 n。接下来 n 行，每行两个整数 `a b`（单个空格分隔）。

**数据范围**：1 ≤ n ≤ 100；-10^6 ≤ a, b ≤ 10^6

## 输出

前 n 行：`max=<较大者>`（相等时取 a）；最后一行：`sum=<所有较大者之和>`。

## 样例

**样例 1**

```
输入：
2
3 7
5 5
输出：
max=7
max=5
sum=12
```

**样例 2**

```
输入：
1
-4 -9
输出：
max=-4
sum=-4
```

## 提示

`type Score = Int64` 只是给类型起个新名字；泛型函数里要用 `>=` 比较，就必须在 `where` 子句里声明 `T <: Comparable<T>`，否则编译器不知道 T 能不能比大小。
