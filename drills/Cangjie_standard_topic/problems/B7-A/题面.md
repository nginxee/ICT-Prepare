# B7-A · 包声明与整体导入

**关卡**：B7 · 包与导入
**对应博客**：《跟我一起学“仓颉”编程语言》第 14 篇
**提交文件**：`answers/B7-A.cj`

> 本题要求：文件第一行必须是 `package B7A`，并且只用整体导入（`import std.env.*` 与 `import std.convert.*`）。读入若干条库存记录，逐条回显并汇总。

## 知识点

- package 声明写在文件第一行
- 整体导入 import 包名.*
- 使用标准库子包 std.env 与 std.convert
- 顶层函数的 public 修饰符

## 输入

第一行一个整数 n。接下来 n 行，每行 `名称 数量`，单个空格分隔。名称只含小写字母。

**数据范围**：1 ≤ n ≤ 100；名称长度 1..10；0 ≤ 数量 ≤ 1000000

## 输出

前 n 行：`name=<名称> count=<数量>`；最后一行：`total=<数量总和>`。

## 样例

**样例 1**

```
输入：
2
pen 3
book 12
输出：
name=pen count=3
name=book count=12
total=15
```

**样例 2**

```
输入：
1
a 0
输出：
name=a count=0
total=0
```

## 提示

每个仓颉源文件都从 `package 包名` 开始（写在最前面）；`import 包名.*` 是整体导入，把这个包里公开的名字一次全带进来。把「拼一行文本」的活儿交给一个顶层 `public func`，main 里只负责读和写。
