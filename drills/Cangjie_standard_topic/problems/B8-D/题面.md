# B8-D · ★ 随机加分成绩报表

**关卡**：B8 · 标准库基础（随机/数学/格式化/字符串）  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 15·16 篇
**提交文件**：`answers/B8-D.cj`

> 用固定种子给每名学生随机加分（总分封顶 100），输出对齐的成绩报表与统计。

## 知识点

- Random 固定种子生成加分
- StringBuilder 拼接与补位
- String.size 数字符
- format 保留小数
- abs 求差的绝对值
- 等级判断与最值统计

## 输入

第一行两个整数 `seed n`，单个空格分隔。接下来 n 行，每行 `姓名 分数`，单个空格分隔。

**数据范围**：1 ≤ n ≤ 100；0 ≤ seed ≤ 1000000；姓名只含小写字母，长度 1..8；0 ≤ 分数 ≤ 100。加分规则：第 i 名学生取 `Random(UInt64(seed))` 的第 i 个 `nextInt64(21)`（范围 0..20），最终分 = 分数 + 加分，超过 100 分的按 100 分记

## 输出

前 n 行：`<姓名补位> <最终分> <等级>`，姓名不足 8 个字符时用 `.` 在其后补齐到 8 个字符；等级规则为最终分 ≥ 90 记 A、≥ 75 记 B、≥ 60 记 C、否则记 D。第 n+1 行：`top=<最终分最高的学生姓名，并列取最先出现的>`；第 n+2 行：`avg=<最终分的平均值，保留 2 位小数>`；第 n+3 行：`spread=<最高分与平均值之差的绝对值，保留 2 位小数>`。

## 样例

**样例 1**

```
输入：
42 2
amy 58
bob 96
输出：
amy..... 76 B
bob..... 100 A
top=bob
avg=88.00
spread=12.00
```

**样例 2**

```
输入：
7 3
cat 50
dog 74
e 100
输出：
cat..... 65 C
dog..... 93 A
e....... 100 A
top=e
avg=86.00
spread=14.00
```

## 提示

补位用 `StringBuilder` 一个一个 append：先 append 姓名，再 append 若干个 `.`，个数是 8 减去姓名的字符数。等级用 if / else if 依次判断；先把所有人的最终分统计完，最后再统一格式化输出。
