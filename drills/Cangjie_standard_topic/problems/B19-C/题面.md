# B19-C · try-with-resources 自动关闭

**关卡**：B19 · 异常处理
**对应博客**：《跟我一起学“仓颉”编程语言》第 51·52·53 篇
**提交文件**：`answers/B19-C.cj`

> 写一个实现 Resource 的会话类，观察它在成功和抛异常两种情况下都被自动关闭。

## 知识点

- Resource 接口（isClosed / close）
- try (r = ...) 自动释放资源
- 正常路径与异常路径都会 close
- close 在 catch 之前执行

## 输入

第一行一个整数 n。接下来 n 行，每行 `标签 模式`，单个空格分隔；模式只可能是 `ok` 或 `boom`。

**数据范围**：1 ≤ n ≤ 5；标签只含大写字母，长度 1..4；模式只能是 ok 或 boom

## 输出

对每一行依次产生若干行输出：构造会话时输出 `open <标签>`；模式为 `ok` 时输出 `use <标签>`；离开会话时输出 `close <标签>`（只会出现一次）；模式为 `boom` 时，在 `close` 之后再输出 `caught <标签>`。全部处理完后输出最后一行 `count=<n>`。

## 样例

**样例 1**

```
输入：
2
A ok
B boom
输出：
open A
use A
close A
open B
close B
caught B
count=2
```

**样例 2**

```
输入：
1
X boom
输出：
open X
close X
caught X
count=1
```

## 提示

让类实现 `Resource` 接口（`isClosed()` 和 `close()` 都要 `public`），然后写 `try (s = 你的类(标签)) { ... }`，异常路径同样会走 close。
