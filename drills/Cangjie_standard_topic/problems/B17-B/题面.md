# B17-B · ArrayList 的收集与统计

**关卡**：B17 · 集合
**对应博客**：《跟我一起学“仓颉”编程语言》第 42·43·44·45·46·47 篇
**提交文件**：`answers/B17-B.cj`

> 读入 n 个整数，把它们中的非零元素按原顺序收集到 ArrayList 里，再输出统计信息。

## 知识点

- ArrayList<T> 创建与 add 追加（不是 append）
- 遍历集合
- size 与下标访问
- contains 查找
- 空集合的处理（不能直接取 list[0]）

## 输入

第一行两个整数 `n t`（单个空格分隔，t 是要查找的目标值）。第二行 n 个整数（单个空格分隔）；n = 0 时第二行不存在。

**数据范围**：0 ≤ n ≤ 100；-10^6 ≤ 每个整数, t ≤ 10^6

## 输出

四行：`count=<收集到的元素个数>`、`sum=<这些元素之和>`、`first=<第一个收集到的元素，一个都没有则输出 none>`、`has=<收集到的元素里是否包含 t：true 或 false>`。

## 样例

**样例 1**

```
输入：
3 7
1 0 -2
输出：
count=2
sum=-1
first=1
has=false
```

**样例 2**

```
输入：
0 5
输出：
count=0
sum=0
first=none
has=false
```

## 提示

`let list = ArrayList<Int64>()` 之后用 `list.add(x)` 追加（注意不叫 append）；`list.contains(t)` 直接判断有没有；集合为空时 `list[0]` 会越界，先看 `list.size` 再取。
