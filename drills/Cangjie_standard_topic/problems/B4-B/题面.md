# B4-B · 冰雹序列

**关卡**：B4 · 流程控制
**对应博客**：《跟我一起学“仓颉”编程语言》第 06·07·08·09 篇
**提交文件**：`answers/B4-B.cj`

> 读入一个正整数，反复按「偶数折半、奇数乘三加一」变换直到变成 1，输出变换步数与过程中出现过的最大值。

## 知识点

- while 循环
- 循环内分支判断
- 累加器计数
- 边扫边求最大值
- 退化输入

## 输入

一行，一个正整数 n。

**数据范围**：1 ≤ n ≤ 1000

## 输出

两行：`steps=<变换步数>`、`max=<从 n 开始到 1 为止出现过的最大数值>`。若 n 已经是 1，步数为 0、最大值为 1。

## 样例

**样例 1**

```
输入：
6
输出：
steps=8
max=16
```

**样例 2**

```
输入：
1
输出：
steps=0
max=1
```

**样例 3**

```
输入：
27
输出：
steps=111
max=9232
```

## 提示

循环条件是「当前值不等于 1」。循环体里先用 `% 2` 判断奇偶再决定怎么更新；每更新一次就累加步数，并顺手更新最大值。n 已经是 1 时循环一次也不进，所以初值要把 n 也算进最大值。
