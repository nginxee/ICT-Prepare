# B21-B · UDP 一发一收

**关卡**：B21 · 网络编程
**对应博客**：《跟我一起学“仓颉”编程语言》第 78·79·80·81·82 篇
**提交文件**：`answers/B21-B.cj`

> 在同一个进程里：主线程起一个 UDP 服务端并让它等在接收调用上，再由客户端把读入的文本发过去；服务端收下后主线程才输出结果。

## 知识点

- UdpSocket 构造（bindAt 命名参数）与 bind
- 绑定端口 0 由系统分配空闲端口
- localAddress 读回真实端口
- sendTo / receiveFrom 收发报文
- spawn 起线程 + get 收齐后再输出

## 输入

一行文本，只含 ASCII 小写字母。

**数据范围**：文本只含小写字母，长度 1..20；只用 127.0.0.1；服务端和客户端都绑定端口 0，由系统分配空闲端口

## 输出

三行：`port_assigned=<绑定端口 0 后系统是否分配到了有效端口，输出 true 或 false>`、`recv=<服务端收到的文本>`、`bytes=<该文本的 UTF-8 字节数>`。

## 样例

**样例 1**

```
输入：
ping
输出：
port_assigned=true
recv=ping
bytes=4
```

**样例 2**

```
输入：
a
输出：
port_assigned=true
recv=a
bytes=1
```

## 提示

服务端写成 `UdpSocket(bindAt: 0)`，然后 `bind()`，再用 `localAddress` 读回系统分配的真实端口；接收要放到 `spawn { ... }` 起的线程里，主线程负责发送，最后用 `get()` 把线程结果收回来再打印 —— 输出顺序才是确定的。字符串和字节数组之间用 `toArray()` / `String.fromUtf8` 转换。
