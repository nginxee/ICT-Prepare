# B10-D · ★ 薪资结算

**关卡**：B10 · 继承与多态  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 19·20 篇
**提交文件**：`answers/B10-D.cj`

> 用员工父类和两种子类实现一个薪资结算程序，Team 类组合保存所有成员并汇总统计。

## 知识点

- open class + <: + override + super 综合
- 向上转型后统一结算（多态）
- 在重写中调用 super.slip() 复用父类逻辑
- is / as 向下转型做分类统计
- 组合：Team 持有 ArrayList<Employee>

## 输入

第一行一个整数 n；接下来 n 行，每行 `类型 姓名 底薪 [额外]`：`base 姓名 底薪`、`sales 姓名 底薪 佣金`、`mgr 姓名 底薪 奖金`。

**数据范围**：1 ≤ n ≤ 100；0 ≤ 底薪, 佣金, 奖金 ≤ 1000000；姓名只含小写字母，长度 1..10

## 输出

n 行工资条：普通员工与销售输出 `<姓名> pay=<薪资>`，经理输出 `MGR <姓名> pay=<薪资>`（经理的薪资 = 底薪 + 奖金，销售的薪资 = 底薪 + 佣金）；随后三行 `total=<薪资总和>`、`mgr=<经理人数>`、`commission=<销售佣金总和>`。

## 样例

**样例 1**

```
输入：
4
base a 100
sales b 200 50
mgr c 300 100
sales d 400 25
输出：
a pay=100
b pay=250
MGR c pay=400
d pay=425
total=1175
mgr=1
commission=75
```

**样例 2**

```
输入：
1
base z 0
输出：
z pay=0
total=0
mgr=0
commission=0
```

## 提示

父类的 `pay()` 要写成 `public open func`，子类重写时用 `super.pay()` 复用父类计算再叠加自己的部分；做分类统计时先用 `is` 判断，再 `as` 转型取出子类特有字段。
