# B3-D · ★ 表达式求值台

**关卡**：B3 · 操作符与表达式  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 04·05 篇
**提交文件**：`answers/B3-D.cj`

> 读入三个整数 x k s，按题面给出的表达式逐个求值并输出，用来检验你对优先级、结合性和类型转换的掌握。

## 知识点

- 运算符优先级与结合性
- 复合赋值操作符
- 整除与取余
- 位运算与逻辑运算混合
- Int64 与 Float64 的显式转换
- 浮点格式化输出

## 输入

一行，三个整数 x k s（单个空格分隔）。

**数据范围**：-100 ≤ x ≤ 100；1 ≤ k ≤ 6；1 ≤ s ≤ 9。浮点结果按四舍五入保留题目要求的小数位。

## 输出

十一行：`prec1=<x + k * 2>`、`prec2=<(x + k) * 2>`、`prec3=<x << k + 1>`、`prec4=<x & s | k>`、`quot=<x / s>`、`rem=<x % s>`、`cond=<x > 0 && x % s == 0>`、`mixed=<x * 2 - s / 2 + k % 3>`、`asFloat=<x 转成 Float64 并保留 1 位小数>`、`ratio=<x 除以 s 的浮点结果，保留 3 位小数>`、`acc=<累加器的最终值>`。其中 `acc` 的算法是：从 x 出发，依次执行「加上 k」「乘以 2」「减去 s」「左移 1 位」「与 1 按位或」。

## 提示

按优先级表从紧到松记：一元 `!`/`-`、`**`、`* / %`、`+ -`、`<< >>`、比较、判等、`&`、`^`、`|`、`&&`、`||`。也就是说 `+` 比 `<<` 结合得更紧，`&` 比 `|` 更紧；同级运算左结合。整数和浮点不能混算，要先做显式转换。
