# B6-C · 静态成员：入库台账

**关卡**：B6 · 结构体 struct
**对应博客**：《跟我一起学“仓颉”编程语言》第 13·17 篇
**提交文件**：`answers/B6-C.cj`

> 每件商品「入库」时用静态成员累计件数与总价，最后用静态函数输出台账。

## 知识点

- 静态常量 static let
- 静态变量 static var
- 静态函数 static func
- 通过类型名访问静态成员

## 输入

第一行一个整数 n。接下来 n 行，每行 `名称 价格`，单个空格分隔。名称只含小写字母。

**数据范围**：1 ≤ n ≤ 100；名称长度 1..10；0 ≤ 价格 ≤ 5000

## 输出

三行：`count=<入库件数>`、`total=<价格总和>`、`report=count=<入库件数>,total=<价格总和>,limit=1000`。

## 样例

**样例 1**

```
输入：
2
pen 1200
book 30
输出：
count=2
total=1230
report=count=2,total=1230,limit=1000
```

**样例 2**

```
输入：
1
a 0
输出：
count=1
total=0
report=count=1,total=0,limit=1000
```

## 提示

静态成员属于类型本身而不是某个对象，用 `类型名.成员名` 访问；静态函数里可以直接写静态成员的名字。台账的累加放在 mut 函数里，每件商品入库时调用一次。
