# B12-C · 可能没有昵称

**关卡**：B12 · 枚举与 Option
**对应博客**：《跟我一起学“仓颉”编程语言》第 25·26·27 篇
**提交文件**：`answers/B12-C.cj`

> 读入一行人员记录，昵称字段可能缺失；用 Option 表示「没有值」，再输出它的三种视图。

## 知识点

- Option<T> / ?T
- Some 与 None
- ?T 的构造
- match 取 Option
- ?. 安全访问
- ?? 提供默认值
- isSome()

## 输入

一行，两种形式之一：`姓名` 或 `姓名 昵称`，用单个空格分隔。

**数据范围**：姓名与昵称都只含小写字母，长度 1..20；昵称最多 20 个字符

## 输出

四行：`name=<姓名>`、`nick=<昵称，缺失时输出 none>`、`nickLen=<昵称的字符数，缺失时输出 0>`、`hasNick=<true|false>`。

## 样例

**样例 1**

```
输入：
tom tommy
输出：
name=tom
nick=tommy
nickLen=5
hasNick=true
```

**样例 2**

```
输入：
tom
输出：
name=tom
nick=none
nickLen=0
hasNick=false
```

## 提示

先用 split 看字段有几个，再决定造 `Some(...)` 还是 `None`；有值/没值用 match 或 isSome 判断，要对可能缺失的值做成员访问时用 `?.`，想给默认值就用 `??`。
