# B17-C · HashSet 去重

**关卡**：B17 · 集合
**对应博客**：《跟我一起学“仓颉”编程语言》第 42·43·44·45·46·47 篇
**提交文件**：`answers/B17-C.cj`

> 读入 n 个整数和一个目标值，输出去重后的个数、升序列表，以及目标值是否出现过。

## 知识点

- HashSet<T> 创建
- add 自动去重
- contains 判断存在
- 遍历集合
- 集合顺序不稳定，输出前先排序

## 输入

第一行一个整数 n。第二行 n 个整数（单个空格分隔）。第三行一个整数 t（要查找的值）。

**数据范围**：1 ≤ n ≤ 100；-10^6 ≤ 每个整数, t ≤ 10^6

## 输出

三行：`distinct=<不同值的个数>`、`sorted=<去重后升序，半角空格分隔>`、`has=<是否出现过 t：true 或 false>`。

## 样例

**样例 1**

```
输入：
4
1 2 2 3
2
输出：
distinct=3
sorted=1 2 3
has=true
```

**样例 2**

```
输入：
2
5 5
4
输出：
distinct=1
sorted=5
has=false
```

## 提示

`HashSet<Int64>()` 的 `add` 自带去重能力；但集合的遍历顺序**不稳定**，输出前要把元素倒进 `ArrayList` 再 `sort`，否则每次运行结果可能不一样。
