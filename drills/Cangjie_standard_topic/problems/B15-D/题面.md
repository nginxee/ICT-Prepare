# B15-D · ★ 泛型工具函数：最大值与排序拼接

> 为一串整数写两个泛型工具函数：一个求最大值（空串返回 none），一个把元素升序拼成一行。

## 知识点

- 多约束 where T <: Comparable<T> & ToString
- 泛型函数接收 ArrayList<T>
- 空集合返回 Option
- 在泛型函数内部排序副本
- 泛型与集合的综合

## 输入

第一行一个整数 n（可以为 0）。若 n > 0，第二行是 n 个整数，单个空格分隔；n = 0 时第二行不存在。

**数据范围**：0 ≤ n ≤ 100；-10^6 ≤ 每个整数 ≤ 10^6

## 输出

三行：`count=<元素个数>`、`max=<最大值，空集合输出 none>`、`sorted=<升序后以半角逗号拼接，空集合输出 none>`。

## 样例

**样例 1**

```
输入：
3
3 1 2
输出：
count=3
max=3
sorted=1,2,3
```

**样例 2**

```
输入：
0
输出：
count=0
max=none
sorted=none
```

## 提示

求最大值要比较元素大小，所以泛型参数需要 `where T <: Comparable<T>` 约束；拼接函数既要排序（比较）又要插值（转字符串），多个约束用 `&` 连起来写。空集合要单独返回 `none`；排序会改动集合本身，先 `clone()` 再排。
