# B12-A · 信号灯枚举

**关卡**：B12 · 枚举与 Option
**对应博客**：《跟我一起学“仓颉”编程语言》第 25·26·27 篇
**提交文件**：`answers/B12-A.cj`

> 读入一个信号灯名称，先转成枚举值，再用 match 取出它的动作与持续秒数。

## 知识点

- enum 定义
- 无参枚举构造器
- match 与枚举
- 枚举的穷尽匹配

## 输入

一行，一个信号灯名称：`red`、`yellow` 或 `green`（保证是三者之一，全小写）。

**数据范围**：输入一定是 red、yellow、green 之一；三者的动作与秒数都不相同

## 输出

两行。第一行 `action=<动作>`，第二行 `seconds=<秒数>`。对应关系：red → `STOP` / 30，yellow → `WAIT` / 3，green → `GO` / 25。

## 样例

**样例 1**

```
输入：
red
输出：
action=STOP
seconds=30
```

**样例 2**

```
输入：
green
输出：
action=GO
seconds=25
```

## 提示

先定义一个只有三个构造器的枚举；再写一个把字符串变成枚举值的函数，最后用 match 从枚举里分别取出动作和秒数。
