# B4-A · 成绩等级

**关卡**：B4 · 流程控制
**对应博客**：《跟我一起学“仓颉”编程语言》第 06·07·08·09 篇
**提交文件**：`answers/B4-A.cj`

> 读入一个百分制成绩，按分数段输出等级，并判断是否及格。

## 知识点

- if/else if/else 多分支
- 分支顺序与区间判定
- 边界值处理
- Bool 变量的输出

## 输入

一行，一个整数 score。

**数据范围**：0 ≤ score ≤ 100

## 输出

两行：第一行 `grade=<等级>`，等级规则为 90..100 得 `A`、80..89 得 `B`、70..79 得 `C`、60..69 得 `D`、0..59 得 `E`；第二行 `pass=true` 或 `pass=false`，当且仅当 score 不小于 60 时为 true。

## 样例

**样例 1**

```
输入：
95
输出：
grade=A
pass=true
```

**样例 2**

```
输入：
59
输出：
grade=E
pass=false
```

**样例 3**

```
输入：
60
输出：
grade=D
pass=true
```

## 提示

分支要从高分段往低分段写，这样每个 `else if` 只需要判断下界，不用再写上界。等级可以先给一个默认值，再在分支里改。
