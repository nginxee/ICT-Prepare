# B14-C · 变长参数的求和器

**关卡**：B14 · 函数进阶（lambda/闭包/操作符重载/语法糖）
**对应博客**：《跟我一起学“仓颉”编程语言》第 32·33·34·35·36·37·38 篇
**提交文件**：`answers/B14-C.cj`

> 写一个能接收任意多个整数的求和函数与求最大值函数，并用输入的数字试出不同实参个数的结果。

## 知识点

- 变长参数语法糖
- 0 个实参的调用
- Array<Int64> 参数与遍历
- 同一函数的多次复用

## 输入

一行，三个整数 `a b c`，用单个空格分隔。

**数据范围**：-1000 ≤ a, b, c ≤ 1000

## 输出

四行：`sum0=<不传任何数字时的求和结果>`、`sum2=<a 与 b 的和>`、`sum3=<a、b、c 三个数的和>`、`max3=<a、b、c 中的最大值>`。

## 样例

**样例 1**

```
输入：
1 2 3
输出：
sum0=0
sum2=3
sum3=6
max3=3
```

**样例 2**

```
输入：
0 0 0
输出：
sum0=0
sum2=0
sum3=0
max3=0
```

## 提示

把最后一个参数声明成数组类型即可：调用时直接列出若干个值，编译器会把它们收集成数组传进去（0 个值就是空数组）；函数体里按普通数组遍历。
