# B14-D · ★ 向量计算器

> 给二维向量结构体重载运算符，用它累加一组向量，再做取负、缩放与原地平移。

## 知识点

- struct 里的操作符重载
- 二元运算符 + 与 *
- 一元运算符 -
- mut 函数原地修改
- 结构体的值语义

## 输入

第一行一个整数 n；接下来 n 行，每行两个整数 `x y`，用单个空格分隔。

**数据范围**：1 ≤ n ≤ 50；-1000 ≤ x, y ≤ 1000

## 输出

五行。设所有向量之和为 (Sx, Sy)：`sum=(<Sx>,<Sy>)`；`neg=(<-Sx>,<-Sy>)`（对和取负）；`scaled=(<2Sx>,<2Sy>)`（和的两倍）；`shifted=(<Sx+n>,<Sy+n>)`（把和复制一份后原地平移 n）；`origin=(<Sx>,<Sy>)`（原来的和，验证复制出来的副本被改动后原值不变）。

## 样例

**样例 1**

```
输入：
1
3 4
输出：
sum=(3,4)
neg=(-3,-4)
scaled=(6,8)
shifted=(4,5)
origin=(3,4)
```

**样例 2**

```
输入：
2
1 2
3 4
输出：
sum=(4,6)
neg=(-4,-6)
scaled=(8,12)
shifted=(6,8)
origin=(4,6)
```

## 提示

运算符重载就是写在结构体里的特殊成员函数：二元运算符只写右操作数（左操作数是自己），一元运算符不写参数。想原地修改实例的成员，成员函数要加 `mut`，而且只能用 `var` 声明的变量去调用它。
