# B5-B · 重载与默认参数

**关卡**：B5 · 函数基础
**对应博客**：《跟我一起学“仓颉”编程语言》第 10·11·12 篇
**提交文件**：`answers/B5-B.cj`

> 定义三个同名的 `render` 函数：一个接收单个整数并描述它的平方，一个接收两个整数并描述它们的和，一个接收字符串并可选地转成大写。

## 知识点

- 函数重载（同名不同参数列表）
- 命名参数
- 命名参数的默认值
- 调用时按名称覆盖默认值

## 输入

一行，`a b word` 三个字段，单个空格分隔：a、b 是整数，word 是只含小写字母的字符串。

**数据范围**：-1000 ≤ a, b ≤ 1000；word 只含小写字母，长度 1..10

## 输出

四行：`square=<对 a 调用单参数版本的输出>`、`sum=<对 a、b 调用双参数版本的输出>`、`word=<对 word 调用字符串版本且不传可选参数的结果>`、`upper=<对 word 调用字符串版本并把可选参数设为 true 的结果>`。其中单参数版本输出 `<a> 的平方是 <a*a>`，双参数版本输出 `<a> + <b> = <a+b>`，字符串版本在可选参数为 true 时输出全大写、否则原样输出。

## 样例

**样例 1**

```
输入：
3 4 abc
输出：
square=3 的平方是 9
sum=3 + 4 = 7
word=abc
upper=ABC
```

**样例 2**

```
输入：
-5 5 x
输出：
square=-5 的平方是 25
sum=-5 + 5 = 0
word=x
upper=X
```

**样例 3**

```
输入：
0 0 zz
输出：
square=0 的平方是 0
sum=0 + 0 = 0
word=zz
upper=ZZ
```

## 提示

重载要求同名函数的参数**个数或类型**不同，编译器按实参选版本。带默认值的参数必须写成命名参数（参数名后加 `!` 再写 `= 默认值`），调用时用 `参数名: 值` 的形式覆盖它，而且命名参数不要求按顺序出现。
