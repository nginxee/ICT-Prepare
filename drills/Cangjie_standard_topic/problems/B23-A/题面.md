# B23-A · ATM 命令模拟

**关卡**：B23 · 综合应用
**对应博客**：《跟我一起学“仓颉”编程语言》第 58·59 篇
**提交文件**：`answers/B23-A.cj`

> 模拟一台 ATM：按顺序读入若干条命令并逐条执行，输出每条命令的结果。初始余额为 0，读入 `quit` 后要打印告别语，并且忽略它后面的命令。

## 知识点

- 命令序列循环处理
- if / else if 分支分派命令
- Int64.tryParse 校验金额
- match 处理 Option
- 状态变量（余额、是否已退出）
- 函数拆分：抽出一个校验函数

## 输入

第一行一个整数 n；随后 n 行命令，每行是下面四种之一（字段之间用空格分隔）：
- `deposit <金额>`：存款
- `withdraw <金额>`：取款
- `balance`：查询余额
- `quit`：退出

**数据范围**：0 ≤ n ≤ 50；金额是 1..10000 的整数；余额始终在 0..100000 之间

## 输出

每条命令输出一行：
- 存款成功：`deposit <金额> ok balance=<新余额>`
- 取款成功：`withdraw <金额> ok balance=<新余额>`
- 余额不足：`withdraw <金额> fail balance=<当前余额>`（余额不变）
- 查询余额：`balance=<当前余额>`
- 退出：`bye balance=<当前余额>`
- 金额不是 1..10000 的整数（或缺参数）：`error amount`
- 以上都不是的命令：`error unknown`
`quit` 之后的命令不再产生任何输出。

## 样例

**样例 1**

```
输入：
5
deposit 100
withdraw 30
balance
withdraw 500
quit
输出：
deposit 100 ok balance=100
withdraw 30 ok balance=70
balance=70
withdraw 500 fail balance=70
bye balance=70
```

**样例 2**

```
输入：
4
deposit abc
foo
withdraw 10
quit
输出：
error amount
error unknown
withdraw 10 fail balance=0
bye balance=0
```

## 提示

用一个 `var` 记余额、一个 `var` 记是否已经 quit；每轮先读一行、`split` 成字段，再按第一个字段分派。金额校验可以抽成一个小函数：参数个数不对或者 `Int64.tryParse` 出来不在 1..10000 就返回 `None`。已经 quit 之后要继续把输入读完（否则会漏读），但不再输出。
