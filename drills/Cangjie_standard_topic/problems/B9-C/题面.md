# B9-C · 静态成员与自动编号

**关卡**：B9 · 类与封装
**对应博客**：《跟我一起学“仓颉”编程语言》第 18·21 篇
**提交文件**：`answers/B9-C.cj`

> 每创建一张工单就自动编号，读入标题后输出编号清单与总编号数。

## 知识点

- static let 静态常量
- static var 静态变量
- static func 静态方法
- 在构造函数里更新静态状态

## 输入

第一行一个整数 n；接下来 n 行，每行一个标题（只含小写字母）。

**数据范围**：1 ≤ n ≤ 100；标题长度 1..10

## 输出

前 n 行每行 `<编号> <标题>`，编号形如 `T-1`、`T-2`…；最后一行为 `issued=<创建的工单总数>`。

## 样例

**样例 1**

```
输入：
2
alpha
beta
输出：
T-1 alpha
T-2 beta
issued=2
```

**样例 2**

```
输入：
1
z
输出：
T-1 z
issued=1
```

## 提示

静态成员属于类而不属于某个对象，用 `类名.成员` 访问；在 `init` 里把静态计数加一，编号就能自动递增。
