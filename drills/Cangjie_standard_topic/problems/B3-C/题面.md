# B3-C · 位运算与字节打包

**关卡**：B3 · 操作符与表达式
**对应博客**：《跟我一起学“仓颉”编程语言》第 04·05 篇
**提交文件**：`answers/B3-C.cj`

> 读入两个字节范围内的整数和一个移位位数，输出六种位运算结果，并把两个数打包成一个整数。

## 知识点

- 按位与 &
- 按位或 |
- 按位异或 ^
- 按位取反 !
- 左移 << 与右移 >>
- 移位与或运算的优先级

## 输入

一行，三个整数 a b k（单个空格分隔）：a、b 是参与位运算的两个操作数，k 是移位位数。

**数据范围**：0 ≤ a, b ≤ 255；0 ≤ k ≤ 6

## 输出

七行：`and=<a 与 b 按位与>`、`or=<a 与 b 按位或>`、`xor=<a 与 b 按位异或>`、`not=<a 按位取反>`、`shl=<a 左移 k 位>`、`shr=<a 右移 k 位>`、`packed=<把 a 放在高 8 位、b 放在低 8 位拼成的整数>`。按位取反按 64 位补码计算，结果等于 -a-1。

## 样例

**样例 1**

```
输入：
12 10 2
输出：
and=8
or=14
xor=6
not=-13
shl=48
shr=3
packed=3082
```

**样例 2**

```
输入：
255 0 0
输出：
and=0
or=255
xor=255
not=-256
shl=255
shr=255
packed=65280
```

**样例 3**

```
输入：
1 1 6
输出：
and=1
or=1
xor=0
not=-2
shl=64
shr=0
packed=257
```

## 提示

位运算符只作用于整数。`!` 作用在整数上是**按位取反**（不是逻辑非）。注意优先级：`<<` 比 `|` 结合得更紧，所以 `a << 8 | b` 会先算左移。
