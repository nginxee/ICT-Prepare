# B11-B · 接口的默认实现

**关卡**：B11 · 抽象类与接口
**对应博客**：《跟我一起学“仓颉”编程语言》第 22·23·24 篇
**提交文件**：`answers/B11-B.cj`

> 用支付接口结算若干笔订单：现金走默认的免手续费实现，刷卡与钱包各自覆盖手续费规则。

## 知识点

- interface 声明与成员方法
- 接口方法的默认实现（带函数体）
- 实现类不写就用默认版本
- 实现类覆盖默认实现
- 接口引用调用多态方法

## 输入

第一行一个整数 m；接下来 m 行，每行 `方式 金额`：方式是 `cash`、`card` 或 `wallet`。

**数据范围**：1 ≤ m ≤ 100；0 ≤ 金额 ≤ 1000000；cash 免手续费，card 收金额的 1%（整除，向下取整），wallet 固定收 2

## 输出

m 行 `<方式> fee=<手续费> total=<金额+手续费>`，最后一行 `feeSum=<手续费总和>`。

## 样例

**样例 1**

```
输入：
3
cash 100
card 200
wallet 50
输出：
cash fee=0 total=100
card fee=2 total=202
wallet fee=2 total=52
feeSum=4
```

**样例 2**

```
输入：
1
cash 0
输出：
cash fee=0 total=0
feeSum=0
```

## 提示

接口里的方法可以直接写函数体，那就是默认实现；实现类可以不写（用默认的），也可以写一份自己的把它覆盖掉。
