# B2-A · 整数族与声明

**关卡**：B2 · 变量与基本数据类型
**对应博客**：《跟我一起学“仓颉”编程语言》第 02·03 篇
**提交文件**：`answers/B2-A.cj`

> 读入两个整数，分别用 let/var 保存并输出它们的和、差、积。

## 知识点

- let 与 var 的区别
- Int64 声明与解析
- 整数运算
- 多行输出

## 输入

一行，两个整数 a b（单个空格分隔）。

**数据范围**：-1000 ≤ a, b ≤ 1000

## 输出

三行：`a+b=<和>`、`a-b=<差>`、`a*b=<积>`（差按 a-b 计算，可能是负数）。

## 样例

**样例 1**

```
输入：
3 5
输出：
a+b=8
a-b=-2
a*b=15
```

**样例 2**

```
输入：
0 0
输出：
a+b=0
a-b=0
a*b=0
```

## 提示

`var` 声明的变量可以改；这题不改也行，但注意 `let` 赋过一次就不能再赋值。
