# B20-C · 互斥锁与 synchronized

**关卡**：B20 · 并发
**对应博客**：《跟我一起学“仓颉”编程语言》第 60·61·62·63·64·65·66·67·68·69·70 篇
**提交文件**：`answers/B20-C.cj`

> 用一把互斥锁保护共享计数，每个线程在嵌套的锁块里做两次自增。

## 知识点

- Mutex 创建互斥锁
- synchronized 自动加锁解锁
- 可重入：嵌套 synchronized 不会死锁
- 共享可变状态放进类实例

## 输入

一行两个整数 n k，单个空格分隔。

**数据范围**：1 ≤ n ≤ 500；1 ≤ k ≤ 8；保证 n × k ≤ 2000

## 输出

三行：`counter=<最终计数>`、`threads=<线程数>`、`consistent=<计数是否恰好等于 2 × n × k>`。必须等全部线程结束后再输出。

## 样例

**样例 1**

```
输入：
3 2
输出：
counter=12
threads=2
consistent=true
```

**样例 2**

```
输入：
1 1
输出：
counter=2
threads=1
consistent=true
```

## 提示

`spawn` 的代码块不能捕获可变的局部变量，所以计数器要放进类的字段里；锁用 `synchronized(mtx) { ... }` 包住临界区。
