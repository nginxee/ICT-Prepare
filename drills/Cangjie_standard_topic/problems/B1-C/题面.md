# B1-C · ★ 三行清单

**关卡**：B1 · 环境 · 编译 · 输出  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 01·85 篇
**提交文件**：`answers/B1-C.cj`

> 读入三行项目记录，输出规范化的清单与条目数。

## 知识点

- 连续多行读入
- 输出格式逐字符对齐
- 把固定值写进输出

## 输入

三行，每行 `项目名 数量`，单个空格分隔。项目名只含小写字母。

**数据范围**：数量是 0..9999 的整数；项目名长度 1..12

## 输出

四行：前三行是 `- <项目名>: <数量> 件`（顺序与输入一致），最后一行为 `条目数: 3`。

## 样例

**样例 1**

```
输入：
pen 3
book 12
bag 0
输出：
- pen: 3 件
- book: 12 件
- bag: 0 件
条目数: 3
```

**样例 2**

```
输入：
a 1
b 2
c 3
输出：
- a: 1 件
- b: 2 件
- c: 3 件
条目数: 3
```

## 提示

读三次、写三行；`条目数` 是固定的 3 —— 先把「读入 → 拼串 → 输出」三段写清楚。
