# B16-C · 接口扩展：让旧类型学会新本领

**关卡**：B16 · 扩展 extension
**对应博客**：《跟我一起学“仓颉”编程语言》第 48·49·50 篇
**提交文件**：`answers/B16-C.cj`

> 定义一个「可描述」接口，用接口扩展让书籍结构体满足它，再把书当作接口类型统一输出。

## 知识点

- 定义 interface
- extend 类型 <: 接口（接口扩展）
- 接口扩展成员要用 public
- 把实现类型当作接口类型使用
- 通过接口调用方法

## 输入

第一行一个整数 n。接下来 n 行，每行 `书名 页数`（单个空格分隔）。

**数据范围**：1 ≤ n ≤ 100；书名只含小写字母且长度 ≤ 10；1 ≤ 页数 ≤ 1000

## 输出

前 n 行：`<书名>(<页数>页)`；最后一行：`thick=<页数 ≥ 100 的本数>`。

## 样例

**样例 1**

```
输入：
2
alg 120
cpp 80
输出：
alg(120页)
cpp(80页)
thick=1
```

**样例 2**

```
输入：
1
z 100
输出：
z(100页)
thick=1
```

## 提示

接口只写方法签名：`interface Describable { func describe(): String }`；再用 `extend Book <: Describable` 补上实现。注意接口扩展里的实现成员要写成 `public func ...`，否则可见性不够。之后就能把 Book 放进 `ArrayList<Describable>` 里统一处理。
