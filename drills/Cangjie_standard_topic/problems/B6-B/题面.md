# B6-B · 值语义：副本互不影响

**关卡**：B6 · 结构体 struct
**对应博客**：《跟我一起学“仓颉”编程语言》第 13·17 篇
**提交文件**：`answers/B6-B.cj`

> 做一个「副本实验」：把同一个结构体对象拷贝两份，只在副本上累加，观察原对象是否被改动。

## 知识点

- struct 是值类型（赋值即拷贝）
- mut 函数修改 var 字段
- let 变量不能调用 mut 函数
- let 字段不可修改

## 输入

一行，三个整数 `v d m`，单个空格分隔：v 是初始值，d 是每次累加的量，m 是累加次数。

**数据范围**：-1000 ≤ v ≤ 1000；1 ≤ d ≤ 1000；0 ≤ m ≤ 1000

## 输出

三行：`a=<a.value>`、`b=<b.value>`、`c=<c.value>`。其中 b 是 a 的拷贝、在 b 上累加 m 次 d；c 是 b 的拷贝、再累加一次 d。

## 样例

**样例 1**

```
输入：
10 5 3
输出：
a=10
b=25
c=30
```

**样例 2**

```
输入：
0 1 0
输出：
a=0
b=0
c=1
```

## 提示

结构体是**值类型**：`var b = a` 得到的是一份独立拷贝，改 b 不会影响 a。要改动字段，字段得声明成 `var`，并且保存它的变量必须是 `var`（`let` 变量不能调用 mut 函数）。
