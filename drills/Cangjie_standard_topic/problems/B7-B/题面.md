# B7-B · 成员导入：只引入要用的

**关卡**：B7 · 包与导入
**对应博客**：《跟我一起学“仓颉”编程语言》第 14 篇
**提交文件**：`answers/B7-B.cj`

> 本题要求：文件第一行必须是 `package B7B`；`getStdIn` 与 `sqrt` 必须用成员导入，不能写 `import std.env.*` / `import std.math.*`。计算若干整数的平方根并求和。

## 知识点

- 成员导入 import 包名.成员名
- 成员导入与整体导入混用
- 使用 std.math 的 sqrt
- Float64.parse 与小数格式化

## 输入

第一行一个整数 n。接下来 n 行，每行一个非负整数 x。

**数据范围**：1 ≤ n ≤ 100；0 ≤ x ≤ 1000000

## 输出

每行输出 `x=<x> sqrt=<x 的平方根，保留 3 位小数>`；最后一行输出 `sum=<x 的总和>`。

## 样例

**样例 1**

```
输入：
2
2
10
输出：
x=2 sqrt=1.414
x=10 sqrt=3.162
sum=12
```

**样例 2**

```
输入：
1
0
输出：
x=0 sqrt=0.000
sum=0
```

## 提示

成员导入写成 `import 包名.成员名`，只把这一个名字带进当前文件。`sqrt` 的参数是 Float64，整数要先显式转换；想保留 3 位小数就给浮点数接一个 `.format(".3")`。
