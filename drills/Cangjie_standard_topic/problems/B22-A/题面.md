# B22-A · 反射读成员

**关卡**：B22 · 元编程与互操作
**对应博客**：《跟我一起学“仓颉”编程语言》第 71·72·73·74·75·76·77·83·84 篇
**提交文件**：`answers/B22-A.cj`

> 定义一个图书类，用反射枚举它的成员名并按名称排序输出，再用反射读出书名、库存，并把库存加一。

## 知识点

- ClassTypeInfo.of 获取类型信息
- instanceVariables 枚举 public 实例变量
- 成员集合顺序不稳定，必须按名称排序后输出
- getInstanceVariable 按名称精确取成员
- getValue 返回 Any，用 as 解包
- isMutable + setValue 通过反射改值

## 输入

一行，三个字段 `书名 单价 库存`，单个空格分隔。

**数据范围**：书名只含小写字母且长度 1..10；1 ≤ 单价 ≤ 1000；0 ≤ 库存 ≤ 1000

## 输出

四行：`members=<成员名按 ASCII 升序排列，用半角逗号连接>`、`title=<书名>`、`stock=<读到的库存>`、`stock2=<通过反射把库存加一后的值>`。

## 样例

**样例 1**

```
输入：
cj 30 4
输出：
members=price,stock,title
title=cj
stock=4
stock2=5
```

**样例 2**

```
输入：
abc 1 0
输出：
members=price,stock,title
title=abc
stock=0
stock2=1
```

## 提示

`ClassTypeInfo.of(对象)` 拿到类型信息，`instanceVariables` 只有本类声明的 public 成员，而且**遍历顺序不保证稳定** —— 先把成员名收进 `ArrayList<String>` 再 `sort`，输出才确定。按名字取成员用 `getInstanceVariable("名字")`；`getValue(对象)` 返回 `Any`，用 `as 类型` 转成 Option 再 `getOrThrow()`；写值之前先 `isMutable()` 判断。
