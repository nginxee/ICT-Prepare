# B5-D · ★ 计算器工厂

**关卡**：B5 · 函数基础  ★挑战
**对应博客**：《跟我一起学“仓颉”编程语言》第 10·11·12 篇
**提交文件**：`answers/B5-D.cj`

> 定义三个一元整数运算函数，再写一个「运算选择器」把选中的函数返回出来，用它反复作用在输入上；同时演示函数内部局部变量遮蔽同名全局常量的效果。

## 知识点

- 函数作为返回值（函数类型）
- 函数作为参数传递
- 全局常量与局部变量同名时的遮蔽
- 递归求和
- 多函数协作与综合输出

## 输入

一行，三个整数 x op times（单个空格分隔）：op 取 0、1、2 分别代表「加一」「乘三」「取负」三种运算。

**数据范围**：-100 ≤ x ≤ 100；0 ≤ op ≤ 2；1 ≤ times ≤ 5

## 输出

六行：`once=<选中的运算对 x 作用一次的结果>`、`repeat=<选中的运算对 x 连续作用 times 次的结果>`、`shadow=<调用「遮蔽演示」函数算出的值，该函数内部用同名局部变量遮蔽了全局常量，结果等于 x 加该局部变量的值>`、`global=<全局常量的值>`、`sumTo=<1 到 times 的递归求和结果>`、`final=<repeat 的值 + shadow 的值 + 全局常量的值 + sumTo 的值>`。全局常量的值固定为 100，函数内部用来遮蔽它的局部变量的值固定为 7。

## 样例

**样例 1**

```
输入：
5 0 3
输出：
once=6
repeat=8
shadow=12
global=100
sumTo=6
final=126
```

**样例 2**

```
输入：
-4 1 2
输出：
once=-12
repeat=-36
shadow=3
global=100
sumTo=3
final=70
```

**样例 3**

```
输入：
9 2 4
输出：
once=-9
repeat=9
shadow=16
global=100
sumTo=10
final=135
```

## 提示

函数的类型写成 `(参数类型, ...) -> 返回类型`。顶层函数的名字本身就是一个该类型的表达式，可以直接 `return` 出去，也可以当实参传给别的函数。注意名字重载过会有歧义，此时要给变量写显式类型标注。内层作用域里声明的变量可以和外层的同名，内层的会遮住外层的，离开内层后外层变量照旧。
