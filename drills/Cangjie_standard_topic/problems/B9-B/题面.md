# B9-B · 账户封装与 mut prop

**关卡**：B9 · 类与封装
**对应博客**：《跟我一起学“仓颉”编程语言》第 18·21 篇
**提交文件**：`answers/B9-B.cj`

> 用私有余额字段封装一个账户，对外只通过 mut prop 属性读写；余额不允许为负，越界操作被拒绝。

## 知识点

- private 私有成员
- mut prop 属性的 get/set
- 在方法里维护不变量
- 通过属性读写私有字段

## 输入

第一行一个整数 `初始余额`；第二行一个整数 m；接下来 m 行，每行一个整数 n（正数表示存入，负数表示取出，0 表示空操作）。

**数据范围**：0 ≤ 初始余额 ≤ 1000000；1 ≤ m ≤ 100；-1000000 ≤ n ≤ 1000000

## 输出

m 行，每行 `ok balance=<余额>` 或 `fail balance=<余额>`；余额不足时操作失败，余额保持原值。

## 样例

**样例 1**

```
输入：
100
3
50
-30
-500
输出：
ok balance=150
ok balance=120
fail balance=120
```

**样例 2**

```
输入：
0
2
-1
7
输出：
fail balance=0
ok balance=7
```

## 提示

余额字段声明成 `private`，外部只能通过 `mut prop` 的 get/set 访问；在方法里先判断改完会不会变成负数，会就返回失败。
