# B20-B · 原子计数器

**关卡**：B20 · 并发
**对应博客**：《跟我一起学“仓颉”编程语言》第 60·61·62·63·64·65·66·67·68·69·70 篇
**提交文件**：`answers/B20-B.cj`

> k 个线程各自对同一个原子计数器自增 n 次，并记录每次拿到的旧值。

## 知识点

- AtomicInt64 原子类型
- fetchAdd 返回旧值
- 多线程并发累加不丢更新
- 用结果校验和验证原子性

## 输入

一行两个整数 n k，单个空格分隔。

**数据范围**：1 ≤ n ≤ 5000；1 ≤ k ≤ 8；保证 n × k ≤ 40000

## 输出

三行：`final=<计数器最终值>`、`checksum=<所有线程拿到的旧值之和>`、`threads=<线程数>`。必须等全部线程结束后再输出。

## 样例

**样例 1**

```
输入：
3 2
输出：
final=6
checksum=15
threads=2
```

**样例 2**

```
输入：
1 1
输出：
final=1
checksum=0
threads=1
```

## 提示

`fetchAdd(1)` 返回的是**加之前**的旧值；每个线程把旧值累加起来作为线程结果，主线程 `get()` 收齐后再相加。
