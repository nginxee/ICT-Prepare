# B21-C · TCP 回显服务

**关卡**：B21 · 网络编程
**对应博客**：《跟我一起学“仓颉”编程语言》第 78·79·80·81·82 篇
**提交文件**：`answers/B21-C.cj`

> 在同一个进程里：服务端线程接受一条 TCP 连接，把收到的文本回发成 `ACK:<文本>`；客户端连接后发送读入的文本并读回回复。

## 知识点

- TcpServerSocket 构造（bindAt）与 bind
- accept 接受连接
- TcpSocket 构造与 connect 连接服务端
- read / write 收发字节
- close 关闭套接字
- spawn + get 保证输出顺序

## 输入

一行文本，只含 ASCII 小写字母。

**数据范围**：文本只含小写字母，长度 1..20；只用 127.0.0.1；服务端绑定端口 0，由系统分配空闲端口

## 输出

两行：`server_recv=<服务端收到的文本>`、`client_recv=<客户端读到的回复>`。

## 样例

**样例 1**

```
输入：
hi
输出：
server_recv=hi
client_recv=ACK:hi
```

**样例 2**

```
输入：
abc
输出：
server_recv=abc
client_recv=ACK:abc
```

## 提示

服务端用 `TcpServerSocket(bindAt: 0)` 加 `bind()`，`accept()` 会阻塞到有客户端连接为止，所以它和读写都要放进 `spawn` 线程；客户端用 `TcpSocket(地址对象)` 加 `connect()`。收发用 `write(字节数组)` 和 `read(缓冲区)`，`read` 返回读到的字节数，用 `String.fromUtf8` 还原文本。
