# B1-A · 你好，仓颉

**关卡**：B1 · 环境 · 编译 · 输出
**对应博客**：《跟我一起学“仓颉”编程语言》第 01·85 篇
**提交文件**：`answers/B1-A.cj`

> 读入一个名字，输出两行问候语。

## 知识点

- main 入口
- println 输出
- readln 读入一行
- 字符串插值 ${}

## 输入

一行，一个名字（只含小写字母，长度 1..20）。

**数据范围**：名字只含小写字母，长度 1..20

## 输出

第一行：`你好, <名字>!`；第二行：`欢迎来到仓颉世界`。

## 样例

**样例 1**

```
输入：
tom
输出：
你好, tom!
欢迎来到仓颉世界
```

**样例 2**

```
输入：
cangjie
输出：
你好, cangjie!
欢迎来到仓颉世界
```

## 提示

`let name = getStdIn().readln().getOrThrow()` 拿到输入；插值写成 `"你好, ${name}!"`。
