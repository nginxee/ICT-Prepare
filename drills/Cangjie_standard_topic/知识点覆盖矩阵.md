## 每题的考察点（由 spec 汇总）

### B1 · 环境 · 编译 · 输出

- `B1-A` 你好，仓颉：main 入口、println 输出、readln 读入一行、字符串插值 ${}
- `B1-B` 信息卡片：多次 println、字符串插值、固定文本与输入的拼接
- `B1-C` ★ 三行清单：连续多行读入、输出格式逐字符对齐、把固定值写进输出

### B2 · 变量与基本数据类型

- `B2-A` 整数族与声明：let 与 var 的区别、Int64 声明与解析、整数运算、多行输出
- `B2-B` 元组交换与区间长度：元组类型、元组解构/交换、区间类型 1..=n、整数计算
- `B2-C` 字符与字符串统计：String 类型、Rune 与字符数（toRuneArray）、UTF-8 字节数（size）、大小写转换
- `B2-D` ★ 类型转换擂台：Int64/Float64 显式转换、截断而非四舍五入、Bool.tryParse、浮点格式化

### B3 · 操作符与表达式

- `B3-A` 算术与整除取余：算术操作符 + - * /、整数除法向零截断、取模 % 的符号规则、多行输出
- `B3-B` 关系判断与逻辑运算：关系操作符 == != < <= > >=、逻辑操作符 ! && ||、短路求值、Bool 值的输出
- `B3-C` 位运算与字节打包：按位与 &、按位或 |、按位异或 ^、按位取反 !、左移 << 与右移 >>、移位与或运算的优先级
- `B3-D` ★ 表达式求值台：运算符优先级与结合性、复合赋值操作符、整除与取余、位运算与逻辑运算混合、Int64 与 Float64 的显式转换、浮点格式化输出

### B4 · 流程控制

- `B4-A` 成绩等级：if/else if/else 多分支、分支顺序与区间判定、边界值处理、Bool 变量的输出
- `B4-B` 冰雹序列：while 循环、循环内分支判断、累加器计数、边扫边求最大值、退化输入
- `B4-C` 对折到超过：do-while 循环、循环体至少执行一次、末尾判断条件、与 while 的区别
- `B4-D` 区间里找倍数：for-in 遍历闭区间 ..=、break 提前退出、continue 跳过本次迭代、累加器统计个数与总和、找不到时的退化输出
- `B4-E` ★ 数字三角与乘法表：嵌套 for-in 循环、外层控行内层控列、行尾不留多余空格、跨循环累加器、while 循环与阈值判断、输出格式逐字符对齐

### B5 · 函数基础

- `B5-A` 三个小函数：func 定义与参数列表、声明返回类型、函数调用与返回值参与运算、函数体最后一个表达式作为返回值
- `B5-B` 重载与默认参数：函数重载（同名不同参数列表）、命名参数、命名参数的默认值、调用时按名称覆盖默认值
- `B5-C` 递归三连：递归函数、递归终止条件、递归调用自身、递归求最大公约数、把递归结果作为返回值
- `B5-D` ★ 计算器工厂：函数作为返回值（函数类型）、函数作为参数传递、全局常量与局部变量同名时的遮蔽、递归求和、多函数协作与综合输出

### B6 · 结构体 struct

- `B6-A` 矩形信息卡：struct 定义、自定义构造函数、成员访问 this.字段、成员函数
- `B6-B` 值语义：副本互不影响：struct 是值类型（赋值即拷贝）、mut 函数修改 var 字段、let 变量不能调用 mut 函数、let 字段不可修改
- `B6-C` 静态成员：入库台账：静态常量 static let、静态变量 static var、静态函数 static func、通过类型名访问静态成员
- `B6-D` ★ 全班加分统计：struct 定义与构造函数、let 字段与 var 字段的区别、mut 函数修改字段、静态成员做全班共享统计、静态函数汇报、成员函数与条件判断

### B7 · 包与导入

- `B7-A` 包声明与整体导入：package 声明写在文件第一行、整体导入 import 包名.*、使用标准库子包 std.env 与 std.convert、顶层函数的 public 修饰符
- `B7-B` 成员导入：只引入要用的：成员导入 import 包名.成员名、成员导入与整体导入混用、使用 std.math 的 sqrt、Float64.parse 与小数格式化
- `B7-C` ★ 别名导入与多成员导入：别名导入 import 包名.成员名 as 别名、花括号多成员导入 import 包名.{a, b}、多个标准库子包协作、综合：读入、计算、格式化输出

### B8 · 标准库基础（随机/数学/格式化/字符串）

- `B8-A` 数学函数小测：std.math 的 ceil / floor / round / sqrt / abs、Float64.getPI() 取圆周率、std.convert 的 format 控制小数位数、Float64.parse 解析小数
- `B8-B` 固定种子的随机数：std.random 的 Random 类型、固定种子保证结果可复现、nextInt64(upper) 的左闭右开区间、最值与平均值统计、浮点格式化
- `B8-C` 字符串体检：String.size 是 UTF-8 字节数、toRuneArray().size 是字符数、count 统计子串出现次数、indexOf 返回 Option 且下标按字节计、replace 批量替换、trim 去首尾空白（std.unicode）
- `B8-D` ★ 随机加分成绩报表：Random 固定种子生成加分、StringBuilder 拼接与补位、String.size 数字符、format 保留小数、abs 求差的绝对值、等级判断与最值统计

### B9 · 类与封装

- `B9-A` 计数器对象：class 定义、init 构造函数、成员变量 let 与 var、this 引用成员、成员函数
- `B9-B` 账户封装与 mut prop：private 私有成员、mut prop 属性的 get/set、在方法里维护不变量、通过属性读写私有字段
- `B9-C` 静态成员与自动编号：static let 静态常量、static var 静态变量、static func 静态方法、在构造函数里更新静态状态
- `B9-D` ★ 成绩册：class + init + this 综合、private 字段与 mut prop 属性、static let / static func 静态成员、ArrayList 存放自定义类对象、跨类调用静态方法、用方法把遍历与统计封装起来

### B10 · 继承与多态

- `B10-A` 父类与子类：open class 定义可继承的父类、<: 继承、init 中调用 super(...)、override 重写方法、this 访问继承来的成员
- `B10-B` 向上转型与多态：子类对象赋给父类引用（向上转型）、父类引用调用被重写的方法、ArrayList<父类> 存放不同子类对象、遍历时的动态绑定
- `B10-C` 向下转型与类型判断：is 判断运行时类型、as 向下转型并得到 Option、getOrThrow 取出转换结果、在父类引用上访问子类特有成员
- `B10-D` ★ 薪资结算：open class + <: + override + super 综合、向上转型后统一结算（多态）、在重写中调用 super.slip() 复用父类逻辑、is / as 向下转型做分类统计、组合：Team 持有 ArrayList<Employee>

### B11 · 抽象类与接口

- `B11-A` 抽象类与抽象成员：abstract class 声明、只有签名没有函数体的抽象成员、子类必须 override 实现抽象成员、抽象类里已经写好的具体方法、通过抽象类引用调用多态
- `B11-B` 接口的默认实现：interface 声明与成员方法、接口方法的默认实现（带函数体）、实现类不写就用默认版本、实现类覆盖默认实现、接口引用调用多态方法
- `B11-C` 多接口与接口参数：一个类用 & 同时实现多个接口、把接口类型写成函数参数类型、同一个对象传给不同接口参数、接口的默认实现调用接口自己的方法
- `B11-D` ★ 含税价结算：abstract class 同时实现多个接口、抽象成员与接口成员的对应关系、接口默认实现里的整数计算、抽象类引用调用接口方法（多态）、接口作为函数参数、ArrayList 存放抽象类对象

### B12 · 枚举与 Option

- `B12-A` 信号灯枚举：enum 定义、无参枚举构造器、match 与枚举、枚举的穷尽匹配
- `B12-B` 带参数的图形枚举：带参数的枚举构造器、match 解构枚举的负载、枚举与元组返回值的配合
- `B12-C` 可能没有昵称：Option<T> / ?T、Some 与 None、?T 的构造、match 取 Option、?. 安全访问、?? 提供默认值、isSome()
- `B12-D` ★ 学生成绩册：枚举与 Option 综合、tryParse 得到 ?Int64、isNone() 与 getOrThrow()、枚举的穷尽 match、HashMap 取值得到 ?Level、缺失字段的处理

### B13 · 模式匹配

- `B13-A` 字符分诊台：match 表达式、常量模式、用 | 合并多个常量、绑定模式 + where 守卫、通配符模式 _
