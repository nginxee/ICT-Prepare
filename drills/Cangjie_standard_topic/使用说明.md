# 仓颉语言编程基础题 · 使用说明

> 按《跟我一起学“仓颉”编程语言》85 篇的知识点分 **23 个关卡**，每题只考一个知识点大类，难度以**基础掌握**为主，每关最后一题是 ★挑战。
> 判题机制、脚本与题目结构和隔壁 `drills\DSA_Advanced_topic\` 完全一致 —— 会用那个就会用这个。

---

## 1. 日常流程（双击就行）

1. **双击 `自助判题.cmd`**
2. 提示出现后，**输入关卡号，回车**（例如 `4`）
3. 它会自动做两件事：
   - **先同步草稿**：把 `answers\default\src\*.cj` 复制到 `answers\`
   - **再判题**
4. 判完会再次提示，可以继续输入；**直接回车 = 退出**

```
请输入关卡号或题号 如 4（第4关下所有题）,B4-C（单题）,a选中全部 直接回车退出 > 4
```

### 可以输入什么

| 输入 | 作用 |
|---|---|
| `4` | 判第 4 关全部题目 |
| `B4-C` | 只判单题 |
| `a` | 判**全部**题目（慢，约 2–3 分钟，适合总检查） |
| 直接回车 | 退出 |

## 2. 目录

```
drills\Cangjie_standard_topic\
├─ 自助判题.cmd          ← 双击这个
├─ judge.ps1             ← 判题脚本本体（纯 ASCII 源码，见第 6 节）
├─ messages.json         ← 所有中文提示（UTF-8，由脚本显式解码）
├─ 使用说明.md            ← 本文件
├─ 知识点覆盖矩阵.md       ← 85 篇博客 → 关卡 的对应表
├─ problems\             ← 题库（不要改）
│  ├─ INDEX.md           ← 题目总表
│  └─ B1-A\              题面.md + in\ + out\
└─ answers\
   ├─ default\src\       ← ★ 你写代码的地方
   └─ B*.cj              ← 判题时自动从 default\src 同步过来
```

**你只需要在 `answers\default\src\` 里写 `.cj`，文件名 = 题号**（如 `B4-C.cj`）。
判题前会自动同步，不用手动拷贝。

## 3. 命令行方式（可选）

```
自助判题.cmd -Level 4
自助判题.cmd -Problem B4-C
自助判题.cmd -Problem B4-C -ShowInput
```

带参数时**不会** `pause`（方便脚本调用）；双击（无参数）才暂停等你看结果。

**交叉测试**：判题不检查题号与文件名是否匹配，可以把任一解法喂给任一题的数据：

```
自助判题.cmd -Problem B6-A -Source answers\default\src\B5-B.cj
```

## 4. 判题说明

- 单用例**上限 5 秒**，超时判 `超时`
- 只比较 stdout，忽略每行行尾空格和末尾空行
- 编译**警告**会显示但**不影响判分**
- 只告诉你「输入 / 期望输出 / 你的输出」+ 差异表，**不给参考实现**
- **特殊题型**：`problems\B22-C\`（宏包）是**只判编译**的题目 —— 答案文件能被 `cjc --compile-macro` 编译通过即算完成，不需要输入输出。脚本通过题目目录里的 `mode.txt` / `flags.txt` 识别这类题。

## 6. 编码上的几个坑（都已处理，别去"修"）

| 坑 | 处理方式 |
|---|---|
| `cmd.exe` 按 **OEM 代码页(936)** 读 `.cmd`，UTF-8 中文会被当命令执行 | `自助判题.cmd` 保持**纯 ASCII**，中文全在 `messages.json` |
| PowerShell 5.1 按 **ANSI 代码页** 读无 BOM 的 `.ps1`，UTF-8 中文会变成语法错误 | `judge.ps1` 同样保持**纯 ASCII** |
| `cjc` 的诊断信息用 **ANSI 代码页** 输出 | 脚本显式按 ANSI 解码，所以中文路径不乱码 |
| `chcp 65001` 会让 `[Console]::ReadLine()` 立即返回 EOF | **不要**在 `自助判题.cmd` 里加 `chcp`，交互提示会直接失效 |
| 测试输入文件带上 BOM 会让第一行多个字符，`Int64.parse` 当场抛异常 | 题库自带的 `in\*.txt` 都是**无 BOM** 的；你自己造数据时别用会写 BOM 的保存方式 |

> 一句话：**`judge.ps1` / `自助判题.cmd` 里不要出现任何非 ASCII 字符。** 要改提示文案，改 `messages.json`（UTF-8）。

## 7. 题库是怎么做出来的（可追责）

- **题库里没有任何答案**：`answers\` 初始是空的（只有 `default\src\.gitkeep` 和 README），**每一题的解法都由你自己写**。判题只给「输入 ↔ 期望输出」，不给参考实现。
- 题目**逐题**由参考实现生成测试数据，并**逐题核验**：
  1. 参考实现在本机 `cjc 1.0.5` 上必须编译通过 + 运行退出码 0；
  2. 题面里手写的样例期望输出必须与参考实现逐字符一致（对不上直接报错）；
  3. 每个用例的期望输出由参考实现产出，且用真实判题脚本回放验证过。
- 按照本仓库的规矩，**参考实现不入库、也不留在盘上**：题库里只有 `题面.md` + `in\` + `out\`，没有任何解法代码；`answers\` 在交付时是空的。
- 覆盖范围：博客 85 篇全部有对应关卡（见 `知识点覆盖矩阵.md`）；其中 12 篇「仅决赛才考」的内容（异常处理、宏、反射注解、C 互操作）放在 B19 / B22，属于**赛后线**，赛前可以先跳过。

## 8. 做题时最容易踩的 API（都是本机 cjc 1.0.5 实测，不是抄文档）

| 想干什么 | 写法 | 坑 |
|---|---|---|
| 读一行 | `getStdIn().readln().getOrThrow()`（需 `import std.env.*`） | 顶层 `readln()` 返回的是 **String**，EOF 时给 `""`，且**没有** `getOrThrow`；`getStdIn().readln()` 才返回 `?String`（EOF 为 `None`） |
| 读到 EOF | `var c = getStdIn().readln()` + `while (c.isSome()) { ... }` | `readln()` 返回 `?String` 时**空行是 `Some("")`**，和 `None` 不是一回事 |
| 解包 `?String` 三选一 | ① 这行**必须存在** → `.getOrThrow()`；② **可能读到末尾**（多组数据）→ `while (isSome())`；③ **真可选**字段 → `?? 默认值` | `?? ""` 把 `None` 悄悄变成空串：题目数据合法时**不影响判分**，但跨题交叉测试（把 A 题解法喂给 B 题数据）或输入被截断时，报错会指向 `Int64.parse` 那一行，而不是真正缺失的输入 —— 查错方向会歪 |
| 数字解析 | `Int64.parse(s)` / `Int64.tryParse(s)` | `parse` 不宽容空白与 `+`；失败抛异常 |
| 浮点输出 | `f.format(".2")`（需 `import std.convert.*`） | **`f.format(".2f")` 会抛异常**（1.0.5 只有 `f/F` 说明符是坏的）；`String` 没有 `format` 成员 |
| 整数补零 | `n.format("03")` → `007`、`-07` | — |
| 舍入 | `round()` / `format` 是**四舍六入五取偶** | `round(2.5)=2.0`、`0.125.format(".2")` 得 `0.12` —— 别自己实现四舍五入去对答案 |
| 哈希表 | `m.add(k, v)` 或 `m[k] = v`；`m.get(k): ?V`；`m.contains(k)` | **没有** `put` / `containsKey`；遍历顺序不稳定 → 输出前必须排序或按键取值 |
| 集合追加 | `list.add(x)` | **不是** `append` |
| 字符串 | `s.size` 是**字节数**，字符数用 `s.toRuneArray().size`；`s.trimAscii()` | 没有 `trim()`（`trim()` 要 `import std.unicode.*`）；没有 `substring`，用切片 `s[0..5]` |
| 数组切片 | `arr.slice(start, len)` | 第二个参数是**长度**，不是结束下标 |
| 数学 | `Float64.getPI()`、`abs/sqrt/ceil/floor/round`（`import std.math.*`） | `getPI` 不是自由函数；`std.math` **没有** `max`/`min`，要手写比较 |
| 随机 | `Random(UInt64(seed))` | 种子类型是 `UInt64`；不固定种子就没有确定输出（题库里的随机题**都固定了种子**，且序列与 SDK 版本有关） |
| 并发 | 共享可变状态**放进类字段**；`spawn { ... }` → `Future`，`get()` 收齐后再打印 | `spawn` 的 lambda **不能捕获可变局部变量**（报 `lambda capturing mutable variables`） |
| 结构体/类 | `mut func` 只能改 `var` 字段；`let` 变量不能调 `mut func` | 值类型赋值即拷贝，改副本不影响原值 |
| 泛型扩展 | `extend<T> Box<T> where T <: ToString` | 少了 `<T>` 会报 `unexpected 'where'`；接口扩展里实现的成员必须显式 `public` |
| 接口/继承 | `class C <: Base & I1 & I2`；`e as T` 返回 `Option<T>` | 接口必须显式写在继承列表里（没有结构化类型）；`open`/`override`/实现接口的成员都要写 `public` |
| 宏 | 宏必须在 `macro package` 里，用 `cjc --compile-macro` 编译 | `--compile-macro` **不能**和 `-o` 同时用（B22-D 就是这类题，判题只判能否编译） |
| 枚举 | `enum E { A \| B \| C }`；换行写时**每行都要以 `\|` 开头** | `enum E {\n Red\n Yellow\n}` 报 `expected declaration` |
| match 穷尽性 | 枚举**不需要** `case _`；`open class` 层级的 match **必须**有 `case _` | 报 `non-exhaustive patterns ... _ is not covered` |
| `as` 转换 | 只用于**类/接口层级**的安全向下转型：`e as T` → `Option<T>` | ⚠️ `let f = a as Float64`（a 是 Int64）**能编译但恒为 `None`** —— 数值转换必须写 `Float64(a)` |
| 闭包 | 捕获局部 `let` 的闭包可以返回/逃逸 | 捕获局部 **`var`** 的闭包**不能逃逸**（报 `lambda capturing mutable variables needs to be called directly`），只能立即调用 |
