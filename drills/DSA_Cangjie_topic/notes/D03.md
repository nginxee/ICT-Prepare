# D3 · 栈

> 4 个单元，每个单元三段：**学术**（定义/不变量/为什么对）→ **实操**（仓颉写法/边界/实测）→ **建议**（做完对应题目再看）。
> 仓颉标准库**没有** `Stack`：本关统一的载体是 `ArrayList` 的尾部 —— `add` 入栈、`size-1` 看栈顶、`remove(at: size-1)` 出栈。

## 3.1 括号匹配（D3-A）

### 学术

- 定义：括号序列合法 ⇔ 任意前缀中"未闭合左括号数"≥ 0，且扫描结束时为 0（三种括号分别满足、且需类型匹配）
- 栈不变量：扫描到位置 i 时，栈内容 = 尚未闭合的左括号，自栈底到栈顶按出现顺序排列
- 三类失败互斥且穷尽：右括号多余（`close`）、与最近的未闭合左括号类型不符（`mismatch`）、扫完仍有未闭合（`open`，取最靠左者）
- 报"第一个"错误：前缀性质一旦被破坏，后续字符无法把它修复成合法序列
- 复杂度：时间 Θ(|s|)，空间最坏 Θ(|s|)（全左括号、嵌套到 10⁵ 层）

### 实操（仓颉）

- 栈用 `ArrayList<Int64>` 存**下标**：`list.add(i)` 入栈、`list[list.size-1]` 看栈顶、`list.remove(at: list.size-1)` 出栈
- 字符遍历用 `s.toRuneArray()` 得到 `Array<Rune>`，再与字面量 `r'('` / `r')'` 比较；`String.size` 是字节数
- 报 `open` 的位置取 `list[0]`（栈底 = 最早未闭合），不是栈顶
- 实测：|s|=2×10⁵、嵌套 99999 层的用例 05 约 95 ms

### 建议（做完 D3-A 之后看）

- 适用：一切"嵌套/回退"结构（括号、标签、代码块）；不适用：求"最长合法子串"（要在栈里存失败位置）
- 最高频错法：先判类型再判空（空栈取栈顶直接崩）；`open` 报栈顶而不是栈底
- 自检：`(`、`)`、`([)]`、`([])` 四个输入，答案应依次为 `open`、`close`、`mismatch`、`OK`

## 3.2 后缀表达式求值（D3-B）

### 学术

- RPN 与表达式树的后序遍历一一对应：求值 = "叶子压栈、内部结点弹出两个子树值算完压回"
- 归纳不变量：读完任意合法前缀后，栈内保存的是该前缀拆出的所有子表达式的值，自底向上按从左到右排列
- 合法 RPN 满足 操作数 = 运算符 + 1，所以 token 数恒为奇数（这就是本题上界只能取到 199999 的原因）
- 非交换运算有方向：**先弹出的是右操作数 b，后弹出的是左操作数 a**，减法、除法必须写 `a−b`、`a/b`
- 复杂度 Θ(token 数)，栈深不超过操作数个数

### 实操（仓颉）

- `line.trimAscii().split(" ")` 一次切完 2×10⁵ 个 token，`Int64.parse` 直接接受 `-9` 这种带负号的写法
- 除法 `/` 已是向零截断（`-9/2 = -4`），不要再自己 floor
- 弹栈前判 `st.size >= 2`；扫完后栈里应恰好剩 1 个元素
- 实测：199999 个 token、中间值到 10¹⁸ 的用例 05 约 120 ms

### 建议（做完 D3-B 之后看）

- 适用：已给 RPN，或需要"无括号、单趟求值"的场合；不适用：要保留表达式结构/要求值过程可视化时
- 最高频错法：a、b 顺序弄反（减法除法立刻错）；用 32 位整型接 10¹⁸ 的中间结果
- 自检：`-9 2 /` 必须是 `-4`（不是 -5）；`5` 这种单 token 必须输出 `5`

## 3.3 下一个更大元素（D3-C）

### 学术

- 目标：对每个 i 求最小的 j > i 使 aⱼ > aᵢ；**严格大于**，相等不算
- 单调栈不变量：从右往左扫，栈内下标的值自栈底向栈顶单调不增，栈顶即"离 i 最近的候选"
- 正确性（弹出规则）：凡 `a[top] ≤ a[i]` 的候选，对 i 左侧任何位置而言 i 都更近且值不更小，故可永久弹出
- 每个下标最多入栈一次、出栈一次 ⇒ 总 Θ(n)，不会因为内层 while 退化成 O(n²)
- 空间 Θ(n)

### 实操（仓颉）

- 栈存**下标**（`ArrayList<Int64>`），答案数组 `Array<Int64>(n, repeat: -1)`
- 弹栈条件写 `a[st[st.size-1]] <= a[i]`（`<=` 而不是 `<`），否则相等的元素会被当成答案
- 从右往左用 `while (i >= 0)`；别写成 `for (i in 0..n)` 从左扫
- 实测：n=2×10⁵ 的用例 05 约 230 ms

### 建议（做完 D3-C 之后看）

- 适用：一趟扫描求"最近更大/更小"；变形（下一个更小、左右两侧更大）只改比较符与扫描方向
- 最高频错法：比较符写成 `<`（相等被当作更大）；栈里存值不存下标（无法输出位置）
- 自检：全相同、严格递减、严格递增三种输入各跑一次，答案应分别全 `-1`、全 `-1`、`2 3 … n −1`

## 3.4 四则运算求值（D3-D）

### 学术

- 算符优先文法 + 左结合：优先级 `* /` = 2、`+ -` = 1、`(` = 0
- 不变量：运算符栈自底向上优先级严格递增（`(` 最小）；**入栈前必须把栈顶所有 ≥ 当前优先级者先算掉**，同级也要算，这才是左结合
- 遇 `)` 连续算到 `(` 为止再弹掉 `(`；扫完后按栈序算完 —— 等价于对表达式树做一次自底向上求值
- 复杂度 Θ(|s|)：每个运算符、每个数字各入栈/出栈常数次；深嵌套不影响复杂度（只影响栈深）

### 实操（仓颉）

- 两个 `ArrayList<Int64>`：数字栈 + 运算符栈（用 1..4 编码 `+ - * /`，0 编码 `(`）
- 多位数要连续扫到非数字再 `Int64.parse(s[start..i])`（String 切片接受 Int64 下标，ASCII 下即字节切片）
- 判数字用 `c >= r'0' && c <= r'9'`；输入可能长达 2×10⁵ 字符，只 `readln()` 一次
- 实测：|s|=2×10⁵、括号嵌套 5 万层的用例 05 约 110 ms

### 建议（做完 D3-D 之后看）

- 适用：整数四则表达式；不适用：一元负号、浮点、乘方（本题数据已排除，遇到要另加规则）
- 最高频错法：同级用 `>` 而不是 `>=` 判弹出（`12-3-4` 会算成 11）；`)` 弹到空而不是弹到 `(`；减法/除法两操作数颠倒
- 自检：`12-3-4` 应 5、`8/2/2` 应 2、`(1+2)*(3-4)` 应 -3，三条各跑一次
