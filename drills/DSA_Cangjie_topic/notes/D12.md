# D12 · 二叉树

> 4 个单元，每个单元三段：**学术**（定义/不变量/为什么对）→ **实操**（仓颉写法/边界/实测）→ **建议**（做完对应题目再看）。
> 全关统一约定：**1 基数组表示** —— 根在下标 1，`i` 的左孩子 `2i`、右孩子 `2i+1`、父亲 `i/2`，`0` 表示空节点。

## 12.1 数组建树与遍历（D12-A）

### 学术

- 完全二叉树的数组表示：根 1，左 `2i`，右 `2i+1`，父亲 `i/2`；这是"把树的高度关系编码成算术关系"，不需要任何指针
- 三种遍历只差"访问根"的时机：前序在两次递归之前、中序在中间、后序在之后；三者是同一骨架的三种线性化
- 数组表示的树高 ≤ `⌊log₂n⌋ + 1`（下标为 `i` 的节点层号就是 `⌊log₂i⌋+1`），n = 10⁵ 时不到 20 层，递归深度天然安全
- 空节点的判据有**两条**：`i > n`（下标越界）或 `a[i] = 0`（显式空标记），缺任何一条都会把空位当节点或直接越界
- 正确性依据：遍历是对"树"这一递归定义的直接归纳 —— 处理根 + 递归处理两棵子树，覆盖且只覆盖所有非空节点

### 实操（仓颉）

- 访问写 `a[i - 1]`：数组本身 0 基，树下标 1 基，`-1` 只在这一处出现
- 递归入口统一写成 `walk(a, n, i)`，函数第一行就是两条空判据，之后才取值
- 三条序列各用一个 `ArrayList<Int64>` 收，最后 `StringBuilder` 拼一行，避免行尾空格
- 空树（`a₁ = 0`）时三条序列都空，三行都输出 `empty`
- 实测：n=10⁵ 的 05 用例在 judge 里约 161 ms

### 建议（做完 D12-A 之后看）

- 别假设"非空值紧凑排列"：`a₄` 非空而 `a₃` 为空完全合法（`a₄` 是 `a₂` 的孩子）
- 三种遍历不要写三份代码：一个 `walk` 里调换 append/递归的顺序即可，改错的风险全在三份代码之间不同步
- 自检动作：`a = [1, 0, 3]` 时 3 是根的**右**孩子，前序必须是 `1 3`，不是 `1 3` 走左链

## 12.2 层序与层最大值（D12-B）

### 学术

- BFS 分层的标准技巧：每轮开始时记下"当前队列长度 − head"，就是本层节点数，再正好弹这么多
- 层序 = 按层号升序、层内按下标升序；在数组表示下这两个顺序恰好一致，所以也可以直接按下标扫，但队列写法对任意树都成立
- 层数 = 最深非空节点的层号，**不等于** `⌊log₂n⌋ + 1`：有空洞时 n 很大而真实层数很浅（斜链是极端例子）
- 空节点不入队，于是"本层节点数"天然等于真实节点数，空洞不会污染统计
- 复杂度 Θ(n)：每个非空节点入队一次、出队一次

### 实操（仓颉）

- 仓颉没有 `Queue`：用 `ArrayList<Int64>` 只 `add` 到尾部 + `head` 指针从头读，`q.size - head` 就是当前层宽度
- 队列里存**下标**而不是值，出队后才能算 `2i`、`2i+1`
- 入队前先判 `left <= n && a[left-1] != 0`，保证队列里永远只有真实节点
- 空树先兜底：输出 `empty` 与 `levels=0` 后直接返回
- 实测：n=10⁵ 的 05 用例在 judge 里约 190 ms

### 建议（做完 D12-B 之后看）

- `remove(at: 0)` 是 O(n)，套进 BFS 就退化成 O(n²)；头指针只前进，队列只增不减
- 最高频错法：把本层节点数当成满二叉树宽度 `2^(k-1)` —— 有空洞时（样例 3 的第 5 层）立刻错
- 自检动作：n = 31 的左斜链（下标 1,2,4,8,16）必须输出 `levels=5` 且每层 1 个节点

## 12.3 树高与叶子数（D12-C）

### 学术

- 递归定义：空树 `h = 0`；非空 `h(i) = 1 + max(h(2i), h(2i+1))`；根自己那颗节点也算一层，所以单节点树高为 1
- 叶子 = **左右孩子都为空**的非空节点；单节点树里根自己既是根又是叶子
- 空树要单独兜住：`h = 0`、叶子 0、叶子和 0；否则递归会把空位当节点、返回 1 层
- 叶子和的量级：n = 10⁵ 的满树约 5×10⁴ 个叶子，每个值可到 10⁶，总和约 5×10¹⁰，必须 Int64
- 复杂度 Θ(n)（每个节点常数次操作），递归深度 ≤ 树高

### 实操（仓颉）

- 求高单独一个递归函数 `height(a, n, i)`，前两行就是"越界 / 空节点 → 返回 0"
- 叶子统计再走一趟递归，累加器用 `Array<Int64>(2, repeat: 0)`：数组是引用类型，能当"带 out 参数"用
- 孩子是否存在写成 `2*i <= n && a[2*i - 1] != 0`（右孩子把 `2i` 换成 `2i+1`），两条都要判
- 实测：n=10⁵ 的 05 用例在 judge 里约 125 ms

### 建议（做完 D12-C 之后看）

- 最高频错法：用 `i > n/2` 判叶子 —— 那是满归满二叉树的性质，有空洞时会把带孩子的节点算成叶子
- 另一个错法：空树不特判，返回 `height=1`、`leaves=1`
- 自检动作：`n=1, a=[42]` 必须是 `1/1/42`；`n=1, a=[0]` 必须是 `0/0/0`

## 12.4 BST 判定与查找（D12-D）

### 学术

- **BST ⇔ 中序遍历序列严格递增**（这是充要条件）。中序有序意味着"所有左子树值 < 根 < 所有右子树值"，是全局性质
- "每个节点局部满足左孩子小、右孩子大"既不充分也不必要，必须用中序才是对的
- 严格递增意味着**重复值也判 NO**：BST 要求左子树全小、右子树全大，等值无处安放
- 数组表示下父亲就是 `i/2`，所以"根到某节点的路径"可以一路除 2 还原，不需要额外存父指针
- 中序有序 ⇒ 前驱/后继可以二分：`lower_bound(x)` 得第一个 ≥ x 的位置 p，前驱是 `p-1`、后继是 `p`
- 复杂度 Θ(n) 建中序 + Θ(q log n) 查询

### 实操（仓颉）

- 中序遍历同时收两个平行数组：`vals`（值）与 `idxs`（下标），后者专门用来还原路径
- 判定写成 `if (vals[j] <= vals[j - 1]) { isBst = false }`：用 `<=` 把"重复"也判掉
- 非 BST 时立刻 `println("isBST=NO")` 并 `return`，一行都不多输出
- 路径还原：`var cur = idxs[p]; while (cur >= 1) { path.add(a[cur - 1]); cur = cur / 2 }`，再倒序输出
- 实测：n=2×10⁵、q=2000 的 05 用例在 judge 里约 173 ms

### 建议（做完 D12-D 之后看）

- 自检动作：`[10, 5, 15, 3, 12, 0, 20]` 每对父子都"左小右大"，但中序是 `3 5 12 10 15 20` —— 必须判 `isBST=NO`，且只输出这一行
- 最高频错法：只比较父子 + 忘记判重复值；另一个是把输出写成"未命中就空白"，题目要 `N <前驱> <后继>`，缺位写 `-`
- 路径别用 `ArrayList.insert(0, x)` 从前面插（O(n)），尾插后倒序输出即可
