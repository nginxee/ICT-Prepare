# D9 · 双指针与滑动窗口

> 4 个单元，每个单元三段：**学术**（定义/不变量/为什么对）→ **实操**（仓颉写法/边界/实测）→ **建议**（做完对应题目再看）。
> 本关的两条主线：**相向双指针靠单调性剪枝**，**同向/变长滑窗靠"指针只前进"**。所有错误几乎都来自指针往回走了。

## 9.1 有序两数之和（D9-A）

### 学术

- 单调性剪枝：`a[lo] + a[hi] > t` ⇒ `a[hi]` 与任何 ≥ `a[lo]` 的元素配对都超 t，故 hi 这个位置永久无用
- 于是 lo 只增、hi 只减，每步至少淘汰一个位置，总步数 ≤ n
- 正确性（多解口径）：命中的第一个 lo 就是"存在解的最小 i"；此刻 hi 是所有"和 ≤ t"的最大下标，等式成立即最大 j
- 复杂度 Θ(n)（加读入）；排序不计（输入已有序）

### 实操（仓颉）

- 三行输入：第一行 n、第二行数组、第三行 t；`Array<Int64>(n, repeat: 0)` 不能省
- 循环条件 `while (lo < hi)`（不是 `<=`），否则同一元素会被用两次
- 无解输出小写 `none`；实测 05（n=2×10⁵）121 ms

### 建议（做完 D9-A 之后看）

- 先读题面的多解口径，再决定指针怎么走：要么让算法自然产出该口径，要么在输出前按口径修正，别指望"碰巧一样"
- 最高频错法：`while (lo <= hi)` 让 `i == j` 合法；`-5 + -5` 这种数据会立刻判错
- 一行自检：n=1、全部相同、t 小于最小两数之和 / 大于最大两数之和

## 9.2 原地合并与移除（D9-B）

### 学术

- 归并双指针：每步取较小者追加，归纳可证结果始终非降序；某侧耗尽后整段搬移
- 原地去重的正确性依据是 `write ≤ read` 恒成立（write 只在写入后 +1，且每次最多追上 read），所以写回不会覆盖尚未读取的数据
- 判据必须是"已落盘末值" `c[read] != c[write−1]`；比较对象换成 `c[read−1]` 就会在原数组自带重复时出错
- 复杂度 Θ(n+m)，额外空间 Θ(1)（若允许 O(n+m) 缓冲则更简单，但那就不是原地了）

### 实操（仓颉）

- `Array<Int64>(n + m, repeat: 0)` 一次开好归并结果，接着在同一个数组上做读写指针
- 输出两行：长度单独一行，第二行数字间一个空格、行末不留空格
- 实测 05（两边各 2×10⁵，去重后 3.3×10⁵ 个元素）309 ms

### 建议（做完 D9-B 之后看）

- 别用 `ArrayList.remove(at:)` 循环删重复（O(n²)），也别新建结果容器再 add（能过但不叫原地）
- 最高频错法：先分别对两个数组去重再拼接 —— 漏掉"跨数组相同值"的去重
- 一行自检：两个数组完全相同、两个数组各自自带重复，各跑一次看长度

## 9.3 最长无重复子串（D9-C）

### 学术

- 窗口不变量：当前窗口 `[left, r]` 内字符互不相同；r 每步 +1，一旦破坏不变量就移动 left 恢复
- `last[c]` 记 c 上一次出现的下标；若它落在窗口内，left 应挪到 `last[c] + 1`
- **left 单调更新（abba 陷阱）**：必须写 `left = max(left, last[c] + 1)`。`abba` 扫到第二个 `b` 时 left 已是 3，而 `a` 的上次位置是 1；若直接写 `left = last[a] + 1 = 2`，left 就倒退了，窗口会重新包含重复字符
- r 前进 n 步、left 前进不超过 n 步 ⇒ 均摊 Θ(n)

### 实操（仓颉）

- 字符集是 ASCII 时用 `Array<Int64>(256, repeat: 0)` 当"数组哈希表"：`last[Int64(s[i])]`
- `s.size` 是字节数、`s[i]` 取到 `Byte`；本题用不到 `toRuneArray()`
- 实测 05：|s| = 2×10⁵ 的满规模数据，答案左端点落在后半段（说明窗口确实一路滑到底，不是提前结束）

### 建议（做完 D9-C 之后看）

- 所有"变长滑窗"都先写 left 的单调更新，再写收缩条件；顺序反了就会出现 abba 类错误
- 最高频错法：每个左端点都重建一个集合（窗口长时退化）；或忘记把 left 夹到 max
- 一行自检：`abba`（陷阱）、`bbbbb`（全同）、全互异（窗口 = 整串）三种输入

## 9.4 三数之和去重（D9-D）

### 学术

- 排序后固定 i，用相向双指针找 `a[j] + a[k] = −a[i]`：内层 Θ(n)，总计 Θ(n²)
- 排序让两个输出约束同时免费获得：组内升序（a ≤ b ≤ c）、组间字典序（i 递增、固定 i 时 j 递增）
- 去重三重：i 跳过与前一个相同的值；命中后 j 跳过相同 b；命中后 k 跳过相同 c
- n = 3000 时 Θ(n²)=9×10⁶ 可过，Θ(n³)=2.7×10¹⁰ 必超时；和用 Int64（3×10⁹ 已越 32 位）

### 实操（仓颉）

- `sort(a)` 对 `Array<Int64>` / `ArrayList<Int64>` 直接可用（`Int64` 已实现 `Comparable`），不需要自定义比较器
- 输出量可能很大（05 用例 20199 行），用 `StringBuilder` 攒完一次 `print`
- 无解输出一行 `none`；行尾不留空格、末尾不留空行

### 建议（做完 D9-D 之后看）

- 把三数之和理解成"外层枚举 + 两数之和"，去重就要在枚举层和指针层各做一次
- 最高频错法：只在 i 层去重，j/k 层不跳；`[0,0,0,0]` 会输出多行
- 一行自检：`[0,0,0,0]`（只一行）、`[-2,0,1,1,2]`（不能重复输出 `-2 1 1`）
