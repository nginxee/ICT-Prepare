# 数据结构与算法（仓颉）题 · 使用说明

> **18 个关卡 / 72 题**，每题只考一关的知识点，每关最后一题是 ★挑战。
> 课程内容与关卡顺序见 **`大纲.md`**；逐题清单见 **`problems\INDEX.md`**。
> 判题机制、脚本与隔壁 `..\Cangjie_standard_topic\` 完全一致 —— 会用那个就会用这个。

---

## 1. 日常流程（双击就行）

1. **双击 `自助判题.cmd`**
2. 提示出现后，**输入关卡号，回车**（例如 `8`）
3. 它会自动做两件事：
   - **先同步草稿**：把 `answers\default\src\*.cj` 复制到 `answers\`
   - **再判题**
4. 判完会再次提示，可以继续输入；**直接回车 = 退出**

```
请输入关卡号或题号 如 3（第3关全部题）,D3-B（单题）,a选中全部 直接回车退出 > 8
```

### 可以输入什么

| 输入 | 作用 |
|---|---|
| `8` | 判第 8 关全部题目（前缀和与差分） |
| `D8-C` | 只判单题 |
| `a` | 判**全部**题目（慢，约 3–5 分钟，适合总检查） |
| 直接回车 | 退出 |

## 2. 目录

```
drills\DSA_Cangjie_topic\
├─ 自助判题.cmd          ← 双击这个
├─ judge.ps1             ← 判题脚本本体（纯 ASCII 源码，见第 6 节）
├─ messages.json         ← 所有中文提示（UTF-8，由脚本显式解码）
├─ 大纲.md                ← ★ 总纲：72 行长表（知识点 / 学术要点 / 仓颉实操 / 复杂度）+ 达标线
├─ notes\                ← ★ 知识点手册：D01.md…D18.md，每关 4 节，每节「学术 → 实操 → 建议」
├─ 使用说明.md            ← 本文件
├─ problems\             ← 题库（不要改）
│  ├─ INDEX.md           ← 题目索引（题号 / 标题 / 用例数 / 对应 notes）
│  └─ D1-A\              题面.md + in\ + out\
└─ answers\
   ├─ default\src\       ← ★ 你写代码的地方
   └─ D*.cj              ← 判题时自动从 default\src 同步过来
```

**你只需要在 `answers\default\src\` 里写 `.cj`，文件名 = 题号**（如 `D8-C.cj`）。
判题前会自动同步，不用手动拷贝。

## 4. 判题说明

- 单用例**上限 5 秒**，超时判 `超时`（算法题的数据规模就是照这条设计的）
- 只比较 stdout，忽略每行行尾空格和末尾空行
- 编译**警告**会显示但**不影响判分**
- 只告诉你「输入 / 期望输出 / 你的输出」+ 差异表，**不给参考实现**
- 每题的用例分工：`01`/`02` 是题面里的样例（小、能手算），`03` 中等，`04` 专治易错点，`05` 是压到数据上界的规模用例 —— **`05` 过不了通常不是"差一点"，而是复杂度不对**

## 5. 三层文档怎么用（先读哪一份）

| 你要做什么 | 看哪一份 |
|---|---|
| 这一关要学到什么程度 | `大纲.md` 第 2 节长表里那 4 行 + 第 3 节达标线 |
| 学定义 / 不变量 / 为什么对 | `notes\D<nn>.md` 对应小节的 **学术** |
| 知道仓颉里怎么写、边界在哪 | 同小节的 **实操（仓颉）** |
| 做完之后怎么避坑、怎么自检 | 同小节的 **建议**（在每节最后，做之前别读） |
| 只看题目要求 | `problems\<ID>\题面.md`（只讲输入输出与样例，没有讲解） |

**建议节奏**：读 notes 该节的「学术」→ 关掉 notes 自己写 → 判题全绿 → 回读同节「建议」→ 用自己的话复述做法与复杂度 → 下一题。

三阶段过关标准（摘自 `大纲.md` 第 3 节）：

| 阶段 | 关卡 | 过关标准 |
|---|---|---|
| 一 · 线性结构 | D1–D5 | 不查资料，20 分钟内写完一关 4 题并全绿 |
| 二 · 有序与查找 | D6–D10 | 看到"区间查询 / 第 k 大 / 去重 / 最长子段"能立刻判定做法与复杂度 |
| 三 · 递归树图与策略 | D11–D18 | 能把问题翻译成树上递归、图上遍历、状态转移；仓颉无现成堆，自己写 |

## 6. 编码上的几个坑（都已处理，别去"修"）

| 坑 | 处理方式 |
|---|---|
| `cmd.exe` 按 **OEM 代码页(936)** 读 `.cmd`，UTF-8 中文会被当命令执行 | `自助判题.cmd` 保持**纯 ASCII**，中文全在 `messages.json` |
| PowerShell 5.1 按 **ANSI 代码页** 读无 BOM 的 `.ps1`，UTF-8 中文会变成语法错误 | `judge.ps1` 同样保持**纯 ASCII** |
| `cjc` 的诊断信息用 **ANSI 代码页** 输出 | 脚本显式按 ANSI 解码，所以中文路径不乱码 |
| `chcp 65001` 会让 `[Console]::ReadLine()` 立即返回 EOF | **不要**在 `自助判题.cmd` 里加 `chcp`，交互提示会直接失效 |
| 测试输入文件带上 BOM 会让第一行多个字符，`Int64.parse` 当场抛异常 | 题库自带的 `in\*.txt` 都是**无 BOM** 的；你自己造数据时别用会写 BOM 的保存方式 |

> 一句话：**`judge.ps1` / `自助判题.cmd` 里不要出现任何非 ASCII 字符。** 要改提示文案，改 `messages.json`（UTF-8）。

## 7. 做题时最容易踩的 API（都是本机 cjc 1.0.5 实测，不是抄文档）

| 想干什么 | 写法 | 坑 |
|---|---|---|
| 读一行 | `getStdIn().readln().getOrThrow()`（需 `import std.env.*`） | 返回 `?String`；**空行是 `Some("")`**，不是 `None` |
| 读到 EOF | `var c = getStdIn().readln()` + `while (c.isSome())` | 别用顶层 `readln()`，它没有 `getOrThrow` |
| 切分一行 | `line.trimAscii().split(" ")` | 连续空格产生空串，要 `if (p.size == 0) { continue }` |
| 解析整数 | `Int64.parse(s)` | 不容忍空白与 `+`；先 `trimAscii()` |
| 排序 | `sort(a)` / `sort(a, descending: true)`（`import std.sort.*`） | 自定义比较器用**命名参数** `by:`；老的 `sortBy` 已废弃 |
| 比较器语义 | `sort(a, by: {x, y => if (x > y) { Ordering.GT } else if (x < y) { Ordering.LT } else { Ordering.EQ }})` → **升序** | 返回"自然序"得升序；要降序把 GT/LT 互换或加 `descending: true` |
| 结构体/元组排序 | 元组可直接排：`sort(entries, by: {x: (String, Int64), y: (String, Int64) => ...})`，取元素 `x[0]`/`x[1]` | 多键排序全写进一层 if-else |
| 稳定排序 | `sort(list, by: {...}, stable: true)` | `stable!` 默认 false |
| 遍历 HashMap | `for ((k, v) in m) { ... }` | **遍历顺序不稳定**，输出前必须自己排序 |
| HashMap 读写 | `m.add(k, v)` / `m[k] = v` / `m.get(k): ?V` / `m.contains(k)` | 没有 `put` / `containsKey`；`get` 返回 Option |
| ArrayList | `add` / `size` / `l[i]` / `remove(at: i)` | 没有 `append`（那是 StringBuilder 的）；头删是 O(n) |
| 定长数组 | `Array<Int64>(n, repeat: 0)`、`slice(start, len)` | `slice` 第二参是**长度**不是结束下标 |
| 整数补零 | `n.format("03")` → `042`、`(-7).format("03")` → `-07` | 负数要加括号 |
| 浮点输出 | `f.format(".2")` | **`.2f` 会抛异常**；舍入是"四舍六入五取偶" |
| 字符串 | `s.size` 是**字节数**，字符数用 `s.toRuneArray().size`；切片 `s[0..5]` | 没有 `substring`、没有 `trim()` |
| 数学 | `import std.math.*`，有 `abs/sqrt/ceil/floor/round` | **没有** `max`/`min`，自己写比较 |
| 栈 / 队列 / 堆 | 标准库**都没有** | 栈用 `ArrayList` 尾部、队列用数组+首尾指针、堆手写 —— 这正是 D3/D4/D13 这三关要练的 |

## 8. 题库是怎么做出来的（可追责）

- **题库里没有任何答案**：`answers\` 初始是空的（只有 `default\src\.gitkeep`），**每一题的解法都由你自己写**。判题只给「输入 ↔ 期望输出」，不给参考实现。
- 题目**逐题**由参考实现生成测试数据，并**逐题核验**：
  1. 参考实现在本机 `cjc 1.0.5` 上必须编译通过 + 运行退出码 0；
  2. 每个用例的期望输出由参考实现产出，不是手写的；
  3. 题面里的**样例 k 与 `in\0k.txt` / `out\0k.txt` 逐字符一致**（由 `_build\check.py` 机械校验，含 BOM / CRLF / 命名 / 用例数）；
  4. 每题都跑过真实判题脚本回放，全绿才算完工。
- 按照本仓库的规矩，**参考实现不入库、也不留在盘上**：题库里只有 `题面.md` + `in\` + `out\`，没有任何解法代码；`answers\` 在交付时是空的。
- 每个用例的规模都**写进了题面**（`数据范围` 一行），`05.txt` 一定踩到那个上界 —— 所以"过了 04 挂了 05"意味着复杂度不够，不是数据坑你。
