# D11-C · 快速幂与取模

**关卡** D11 · 递归与分治 ｜ **提交** `answers/D11-C.cj`

求 q 组 `a^b mod m`，每组查询一行输出。

## 输入

第一行一个整数 q。
接下来 q 行，每行三个整数 a、b、m，单个空格分隔。

**数据范围**：1 ≤ q ≤ 10⁵；0 ≤ a ≤ 2×10⁹-1；0 ≤ b ≤ 10¹⁸；1 ≤ m ≤ 2×10⁹。

## 输出

q 行，第 i 行是第 i 组查询的 `a^b mod m`（结果一定落在 `[0, m-1]`）。

约定 `a^0 = 1`（含 `0^0 = 1`，即幂为 0 时结果为 `1 mod m`，`m = 1` 时为 `0`）。

## 样例

**样例 1**

```
输入：
3
2 10 1000
3 7 13
5 0 7
输出：
24
3
1
```

**样例 2**

```
输入：
5
0 0 1000
0 5 1000
1999999999 0 1000
7 1000000000000000000 1
0 1000000000000000000 97
输出：
1
0
1
0
0
```
