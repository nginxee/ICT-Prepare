# D9-B · 合并与移除（原地）

**关卡** D9 · 双指针与滑动窗口 ｜ **提交** `answers/D9-B.cj`

把两个非降序数组归并成一个非降序序列并去掉重复值（每个值只保留一个），输出结果长度和结果本身。

## 输入

第一行两个整数 n、m。
第二行 n 个整数，非降序，单个空格分隔。
第三行 m 个整数，非降序，单个空格分隔。

**数据范围**：1 ≤ n, m ≤ 2×10⁵；0 ≤ aᵢ, bᵢ ≤ 10⁹。

## 输出

两行：

```
第一行：合并去重后的元素个数 L
第二行：L 个整数，非降序，单个空格分隔，行末无空格
```

## 样例

**样例 1**

```
输入：
4 4
1 3 5 7
2 3 6 8
输出：
7
1 2 3 5 6 7 8
```

**样例 2**

```
输入：
1 1
0
0
输出：
1
0
```
