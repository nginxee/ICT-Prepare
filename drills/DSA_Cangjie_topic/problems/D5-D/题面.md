# D5-D · ★ 快慢指针：中点与环

**关卡** D5 · 链表 ｜ **提交** `answers/D5-D.cj`

一条链表可能有环：求链上节点个数、无环时的左中点、是否有环、环入口是哪个节点。
输出的是**节点下标**，不是节点的值。

## 输入

第一行一个整数 n，节点下标为 0 … n-1。
接下来 n 行，每行两个整数 `val nxt`：该节点的值，以及下一个节点的下标（`-1` 表示没有下一个）。
最后一行一个整数 head：首节点下标（`-1` 表示空链表）。

保证：从 head 出发沿 next 走，要么走到 `-1` 结束，要么回到某个走过的节点形成唯一的环；
不存在"两条不同路径进入同一个环"的情况。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ val ≤ 10⁹；nxt ∈ {-1} ∪ [0, n-1]；head ∈ {-1} ∪ [0, n-1]。

## 输出

四行：

- `len=` 链上不同节点的个数：无环时是链长 L，有环时是"入口前节点数 + 环长"
- `mid=` 左中点的节点下标；空链表或有环时输出 `-1`
- `cycle=` 有环输出 `1`，无环输出 `0`
- `entry=` 环入口的节点下标；无环输出 `-1`

左中点定义：链长为 L 时，沿链第 `(L-1)/2` 个节点（0 基计数，除法向下取整），即 L 为偶数时取靠前的那个。

## 样例

**样例 1**

```
输入：
5
100 1
100 2
200 3
200 4
300 -1
0
输出：
len=5
mid=2
cycle=0
entry=-1
```

**样例 2**

```
输入：
1
7 0
0
输出：
len=1
mid=-1
cycle=1
entry=0
```
