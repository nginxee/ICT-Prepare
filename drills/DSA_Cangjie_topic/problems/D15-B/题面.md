# D15-B · Kahn 拓扑排序

**关卡** D15 · 最短路与拓扑排序 ｜ **提交** `answers/D15-B.cj`

给一张有向图，输出它的字典序最小的拓扑序；若有环，输出 `cycle`。

## 输入

第一行两个整数 n 和 m（点数、边数），单个空格分隔。
接下来 m 行，每行两个整数 u v，表示一条有向边 u → v。

**数据范围**：1 ≤ n ≤ 10⁵；0 ≤ m ≤ 2×10⁵；1 ≤ u, v ≤ n（输入不保证无环；允许自环与重边）。

## 输出

若存在拓扑序：一行 n 个整数，为**字典序最小**的拓扑序（每个顶点恰好出现一次），单个空格分隔，行尾不留空格；若存在环：只输出一行 `cycle`。

## 样例

**样例 1**

```
输入：
5 4
1 5
2 5
5 3
5 4
输出：
1 2 5 3 4
```

**样例 2**

```
输入：
3 3
1 2
2 3
3 1
输出：
cycle
```
