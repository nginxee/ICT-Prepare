# D6-B · 多键排序（成绩降序 + 姓名升序）

**关卡** D6 · 排序 ｜ **提交** `answers/D6-B.cj`

给出 n 条"姓名 成绩"，按成绩降序输出；成绩相同则按姓名字典序升序。

## 输入

第一行一个整数 n。
接下来 n 行，每行 `姓名 成绩`，中间一个空格。

**数据范围**：1 ≤ n ≤ 10⁵；姓名长度 1–8（只含 `a`–`z`）；0 ≤ 成绩 ≤ 1000。

## 输出

n 行，每行 `姓名 成绩`（一个空格分隔），排列顺序为：成绩降序；成绩相同则姓名升序。

姓名与成绩都相同的两行之间不分先后，按原样输出即可。

## 样例

**样例 1**

```
输入：
4
dave 95
bob 90
alice 95
carol 90
输出：
alice 95
dave 95
bob 90
carol 90
```

**样例 2**

```
输入：
1
z 0
输出：
z 0
```
