# D8-D · 大规模差分 + 溢出边界

**关卡** D8 · 前缀和与差分 ｜ **提交** `answers/D8-D.cj`

n 个格子各有一个 0..9 的初值，做 q 次「把第 l 到第 r 个格子都加 x」，输出所有操作结束后的总和、最大值及其最小下标、负值格子数。

## 输入

第一行两个整数 n、q。
第二行 n 个整数（0..9），单个空格分隔，表示初始值。
接下来 q 行，每行三个整数 l、r、x。

**数据范围**：1 ≤ n ≤ 10⁶；0 ≤ aᵢ ≤ 9；0 ≤ q ≤ 2×10⁵；1 ≤ l ≤ r ≤ n；-10⁶ ≤ x ≤ 10⁶。

## 输出

三行：

```
第一行：所有操作结束后，所有格子值之和
第二行：最大值 和 它第一次出现的下标（1 起），中间一个空格
第三行：值为负数的格子个数
```

## 样例

**样例 1**

```
输入：
6 3
5 5 5 5 5 5
1 6 10
2 3 -20
6 6 4
输出：
54
19 6
2
```

**样例 2**

```
输入：
1 1
0
1 1 -7
输出：
-7
-7 1
1
```
