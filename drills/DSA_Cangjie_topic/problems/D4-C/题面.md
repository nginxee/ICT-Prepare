# D4-C · 约瑟夫环（报数出队）

**关卡** D4 · 队列与双端队列 ｜ **提交** `answers/D4-C.cj`

n 个人围成一圈报数，报到 k 的人出队，按出队顺序输出全部人的编号。

## 输入

一行两个整数 n、k，单个空格分隔，分别表示人数和报数上限。

**数据范围**：1 ≤ n ≤ 2×10⁵；1 ≤ k ≤ 30。

## 输出

一行，按**出队顺序**输出 n 个人的编号，编号之间用单个空格分隔，行末不要多余空格。

规则：编号为 1 … n；从 1 号开始报 1，报到 k 的人出队；该人的下一位重新从 1 报起，如此反复直到所有人出队。

## 样例

**样例 1**

```
输入：
7 3
输出：
3 6 2 7 5 1 4
```

**样例 2**

```
输入：
1 1
输出：
1
```
