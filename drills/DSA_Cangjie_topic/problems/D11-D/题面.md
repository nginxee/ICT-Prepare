# D11-D · ★ 逆序对计数

**关卡** D11 · 递归与分治 ｜ **提交** `answers/D11-D.cj`

统计数组里有多少对 (i, j) 满足 i < j 且 aᵢ > aⱼ。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

一行，一个整数：逆序对个数（相等不算逆序）。

## 样例

**样例 1**

```
输入：
5
2 3 8 6 1
输出：
5
```

**样例 2**

```
输入：
1
5
输出：
0
```
