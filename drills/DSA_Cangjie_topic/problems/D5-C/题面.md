# D5-C · 合并两个有序链表

**关卡** D5 · 链表 ｜ **提交** `answers/D5-C.cj`

两条各自按值非降序的单链表，归并成一条有序链，输出合并后的值序列与合并后的 next 数组。

## 输入

先描述链表 1，再描述链表 2，两段格式相同：

```
n1
val nxt        （共 n1 行，节点下标 0 … n1-1）
head1
n2
val nxt        （共 n2 行，节点下标 0 … n2-1）
head2
```

`nxt` 是下一个节点在**本链表内**的下标（`-1` 表示链尾）；`head` 是首节点下标（`-1` 表示该链表为空）。

保证：每条链从自己的 head 出发恰好走完本链表全部节点，且链上值非降序。

**数据范围**：0 ≤ n1, n2 ≤ 10⁵ 且 1 ≤ n1 + n2 ≤ 2×10⁵；-10⁹ ≤ val ≤ 10⁹；nxt ∈ {-1} ∪ [0, n-1]；head ∈ {-1} ∪ [0, n-1]。

## 输出

三行：

- `len=` 合并后链上的节点个数（等于 n1 + n2）
- `seq=` 从新的 head 开始沿 next 输出的各节点值，单个空格分隔
- `next=` 合并后的 next 数组：按拼接下标空间 0、1、…、n1+n2-1 的顺序打印每个节点的 next
  （下标 i < n1 指链表 1 的节点 i；下标 i ≥ n1 指链表 2 的节点 i - n1；`-1` 原样输出）

合并规则：两链当前节点取**值较小**者接到结果链尾；**值相等时取链表 1 的节点**。

## 样例

**样例 1**

```
输入：
3
1 1
3 2
5 -1
0
2
2 1
4 -1
0
输出：
len=5
seq=1 2 3 4 5
next=3 4 -1 1 2
```

**样例 2**

```
输入：
3
1 1
2 2
3 -1
0
0
-1
输出：
len=3
seq=1 2 3
next=1 2 -1
```
