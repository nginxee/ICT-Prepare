# D6-C · 计数排序（值域小）

**关卡** D6 · 排序 ｜ **提交** `answers/D6-C.cj`

给出 n 个非负整数，输出不同值的个数，以及升序排列后的整个序列。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；0 ≤ 每个整数 ≤ 10⁶。

## 输出

两行：

- `distinct=` 出现了多少种不同的值
- `sorted=` 升序排列后的 n 个整数，单个空格分隔，行末不要多余空格

## 样例

**样例 1**

```
输入：
6
3 1 3 0 1 2
输出：
distinct=4
sorted=0 1 1 2 3 3
```

**样例 2**

```
输入：
1
1000000
输出：
distinct=1
sorted=1000000
```
