# D2-C · 切片与循环右移

**关卡** D2 · 数组与 ArrayList ｜ **提交** `answers/D2-C.cj`

给 n 个整数与位移量 k，输出循环右移 k 位后的序列，以及原数组的前 min(4, n) 个、后 min(4, n) 个元素与元素和。

## 输入

第一行两个整数 n 和 k，单个空格分隔。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；0 ≤ k ≤ 10⁹；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

四行：

```
rot=<循环右移 k 位后的 n 个整数，单个空格分隔>
pre=<原数组前 min(4, n) 个元素，单个空格分隔>
suf=<原数组后 min(4, n) 个元素，单个空格分隔>
sum=<原数组所有元素之和>
```

`pre` / `suf` / `sum` 一律按**右移之前**的原数组计算，答案唯一。

## 样例

**样例 1**

```
输入：
5 2
1 2 3 4 5
输出：
rot=4 5 1 2 3
pre=1 2 3 4
suf=2 3 4 5
sum=15
```

**样例 2**

```
输入：
4 8
1 2 3 4
输出：
rot=1 2 3 4
pre=1 2 3 4
suf=1 2 3 4
sum=10
```
