# D12-C · 树高与叶子数

**关卡** D12 · 二叉树 ｜ **提交** `answers/D12-C.cj`

按数组表示读入一棵二叉树，输出树高、叶子个数、所有叶子的值之和。

## 输入

第一行一个整数 n。
第二行 n 个整数 a₁…aₙ，单个空格分隔。

数组表示约定（全关统一）：

- **下标从 1 起**：`a₁` 是根，`aᵢ` 的左孩子是 `a₂ᵢ`，右孩子是 `a₂ᵢ₊₁`；
- `aᵢ = 0` 表示**该位置是空节点**，且它的子孙位置也一定是 `0`；
- 下标大于 n 的位置一律视为空。

**数据范围**：1 ≤ n ≤ 10⁵；0 ≤ aᵢ ≤ 10⁶；非空节点的值都 ≥ 1。

## 输出

三行，格式固定：

```
height=<树高（层数），空树为 0>
leaves=<叶子个数，空树为 0>
leafsum=<所有叶子节点的值之和，空树为 0>
```

叶子指**左右孩子都为空**的非空节点。

## 样例

**样例 1**

```
输入：
7
1 2 3 4 5 6 7
输出：
height=3
leaves=4
leafsum=22
```

**样例 2**

```
输入：
1
42
输出：
height=1
leaves=1
leafsum=42
```
