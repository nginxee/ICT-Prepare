# D15-C · 无权图单源最短路

**关卡** D15 · 最短路与拓扑排序 ｜ **提交** `answers/D15-C.cj`

有向无权图上求起点 s 到所有点的最短边数，并输出 BFS 的出队顺序。

## 输入

第一行三个整数 n m s（点数、边数、起点），单个空格分隔。
接下来 m 行，每行两个整数 u v，表示一条有向边 u → v。

**数据范围**：1 ≤ n ≤ 10⁵；0 ≤ m ≤ 2×10⁵；1 ≤ s, u, v ≤ n；允许自环与重边。

## 输出

两行：第 1 行 n 个整数，s 到 1..n 每个点的最短边数，不可达输出 `-1`，s 自己为 `0`；第 2 行 BFS 的出队顺序（只列从 s 可达的点，含 s），单个空格分隔。

出队序的约定：每个点的出边按编号升序依次检查，先进队列的先出队。

## 样例

**样例 1**

```
输入：
4 4 1
1 3
1 2
2 4
3 4
输出：
0 1 1 2
1 2 3 4
```

**样例 2**

```
输入：
3 1 2
1 2
输出：
-1 0 -1
2
```
