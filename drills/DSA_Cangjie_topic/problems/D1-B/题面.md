# D1-B · 平方和与均值

**关卡** D1 · 规模、复杂度与 Int64 ｜ **提交** `answers/D1-B.cj`

给 n 个整数，输出平方和、和、整数均值，以及平方大于该均值的元素个数。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹；保证 Σaᵢ² ≤ 9×10¹⁸。

## 输出

四行，每行 `名字=值`：

```
sumsq=<Σaᵢ²>
sum=<Σaᵢ>
avg=<Σaᵢ / n，向零截断取整数>
big=<满足 aᵢ² > (Σaᵢ² / n 向下取整) 的元素个数>
```

## 样例

**样例 1**

```
输入：
5
1 -2 3 -4 5
输出：
sumsq=55
sum=3
avg=0
big=2
```

**样例 2**

```
输入：
2
-7 0
输出：
sumsq=49
sum=-7
avg=-3
big=1
```
