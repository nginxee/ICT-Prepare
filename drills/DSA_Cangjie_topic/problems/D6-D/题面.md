# D6-D · ★ 词频榜 Top-K

**关卡** D6 · 排序 ｜ **提交** `answers/D6-D.cj`

统计 n 个单词各自出现的次数，输出次数最多的前 k 个：次数降序；次数相同则单词字典序升序。

## 输入

第一行两个整数 n、k，单个空格分隔。
接下来 n 行，每行一个单词（只含小写字母，不含空格）。

**数据范围**：1 ≤ n ≤ 2×10⁵；1 ≤ k ≤ 不同单词的个数；单词长度 1–10（只含 `a`–`z`）。

## 输出

k 行，每行 `单词 次数`（一个空格分隔），排列顺序为：次数降序；次数相同则单词字典序升序。

## 样例

**样例 1**

```
输入：
6 3
b
a
b
c
a
b
输出：
b 3
a 2
c 1
```

**样例 2**

```
输入：
4 2
beta
alpha
alpha
beta
输出：
alpha 2
beta 2
```
