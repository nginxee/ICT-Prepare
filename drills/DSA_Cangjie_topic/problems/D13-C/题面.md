# D13-C · Top-K 大元素

**关卡** D13 · 堆与优先队列 ｜ **提交** `answers/D13-C.cj`

输出 n 个整数中最大的 k 个。

## 输入

第一行两个整数 n 和 k，单个空格分隔。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ k ≤ n ≤ 2×10⁵；-10⁹ ≤ 每个整数 ≤ 10⁹。

## 输出

一行 k 个整数：最大的 k 个，**从大到小**排列，单个空格分隔，行尾不留空格。相同的值各占一位（例如 `5 5 3` 里前 2 大就是 `5 5`）。

## 样例

**样例 1**

```
输入：
5 2
3 9 1 9 7
输出：
9 9
```

**样例 2**

```
输入：
4 4
-1 -2 -3 -4
输出：
-1 -2 -3 -4
```
