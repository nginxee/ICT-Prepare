# D3-B · 后缀表达式求值

**关卡** D3 · 栈 ｜ **提交** `answers/D3-B.cj`

给一个合法的后缀表达式（RPN），求它的整数值。

## 输入

一行，token 之间用**单个空格**分隔。每个 token 要么是整数（可带一个负号），要么是 `+` `-` `*` `/` 之一。

**数据范围**：1 ≤ token 数 ≤ 2×10⁵（合法的后缀表达式 token 数必为奇数：操作数比运算符多一个，所以最大取到 199999）；
|操作数| ≤ 10⁹；数据保证表达式合法、除法除数不为 0、任意中间结果与最终结果的绝对值 ≤ 9×10¹⁸（`Int64` 装得下）。

## 输出

一行一个整数：表达式的值。除法结果向零截断。答案唯一。

## 样例

**样例 1**

```
输入：
3 4 + 2 *
输出：
14
```

**样例 2**

```
输入：
-9 2 /
输出：
-4
```
