# D17-C · 跳跃游戏

**关卡** D17 · 贪心 ｜ **提交** `answers/D17-C.cj`

站在下标 0，每次从 i 最多能前进 a[i] 步，求跳到最后一个下标的最少跳跃次数。

## 输入

第一行一个整数 n。
第二行 n 个整数，第 i 个是 a[i]（下标从 0 开始数）。

**数据范围**：1 ≤ n ≤ 2×10⁵；0 ≤ a[i] ≤ 10⁹。

## 输出

- 能到达下标 n-1：输出一行 `steps=<最少跳跃次数>`
- 不能到达：输出一行 `-1`

起点就是终点时（n = 1）步数为 `0`。最少次数唯一，不存在并列取舍。

## 样例

**样例 1**

```
输入：
5
2 3 1 1 4
输出：
steps=2
```

**样例 2**

```
输入：
1
0
输出：
steps=0
```
