# D1-D · ★ 最长平台（相邻相等最长段）

**关卡** D1 · 规模、复杂度与 Int64 ｜ **提交** `answers/D1-D.cj`

给 n 个整数，找相邻且相等的最长一段（平台），输出它的长度、起始下标和值。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 10⁶；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

三行，每行 `名字=值`：`len=` 长度、`start=` 该段第一个元素的下标（从 1 起）、`value=` 该段的元素值。

长度相同的平台有多段时，输出**起始下标最小**的那一段。

## 样例

**样例 1**

```
输入：
10
1 1 2 2 2 3 3 1 1 1
输出：
len=3
start=3
value=2
```

**样例 2**

```
输入：
1
5
输出：
len=1
start=1
value=5
```
