# D8-A · 一维前缀和：q 次区间和

**关卡** D8 · 前缀和与差分 ｜ **提交** `answers/D8-A.cj`

给 n 个整数与 q 次区间查询，逐次输出区间和。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。
第三行一个整数 q。
接下来 q 行，每行两个整数 l、r。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹；1 ≤ q ≤ 10⁵；1 ≤ l ≤ r ≤ n。

## 输出

q 行，每行一个整数：区间 `a[l..r]` 的元素和（可能为负数）。

## 样例

**样例 1**

```
输入：
5
3 -1 4 1 -5
4
1 5
2 4
3 3
1 2
输出：
2
4
4
2
```

**样例 2**

```
输入：
1
-7
2
1 1
1 1
输出：
-7
-7
```
