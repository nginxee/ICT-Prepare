# D9-D · ★ 三数之和（排序 + 相向双指针 + 去重）

**关卡** D9 · 双指针与滑动窗口 ｜ **提交** `answers/D9-D.cj`

找出所有满足 `a + b + c = 0` 的不重复三元组，每组一行输出；一个都没有时输出 `none`。

## 输入

第一行一个整数 n。
第二行 n 个整数（单个空格分隔，可能有重复）。

**数据范围**：1 ≤ n ≤ 3000；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

每行一个三元组，写成 `a b c`（三个整数、单个空格分隔、组内升序）。

顺序与多解口径（判题逐字符比较，顺序必须完全一致）：

- 值相同的三元组只输出一次
- 所有三元组按 `(a, b, c)` 的字典序升序输出（先比 a，再比 b，再比 c）
- 一个解都没有时输出一行 `none`
- 行尾不留空格，输出末尾不留空行

## 样例

**样例 1**

```
输入：
6
-1 0 1 2 -1 -4
输出：
-1 -1 2
-1 0 1
```

**样例 2**

```
输入：
3
1 2 3
输出：
none
```
