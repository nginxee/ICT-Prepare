# D3-C · 下一个更大元素

**关卡** D3 · 栈 ｜ **提交** `answers/D3-C.cj`

给 n 个整数，对每个位置输出它右侧第一个严格大于它的元素的下标，没有则输出 -1。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

一行 n 个整数，单个空格分隔。第 i 个数是"满足 j > i 且 aⱼ > aᵢ 的最小 j"（1 起），不存在则输出 -1。答案唯一。

## 样例

**样例 1**

```
输入：
5
2 1 3 4 5
输出：
3 3 4 5 -1
```

**样例 2**

```
输入：
4
7 7 7 7
输出：
-1 -1 -1 -1
```
