# D2-A · 定长数组：逆序与原位交换

**关卡** D2 · 数组与 ArrayList ｜ **提交** `answers/D2-A.cj`

给 n 个整数，输出逆序后的序列、逆序所需的交换次数，以及逆序前后取值相同的对称下标对个数。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

三行：

```
rev=<逆序后的 n 个整数，单个空格分隔>
swaps=<原地交换的执行次数，应等于 floor(n/2)>
same=<满足 aᵢ == a(n+1-i) 的下标对个数，i < n+1-i；n 为奇数时中间元素不参与>
```

`same` 按**原始**数组统计（逆序之前）。答案唯一。

## 样例

**样例 1**

```
输入：
5
1 2 3 4 5
输出：
rev=5 4 3 2 1
swaps=2
same=0
```

**样例 2**

```
输入：
1
7
输出：
rev=7
swaps=0
same=0
```
