# D15-A · Dijkstra（非负边权）

**关卡** D15 · 最短路与拓扑排序 ｜ **提交** `answers/D15-A.cj`

无向图、边权非负，求 1 号点到其它所有点的最短距离。

## 输入

第一行两个整数 n 和 m（点数、边数），单个空格分隔。
接下来 m 行，每行三个整数 u v w，表示 u 与 v 之间有一条长度为 w 的无向边。

**数据范围**：1 ≤ n ≤ 10⁵；0 ≤ m ≤ 2×10⁵；1 ≤ u, v ≤ n；u ≠ v；0 ≤ w ≤ 10⁹（允许 0 权边与重边）。

## 输出

一行 n 个整数：1 号点到 1..n 每个点的最短距离，不可达输出 `-1`，1 号点自己为 `0`，单个空格分隔，行尾不留空格。

## 样例

**样例 1**

```
输入：
5 5
1 2 4
1 3 1
3 2 1
2 4 1
3 4 5
输出：
0 2 1 3 -1
```

**样例 2**

```
输入：
1 0
输出：
0
```
