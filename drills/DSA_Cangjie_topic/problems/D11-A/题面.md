# D11-A · 递归三连（阶乘/斐波那契/数组和）

**关卡** D11 · 递归与分治 ｜ **提交** `answers/D11-A.cj`

读入 k、m、n 与 k 个整数，一次输出阶乘 `m!`、斐波那契第 n 项、以及数组元素之和。

## 输入

第一行三个整数 k、m、n，其中 k 是数组长度、m 是阶乘参数、n 是斐波那契下标。
第二行 k 个整数，单个空格分隔。

**数据范围**：1 ≤ k ≤ 2×10⁵；1 ≤ m ≤ 20；1 ≤ n ≤ 90；-10⁹ ≤ 每个数 ≤ 10⁹。

## 输出

三行，格式固定（`名字=` 后紧跟数值，不要空格）：

```
fact=<m!>
fib=<F(n)>
sum=<数组元素之和>
```

其中 `0! = 1`、`1! = 1`；斐波那契 `F(1) = 1`、`F(2) = 1`、`F(n) = F(n-1) + F(n-2)`。

## 样例

**样例 1**

```
输入：
5 5 10
1 2 3 4 5
输出：
fact=120
fib=55
sum=15
```

**样例 2**

```
输入：
1 1 2
-1000000000
输出：
fact=1
fib=1
sum=-1000000000
```
