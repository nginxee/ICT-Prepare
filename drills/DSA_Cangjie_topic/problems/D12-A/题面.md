# D12-A · 数组建树 + 前/中/后序遍历

**关卡** D12 · 二叉树 ｜ **提交** `answers/D12-A.cj`

按数组表示读入一棵二叉树，输出它的前序、中序、后序遍历序列。

## 输入

第一行一个整数 n。
第二行 n 个整数 a₁…aₙ，单个空格分隔。

数组表示约定（全关统一）：

- **下标从 1 起**：`a₁` 是根，`aᵢ` 的左孩子是 `a₂ᵢ`，右孩子是 `a₂ᵢ₊₁`；
- `aᵢ = 0` 表示**该位置是空节点**，且它的子孙位置也一定是 `0`；
- 下标大于 n 的位置一律视为空。

**数据范围**：1 ≤ n ≤ 10⁵；0 ≤ aᵢ ≤ 10⁶；非空节点的值都 ≥ 1。

## 输出

三行，依次是**前序遍历**、**中序遍历**、**后序遍历**的节点值序列：

- 只输出非空节点，值之间用**单个空格**分隔，行尾不留空格；
- 如果整棵树是空的（`a₁ = 0`），三行都输出 `empty`。

## 样例

**样例 1**

```
输入：
7
1 2 3 4 5 6 7
输出：
1 2 4 5 3 6 7
4 2 5 1 6 3 7
4 5 2 6 7 3 1
```

**样例 2**

```
输入：
1
0
输出：
empty
empty
empty
```
