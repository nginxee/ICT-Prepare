# D18-C · LIS（最长上升子序列）

**关卡** D18 · 动态规划 ｜ **提交** `answers/D18-C.cj`

求最长**严格上升**子序列的长度，并输出其中一个方案。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 10⁴；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

两行：

```
len=<最长严格上升子序列的长度>
seq=<该方案的所有值，单个空格分隔>
```

**多解口径**：长度为 `len` 的上升子序列可能有很多个，输出**下标序列字典序最小**的那一个（即从前往后尽量选下标最小的可行元素），`seq` 就是这个方案的取值。所以输出唯一。

## 样例

**样例 1**

```
输入：
6
1 7 3 5 9 4
输出：
len=4
seq=1 3 5 9
```

**样例 2**

```
输入：
1
42
输出：
len=1
seq=42
```
