# D17-D · ★ 拼最大数（比较器排序）

**关卡** D17 · 贪心 ｜ **提交** `answers/D17-D.cj`

把 n 个十进制数字串首尾相接，拼成一个最大的数并输出。

## 输入

第一行一个整数 n。
第二行 n 个十进制数字串，单个空格分隔（每个串只由 `0`–`9` 组成，可能有前导零）。

**数据范围**：1 ≤ n ≤ 10⁵；每个数字串长度 1 ≤ len ≤ 20；输入不含负号、不含小数点。

## 输出

一行，拼接结果**去掉前导零**后的字符串。

- 拼接顺序由"拼出来最大"唯一确定（两种顺序拼出的字符串相同的情形，输出也一样）
- 数字串都是 `0`（或去掉前导零后什么都不剩）时，输出单个 `0`
- 行尾不留空格，输出末尾不留空行

## 样例

**样例 1**

```
输入：
3
3 30 34
输出：
34330
```

**样例 2**

```
输入：
4
0 0 0 0
输出：
0
```
