# D9-A · 有序数组两数之和

**关卡** D9 · 双指针与滑动窗口 ｜ **提交** `answers/D9-A.cj`

给一个非降序数组和目标 t，找两个不同位置 i < j 使 `a[i] + a[j] = t`，输出这一对下标；没有这样的对就输出 `none`。

## 输入

第一行一个整数 n。
第二行 n 个整数，非降序排列，单个空格分隔。
第三行一个整数 t。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹；-2×10⁹ ≤ t ≤ 2×10⁹。

## 输出

有解时一行两个整数 `i j`（`i < j`，下标从 1 开始）；无解时一行 `none`。

多解口径：在所有满足条件的 `(i, j)` 中取 i 最小的那一组；同一 i 对应多个 j 时取 j 最大的那一组。

## 样例

**样例 1**

```
输入：
5
1 2 3 4 6
6
输出：
2 4
```

**样例 2**

```
输入：
1
5
10
输出：
none
```
