# D18-D · ★ 编辑距离 / LCS

**关卡** D18 · 动态规划 ｜ **提交** `answers/D18-D.cj`

求把 s1 变成 s2 的最少操作数（每次可以替换、删除、插入一个字符），并输出一个最短操作序列。

## 输入

第一行一个字符串 s1，第二行一个字符串 s2。
两个串都只由小写英文字母 `a`–`z` 组成，不含空格。

**数据范围**：1 ≤ |s1|, |s2| ≤ 1000；保证 |s1|·|s2| ≤ 10⁶。

## 输出

两行：

```
dist=<最少操作数>
script=<操作序列>
```

`script` 的每个字符含义（顺序即执行顺序，全部作用在 s1 上）：

- `M`：两个字符相同，一起前进（代价 0）
- `S`：把 s1 当前字符替换成 s2 当前字符（代价 1）
- `D`：删除 s1 的当前字符（代价 1）
- `I`：在 s1 当前位置插入一个 s2 的当前字符（代价 1）

**多解口径**：最短编辑脚本可能不止一个，按下面的规则唯一确定——
从 `(i, j) = (|s1|, |s2|)` 开始往回退，每一步按 `M`、`S`、`D`、`I` 的优先级取第一个成立的：

1. `i > 0` 且 `j > 0` 且 `s1[i-1] == s2[j-1]` 且 `dp[i][j] == dp[i-1][j-1]` → 取 `M`
2. 否则 `i > 0` 且 `j > 0` 且 `dp[i][j] == dp[i-1][j-1] + 1` → 取 `S`
3. 否则 `i > 0` 且 `dp[i][j] == dp[i-1][j] + 1` → 取 `D`
4. 否则 → 取 `I`

（`dp[i][j]` 是把 s1 前 i 个字符变成 s2 前 j 个字符的最少操作数。）退到 `(0, 0)` 后把收集到的操作**反转**输出。
`script` 的长度等于 `dist` 加上 `M` 的个数。

## 样例

**样例 1**

```
输入：
kitten
sitting
输出：
dist=3
script=SMMMSMI
```

**样例 2**

```
输入：
a
b
输出：
dist=1
script=S
```
