# D16-B · 朋友圈计数

**关卡** D16 · 并查集 ｜ **提交** `answers/D16-B.cj`

给 n 个人和 m 对"互相认识"的关系（认识关系可以传递），输出最后的朋友圈个数与最大的那个朋友圈的人数。

## 输入

第一行两个整数 n、m。
接下来 m 行，每行两个整数 u、v，表示 u 和 v 互相认识。

**数据范围**：1 ≤ n ≤ 2×10⁵；0 ≤ m ≤ 2×10⁵；1 ≤ u, v ≤ n；关系可能重复，也可能出现 u = v。

## 输出

两行，每行 `名字=值`，值都是十进制整数：

```
groups=<朋友圈个数>
largest=<最大的那个朋友圈的人数>
```

单独一个人也算一个朋友圈（人数 1）。答案唯一，不涉及输出顺序的取舍。

## 样例

**样例 1**

```
输入：
6 3
1 2
2 3
5 6
输出：
groups=3
largest=3
```

**样例 2**

```
输入：
1 0
输出：
groups=1
largest=1
```
