# D14-C · 连通块计数

**关卡** D14 · 图的遍历 ｜ **提交** `answers/D14-C.cj`

数一数无向图有多少个连通块，并输出每个块的最小编号与点数。

## 输入

第一行两个整数 n 和 m，单个空格分隔。
接下来 m 行，每行两个整数 u v，表示 u 与 v 之间有一条无向边。

**数据范围**：1 ≤ n ≤ 10⁵；0 ≤ m ≤ 2×10⁵；1 ≤ u, v ≤ n；u ≠ v；允许重边。

## 输出

第 1 行一个整数 k（连通块个数）；接下来 k 行，每行两个整数 `<块内最小编号> <块内点数>`，按最小编号从小到大排列，两个整数单个空格分隔。

## 样例

**样例 1**

```
输入：
6 3
1 2
2 3
5 6
输出：
3
1 3
4 1
5 2
```

**样例 2**

```
输入：
1 0
输出：
1
1 1
```
