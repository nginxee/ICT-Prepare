# D16-C · 大规模操作（压缩 vs 不压缩）

**关卡** D16 · 并查集 ｜ **提交** `answers/D16-C.cj`

维护 1..n 的连通性，按顺序处理 m 次合并与查询操作（规模比 D16-A 大得多）。

## 输入

第一行两个整数 n、m。
接下来 m 行，每行三个整数 `op u v`：`op = 1` 表示合并 u 和 v 所在的组，`op = 2` 表示询问 u 和 v 是否连通。

**数据范围**：1 ≤ n ≤ 10⁵；1 ≤ m ≤ 2×10⁵；1 ≤ u, v ≤ n；`op` 只取 1 或 2；保证至少有一个 `op = 2` 的行。

## 输出

对每个 `op = 2` 的行按输入顺序输出一行：连通输出 `YES`，不连通输出 `NO`。
`op = 1` 的行不产生任何输出。行尾不留空格，输出末尾不留空行。

## 样例

**样例 1**

```
输入：
4 5
2 1 2
1 1 2
2 1 2
1 2 3
2 1 3
输出：
NO
YES
YES
```

**样例 2**

```
输入：
2 4
2 1 2
1 1 1
2 1 1
2 2 2
输出：
NO
YES
YES
```
