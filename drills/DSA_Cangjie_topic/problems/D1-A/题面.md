# D1-A · 一趟扫描四个量

**关卡** D1 · 规模、复杂度与 Int64 ｜ **提交** `answers/D1-A.cj`

给 n 个整数，输出它们的和、最大值、最小值、负数个数。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

四行，每行 `名字=值`：`sum=` 所有数之和、`max=` 最大值、`min=` 最小值、`neg=` 负数个数（0 不算负数）。

## 样例

**样例 1**

```
输入：
5
3 -1 4 -5 0
输出：
sum=1
max=4
min=-5
neg=2
```

**样例 2**

```
输入：
1
0
输出：
sum=0
max=0
min=0
neg=0
```
