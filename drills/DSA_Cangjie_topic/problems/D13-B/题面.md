# D13-B · 堆排序

**关卡** D13 · 堆与优先队列 ｜ **提交** `answers/D13-B.cj`

读入 n 个整数，输出建堆之后的大顶堆数组，以及原地堆排序之后的升序数组。

## 输入

第一行一个整数 n。
第二行 n 个整数 a₁ … aₙ，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ 每个整数 ≤ 10⁹。

## 输出

两行：第 1 行是建堆之后的大顶堆数组（n 个整数，单个空格分隔，行尾不留空格）；第 2 行是升序排好序的数组（n 个整数，单个空格分隔，行尾不留空格）。

建堆与排序过程按下面的约定，否则第 1 行对不上：

1. **建堆**：`i` 从 `n/2-1` 递减到 `0`，对每个 `i` 执行一次下沉。下沉规则：若当前结点有孩子，取较**大**的孩子（两个孩子相等时取左孩子）；该孩子比当前结点大就交换，然后在新位置继续下沉；否则停止。
2. **排序**：重复 n-1 次：把堆顶 `a[0]` 与当前堆的最后一个元素交换，堆大小减一，再对堆顶下沉一次（规则同上）。做完后整个数组升序。

## 样例

**样例 1**

```
输入：
5
4 10 3 5 1
输出：
10 5 3 4 1
1 3 4 5 10
```

**样例 2**

```
输入：
2
2 2
输出：
2 2
2 2
```
