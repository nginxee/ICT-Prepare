# D8-B · 一维差分：区间加后还原

**关卡** D8 · 前缀和与差分 ｜ **提交** `answers/D8-B.cj`

给一个长度为 n 的数组与 q 次「把 a[l..r] 每个元素都加 x」的操作，输出所有操作做完后的数组。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔，表示初始数组。
第三行一个整数 q。
接下来 q 行，每行三个整数 l、r、x。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹；1 ≤ q ≤ 10⁵；1 ≤ l ≤ r ≤ n；-10⁹ ≤ x ≤ 10⁹。

## 输出

一行，n 个整数，单个空格分隔：所有操作做完之后的数组。数字之间恰好一个空格，行末无空格。

## 样例

**样例 1**

```
输入：
5
1 2 3 4 5
3
1 3 10
2 5 -3
4 4 7
输出：
11 9 10 8 2
```

**样例 2**

```
输入：
1
0
2
1 1 5
1 1 -2
输出：
3
```
