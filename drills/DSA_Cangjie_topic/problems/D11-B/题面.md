# D11-B · 归并排序（自己写 merge）

**关卡** D11 · 递归与分治 ｜ **提交** `answers/D11-B.cj`

把 n 个整数排成非降序，并输出排序后每个位置上的数在原数组中的下标。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔（**可能有大量重复值**）。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁶ ≤ aᵢ ≤ 10⁶。

## 输出

两行：

1. 第一行：非降序排好的 n 个数，单个空格分隔。
2. 第二行：**稳定序下标** —— 排序后每个位置上的数在原数组中的下标（1 起），单个空格分隔。
   即：并列的数之间，原下标小的排在前面。

## 样例

**样例 1**

```
输入：
5
3 1 2 1 3
输出：
1 1 2 3 3
2 4 3 1 5
```

**样例 2**

```
输入：
1
7
输出：
7
1
```
