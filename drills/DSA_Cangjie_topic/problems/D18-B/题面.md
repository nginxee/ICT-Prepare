# D18-B · 0/1 背包（恰好装满）

**关卡** D18 · 动态规划 ｜ **提交** `answers/D18-B.cj`

n 件物品各有重量与价值，每件最多用一次，求把容量**正好装满** V 时的最大总价值。

## 输入

第一行两个整数 `n V`：物品件数、背包容量。
接下来 n 行，每行两个整数 `w v`，表示该物品的重量和价值。

**数据范围**：1 ≤ n ≤ 1000；1 ≤ V ≤ 1000；1 ≤ w ≤ 1000；0 ≤ v ≤ 10⁹；保证 n·V ≤ 10⁶。物品重量可能大于 V（那件物品就用不上）。

## 输出

- 能恰好装满：输出一行 `best=<最大总价值>`
- 不能恰好装满：输出一行 `-1`

只要求总重量**恰好等于** V；总价值相同但选法不同的情形不影响输出。答案唯一。

## 样例

**样例 1**

```
输入：
3 5
2 3
3 4
2 5
输出：
best=9
```

**样例 2**

```
输入：
1 3
2 100
输出：
-1
```
