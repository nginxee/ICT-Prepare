# D3-A · 括号匹配（三种括号）

**关卡** D3 · 栈 ｜ **提交** `answers/D3-A.cj`

给一行只含 `(` `)` `[` `]` `{` `}` 的字符串，判断是否完全匹配；不匹配时输出第一个出错的位置与类型。

## 输入

一行字符串 s，只由 `(` `)` `[` `]` `{` `}` 六种字符组成，不含空格。

**数据范围**：1 ≤ |s| ≤ 2×10⁵。

## 输出

一行：

- 完全匹配：输出 `OK`
- 不匹配：输出 `NO <pos> <code>`，`pos` 为从 1 起的字符下标，`code` 取以下三种之一：

```
close     ← 遇到右括号时，前面没有未闭合的左括号
mismatch  ← 遇到右括号时，最近一个未闭合的左括号与它类型不同
open      ← 扫完整个串仍有未闭合的左括号；pos 报最靠左（最早）那个左括号的下标
```

判定顺序固定：**从左往右扫，报第一个发现的错误**；`close` / `mismatch` 取当前右括号的位置，`open` 取最靠左那个左括号的位置。

## 样例

**样例 1**

```
输入：
([]){}([{}])
输出：
OK
```

**样例 2**

```
输入：
)
输出：
NO 1 close
```
