# D12-B · 层序遍历与每层最大值

**关卡** D12 · 二叉树 ｜ **提交** `answers/D12-B.cj`

按数组表示读入一棵二叉树，输出层序遍历序列，以及每层的节点数与最大值。

## 输入

第一行一个整数 n。
第二行 n 个整数 a₁…aₙ，单个空格分隔。

数组表示约定（全关统一）：

- **下标从 1 起**：`a₁` 是根，`aᵢ` 的左孩子是 `a₂ᵢ`，右孩子是 `a₂ᵢ₊₁`；
- `aᵢ = 0` 表示**该位置是空节点**，且它的子孙位置也一定是 `0`；
- 下标大于 n 的位置一律视为空。

**数据范围**：1 ≤ n ≤ 10⁵；0 ≤ aᵢ ≤ 10⁶；非空节点的值都 ≥ 1。

## 输出

1. 第一行：层序遍历得到的节点值序列，单个空格分隔；树为空（`a₁ = 0`）时输出 `empty`。
2. 第二行：`levels=<层数>`；树为空时输出 `levels=0`。
3. 之后每层一行：`<层号> <该层节点数> <该层最大值>`，层号从 1 开始；树为空时**不输出**这些行。

## 样例

**样例 1**

```
输入：
7
1 2 3 4 5 6 7
输出：
1 2 3 4 5 6 7
levels=3
1 1 1
2 2 3
3 4 7
```

**样例 2**

```
输入：
1
0
输出：
empty
levels=0
```
