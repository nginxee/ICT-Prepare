# D2-D · ★ 稳定分区（负数在前正数在后）

**关卡** D2 · 数组与 ArrayList ｜ **提交** `answers/D2-D.cj`

给 n 个整数做稳定分区：负数全部在前、非负数在后，两侧各自保持原相对顺序；输出分区结果与负、零、正的个数。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

四行：

```
part=<稳定分区后的 n 个整数，单个空格分隔>
neg=<负数的个数>
zero=<0 的个数>
pos=<正数的个数>
```

分区规则固定：负数在前、非负数在后；两段内部都保持**原数组中的先后顺序**。答案唯一（稳定分区结果只有一种）。

## 样例

**样例 1**

```
输入：
8
3 -1 0 -2 5 -3 7 -4
输出：
part=-1 -2 -3 -4 3 0 5 7
neg=4
zero=1
pos=3
```

**样例 2**

```
输入：
5
-5 -4 -3 -2 -1
输出：
part=-5 -4 -3 -2 -1
neg=5
zero=0
pos=0
```
