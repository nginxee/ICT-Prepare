# D18-A · 线性 DP：最大子段和

**关卡** D18 · 动态规划 ｜ **提交** `answers/D18-A.cj`

求一个非空连续子段的最大和，并输出该子段的左右端点（1 开始计数）。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

三行，每行 `名字=值`：

```
max=<最大子段和>
l=<左端点下标，1 开始>
r=<右端点下标，1 开始>
```

子段不允许为空（全是负数时答案就是最大的那个负数）。
**多解口径**：和最大的子段可能不止一个，输出**左端点最小**的那一个；左端点也相同时，输出**右端点最小**的那一个。所以输出唯一。

## 样例

**样例 1**

```
输入：
8
-2 1 -3 4 -1 2 1 -5
输出：
max=6
l=4
r=7
```

**样例 2**

```
输入：
1
-5
输出：
max=-5
l=1
r=1
```
