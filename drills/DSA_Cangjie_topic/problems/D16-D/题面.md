# D16-D · ★ Kruskal 最小生成树

**关卡** D16 · 并查集 ｜ **提交** `answers/D16-D.cj`

给 n 个点、m 条带权无向边，求最小生成树的总权重；图不连通时报告不可行。

## 输入

第一行两个整数 n、m（点数、边数）。
接下来 m 行，每行三个整数 `u v w`，表示一条连接 u、v 的无向边，权值为 w。

**数据范围**：1 ≤ n ≤ 10⁵；0 ≤ m ≤ 2×10⁵；1 ≤ u, v ≤ n；0 ≤ w ≤ 10⁹；可能存在自环与重边。

## 输出

- 若图连通：输出一行 `mst=<最小生成树的总权重>`
- 若图不连通：输出一行 `IMPOSSIBLE`

连通指 n 个点全部落在同一个连通块里（n = 1 时视作连通，总权重为 0）。最小生成树的总权重唯一，不存在并列取舍。

## 样例

**样例 1**

```
输入：
4 5
1 2 1
2 3 2
3 4 3
1 4 10
2 4 4
输出：
mst=6
```

**样例 2**

```
输入：
3 1
1 2 5
输出：
IMPOSSIBLE
```
