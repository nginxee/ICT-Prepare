# D3-D · ★ 四则运算表达式求值

**关卡** D3 · 栈 ｜ **提交** `answers/D3-D.cj`

给一行合法的四则运算表达式（含括号），求它的整数值。

## 输入

一行字符串 s，由数字 `0`-`9`、运算符 `+ - * /`、括号 `( )` 组成，**不含空格**。

**数据范围**：1 ≤ |s| ≤ 2×10⁵；数据保证：
`-` 只作二元减号（不会出现在表达式开头、`(` 之后或运算符之后，因此没有一元负号）；
括号正确配对、表达式合法；除法除数不为 0 且一定能整除；
任意中间结果与最终结果的绝对值 ≤ 9×10¹⁸（`Int64` 装得下）。

## 输出

一行一个整数：表达式的值。答案唯一。

## 样例

**样例 1**

```
输入：
1+2*3
输出：
7
```

**样例 2**

```
输入：
42
输出：
42
```
