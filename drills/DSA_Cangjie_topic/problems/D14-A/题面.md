# D14-A · 邻接表建图 + DFS 访问序

**关卡** D14 · 图的遍历 ｜ **提交** `answers/D14-A.cj`

用邻接表把无向图建起来，输出从 1 号点出发的深度优先访问序。

## 输入

第一行两个整数 n 和 m，单个空格分隔。
接下来 m 行，每行两个整数 u v，表示 u 与 v 之间有一条无向边。

**数据范围**：1 ≤ n ≤ 10⁵；0 ≤ m ≤ 2×10⁵；1 ≤ u, v ≤ n；u ≠ v；允许重边。

## 输出

一行 n 个整数：访问序（1 到 n 的一个排列），单个空格分隔，行尾不留空格。

访问规则：先访问当前点，再按编号**从小到大**依次深入未访问的邻居；一个连通块走完之后，从**最小编号**的未访问点重新开始。

## 样例

**样例 1**

```
输入：
6 5
1 2
1 3
2 4
3 4
5 6
输出：
1 2 4 3 5 6
```

**样例 2**

```
输入：
1 0
输出：
1
```
