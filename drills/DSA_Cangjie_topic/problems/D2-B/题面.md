# D2-B · ArrayList：删值去重保序

**关卡** D2 · 数组与 ArrayList ｜ **提交** `answers/D2-B.cj`

给 n 个整数与一个值 x，删掉所有等于 x 的元素、把剩下的保序去重，输出结果序列、保留个数与被删掉的个数。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。
第三行一个整数 x（要删掉的值）。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹；-10⁹ ≤ x ≤ 10⁹。

## 输出

三行：

```
kept=<处理后的序列，单个空格分隔；若一个元素都不剩，输出 kept=none>
size=<保留的元素个数>
removed=<被删掉的元素个数，等于 n - size>
```

"被删掉"包括两类：值等于 x 的、以及重复出现的。答案唯一（保序去重结果只有一种）。

## 样例

**样例 1**

```
输入：
8
3 1 3 2 1 4 3 2
3
输出：
kept=1 2 4
size=3
removed=5
```

**样例 2**

```
输入：
4
5 5 5 5
5
输出：
kept=none
size=0
removed=4
```
