# D10-C · 两数之和返回下标

**关卡** D10 · 哈希表与集合 ｜ **提交** `answers/D10-C.cj`

在数组里找两个不同下标 i < j，使 aᵢ + aⱼ = target，输出符合规则的那一对下标。

## 输入

第一行两个整数 n 和 target。
第二行 n 个整数，单个空格分隔。

**数据范围**：2 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹；-2×10⁹ ≤ target ≤ 2×10⁹。

## 输出

一行：

- 有解：输出 `i j`（**1 起**下标，`i < j`）。要求 `i ≠ j`；在所有解中 **i 最小**，i 相同的解中 **j 最小**（该解唯一）。
- 无解：输出 `-1`。

## 样例

**样例 1**

```
输入：
5 5
3 1 3 2 4
输出：
1 4
```

**样例 2**

```
输入：
2 100
1 2
输出：
-1
```
