# D9-C · 最长无重复子串

**关卡** D9 · 双指针与滑动窗口 ｜ **提交** `answers/D9-C.cj`

给一个字符串，输出最长的「字符互不相同」的连续子串的长度与左端点下标。

## 输入

第一行一个字符串 s（不含空格）。

**数据范围**：1 ≤ |s| ≤ 2×10⁵；s 只由 ASCII 可见字符（编码 33–126，即 `!` 到 `~`）组成。

## 输出

两行，每行 `名字=值`：

```
len=<最长无重复子串的长度>
start=<它的左端点下标，1 开始计数>
```

多解口径：长度最大的无重复子串可能不止一个（例如 `abba` 有 `ab` 和 `ba`），规定输出左端点最小的那一个，所以答案唯一。

## 样例

**样例 1**

```
输入：
abcabcbb
输出：
len=3
start=1
```

**样例 2**

```
输入：
bbbbb
输出：
len=1
start=1
```
