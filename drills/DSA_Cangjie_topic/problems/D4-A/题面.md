# D4-A · 操作序列模拟队列

**关卡** D4 · 队列与双端队列 ｜ **提交** `answers/D4-A.cj`

读入 m 条队列指令，逐条执行，并对每条查询指令输出结果。

## 输入

第一行一个整数 m。
接下来 m 行，每行一条指令，形式为下面五种之一（指令名大写，片段间一个空格）：

- `PUSH x` 把整数 x 放到队尾
- `POP` 弹出队首元素
- `FRONT` 查看队首元素，不弹出
- `EMPTY` 查询队列是否为空
- `SIZE` 查询当前元素个数

**数据范围**：1 ≤ m ≤ 2×10⁵；-10⁹ ≤ x ≤ 10⁹。

## 输出

按指令出现顺序，每条查询指令输出一行（`PUSH` 不产生输出）：

- `POP`：被弹出的值；队列为空输出 `none`
- `FRONT`：队首的值；队列为空输出 `none`
- `EMPTY`：`true` 或 `false`
- `SIZE`：当前元素个数

## 样例

**样例 1**

```
输入：
7
PUSH 3
PUSH 5
FRONT
POP
EMPTY
POP
EMPTY
输出：
3
3
false
5
true
```

**样例 2**

```
输入：
4
POP
FRONT
EMPTY
SIZE
输出：
none
none
true
0
```
