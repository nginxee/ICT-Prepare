# D10-D · ★ 分组聚合（按特征分组）

**关卡** D10 · 哈希表与集合 ｜ **提交** `answers/D10-D.cj`

把 n 个单词按"互为异位词"分组后输出。两个单词的字母重排后能相同，就算同一组。

## 输入

第一行一个整数 n。
第二行 n 个单词，由小写字母组成，单个空格分隔。

**数据范围**：1 ≤ n ≤ 10⁵；每个单词长度 1～8，只含 `a`~`z`；同一个单词可以重复出现。

## 输出

- 第一行：组数 g。
- 接下来 g 行，每行：`键 该组词数 词1 词2 …`（各部分之间**单个空格**）。

排序规则（三条都要严格照做）：

1. **键**的定义：把该组任意一个单词的字符按升序排好得到的串（例如 `tea` → `aet`）。
2. **组间**：按键的字典序**升序**排列。
3. **组内**：按单词本身的字典序**升序**排列；**重复出现的单词要重复列出**，不去重。

## 样例

**样例 1**

```
输入：
5
eat tea ate tan nat
输出：
2
aet 3 ate eat tea
ant 2 nat tan
```

**样例 2**

```
输入：
1
a
输出：
1
a 1 a
```
