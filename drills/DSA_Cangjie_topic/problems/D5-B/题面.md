# D5-B · 反转单链表

**关卡** D5 · 链表 ｜ **提交** `answers/D5-B.cj`

把读入的单链表整个反转（改链接，不是改值），输出反转后的值序列与反转后的 next 数组。

## 输入

第一行一个整数 n，节点下标为 0 … n-1。
接下来 n 行，每行两个整数 `val nxt`：该节点的值，以及下一个节点的下标（`-1` 表示没有下一个）。
最后一行一个整数 head：首节点下标。

保证：从 head 出发沿 next 恰好走完全部 n 个节点，不成环、不提前结束。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ val ≤ 10⁹；nxt ∈ {-1} ∪ [0, n-1]；head ∈ {0..n-1}。

## 输出

三行：

- `len=` 反转后链上的节点个数
- `seq=` 从新的 head 开始沿 next 输出的各节点值，单个空格分隔
- `next=` 反转后的 next 数组：按节点下标 0、1、…、n-1 的顺序，把每个节点的 next 值用单个空格分隔打印（`-1` 原样输出）

## 样例

**样例 1**

```
输入：
4
10 1
20 2
30 3
40 -1
0
输出：
len=4
seq=40 30 20 10
next=-1 0 1 2
```

**样例 2**

```
输入：
1
7 -1
0
输出：
len=1
seq=7
next=-1
```
