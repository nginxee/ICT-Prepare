# D13-A · 手写最小堆：建堆与取最小

**关卡** D13 · 堆与优先队列 ｜ **提交** `answers/D13-A.cj`

先读入 n 个整数建一个最小堆，再按给定的 m 个操作维护它：每次取最小值时，输出取到的值与取完之后堆内的元素个数。

## 输入

第一行一个整数 n。
第二行 n 个整数 a₁ … aₙ，单个空格分隔。
第三行一个整数 m。
接下来 m 行，每行一个操作：`1 x` 表示把整数 x 插入堆中（`1` 与 `x` 之间一个空格）；`2` 表示取出堆中的最小值。

**数据范围**：1 ≤ n ≤ 2×10⁵；1 ≤ m ≤ 2×10⁵；-10⁹ ≤ 初始元素与插入的 x ≤ 10⁹；任意时刻堆内元素个数 ≤ 2×10⁵。

## 输出

对每个 `2` 操作按出现顺序输出一行：

- 堆非空：`<取出的最小值> <取出之后堆内的元素个数>`，两个整数、单个空格分隔（元素个数指**取完之后**剩下的个数）；
- 堆为空：输出 `empty`。

`1` 操作不产生任何输出。

## 样例

**样例 1**

```
输入：
3
5 1 3
4
2
2
1 -2
2
输出：
1 2
3 1
-2 1
```

**样例 2**

```
输入：
1
7
2
2
2
输出：
7 0
empty
```
