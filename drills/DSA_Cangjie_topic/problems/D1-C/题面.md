# D1-C · 首次/末次与出现次数

**关卡** D1 · 规模、复杂度与 Int64 ｜ **提交** `answers/D1-C.cj`

给 n 个整数与目标值 x，输出 x 的首次下标、末次下标、出现次数与最大空档。

## 输入

第一行两个整数 n 和 x，单个空格分隔。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹；-10⁹ ≤ x ≤ 10⁹。

## 输出

四行，每行 `名字=值`：`first=`、`last=`（下标从 1 起，没出现输出 `-1`）、`count=`（没出现输出 `0`）、`maxgap=`。

若 x 的出现下标依次为 p₁ < p₂ < … < p_k，则 `maxgap = max(pᵢ₊₁ − pᵢ − 1)`；k ≤ 1 时 `maxgap = 0`。

## 样例

**样例 1**

```
输入：
8 3
5 3 -1 3 3 7 3 0
输出：
first=2
last=7
count=4
maxgap=1
```

**样例 2**

```
输入：
3 9
1 2 3
输出：
first=-1
last=-1
count=0
maxgap=0
```
