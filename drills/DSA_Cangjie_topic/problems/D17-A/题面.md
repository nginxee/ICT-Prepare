# D17-A · 区间调度（最多不重叠）

**关卡** D17 · 贪心 ｜ **提交** `answers/D17-A.cj`

给 n 个半开区间 [l, r)，求最多能选出多少个两两不重叠的区间。

## 输入

第一行一个整数 n。
接下来 n 行，每行两个整数 `l r`，表示半开区间 [l, r)。

**数据范围**：1 ≤ n ≤ 2×10⁵；0 ≤ l < r ≤ 10⁹。区间之间可能重复、可能互相包含。

## 输出

一行 `count=<最多能选出的区间个数>`。

不重叠指：任取两个被选区间，前一个的右端点 ≤ 后一个的左端点（端点相接不算重叠）。最大个数唯一，不存在并列取舍。

## 样例

**样例 1**

```
输入：
4
1 3
2 5
3 6
5 7
输出：
count=2
```

**样例 2**

```
输入：
3
2 5
2 5
2 5
输出：
count=1
```
