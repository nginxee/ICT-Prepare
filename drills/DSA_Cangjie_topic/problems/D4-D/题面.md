# D4-D · ★ 滑动窗口最大值

**关卡** D4 · 队列与双端队列 ｜ **提交** `answers/D4-D.cj`

长度 k 的窗口在数组上从左滑到右，输出每个窗口内的最大值。

## 输入

第一行两个整数 n、k，单个空格分隔。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；1 ≤ k ≤ n；-10⁹ ≤ aᵢ ≤ 10⁹。

## 输出

一行，按窗口从左到右的顺序输出 n - k + 1 个整数，单个空格分隔，行末不要多余空格。

窗口 i（0 ≤ i ≤ n-k）覆盖下标 `i … i+k-1`，输出该区间内的最大元素（有重复值时结果唯一）。

## 样例

**样例 1**

```
输入：
8 3
1 3 -1 -3 5 3 6 7
输出：
3 3 5 5 6 7
```

**样例 2**

```
输入：
1 1
5
输出：
5
```
