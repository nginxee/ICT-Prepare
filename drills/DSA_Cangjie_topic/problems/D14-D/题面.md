# D14-D · ★ 网格 BFS（迷宫最短步数）

**关卡** D14 · 图的遍历 ｜ **提交** `answers/D14-D.cj`

给一张网格迷宫和一个起点 `S`，回答 q 个查询：从 `S` 走到指定格子最少要几步（上下左右，每步一格，不能穿墙）。

## 输入

第一行两个整数 n 和 m（行数、列数）。
接下来 n 行，每行一个长度为 m 的字符串，只含 `#`、`.`、`S`（`S` 恰好出现一次）。
接下来一行一个整数 q，再接下来 q 行，每行两个整数 x y（1 ≤ x ≤ n，1 ≤ y ≤ m，表示第 x 行第 y 列）。

**数据范围**：1 ≤ n, m ≤ 800 且 n·m ≤ 6.4×10⁵；1 ≤ q ≤ 10⁵；格子只含 `#`、`.`、`S`。

## 输出

q 行，每行一个整数：从 `S` 走到该格子的最少步数；`S` 自己输出 `0`，该格是墙或从 `S` 走不到则输出 `-1`。

## 样例

**样例 1**

```
输入：
3 4
S.#.
.#..
...#
2
1 4
3 4
输出：
7
-1
```

**样例 2**

```
输入：
1 1
S
1
1 1
输出：
0
```
