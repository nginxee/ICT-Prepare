# D7-D · 最小化最大工作量

**关卡** D7 · 二分查找 ｜ **提交** `answers/D7-D.cj`

把 n 个任务按给定顺序切成若干连续段分给工人（每人一段、至少一个任务、最多 k 个工人），输出最大工作量的最小可能值，以及取到该值时最少需要的工人数。

## 输入

第一行两个整数 n、k。
第二行 n 个正整数，单个空格分隔，表示每个任务的工作量。

**数据范围**：1 ≤ n ≤ 2×10⁵；1 ≤ k ≤ 2×10⁵（k 可以大于 n）；1 ≤ aᵢ ≤ 10⁹。

## 输出

两行：

```
第一行：最小可能的最大工作量（一个整数）
第二行：达到这个最优值所需的最少工人数（即最少切成几段）
```

两个答案都唯一，不需要输出具体切法。

## 样例

**样例 1**

```
输入：
5 2
7 2 5 10 8
输出：
18
2
```

**样例 2**

```
输入：
3 10
3 1 4
输出：
4
2
```
