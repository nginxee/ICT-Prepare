# D7-C · 旋转有序数组找最小值

**关卡** D7 · 二分查找 ｜ **提交** `answers/D7-C.cj`

一个非降序数组被旋转了若干位（元素可重复），输出它的最小值。

## 输入

第一行一个整数 n。
第二行 n 个整数，由一个非降序数组旋转若干位得到，单个空格分隔。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹；元素允许重复。

## 输出

一个整数：数组中的最小值。

## 样例

**样例 1**

```
输入：
5
3 4 5 1 2
输出：
1
```

**样例 2**

```
输入：
4
7 7 7 7
输出：
7
```
