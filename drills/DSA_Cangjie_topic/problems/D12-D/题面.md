# D12-D · ★ 二叉搜索树（判定与查找）

**关卡** D12 · 二叉树 ｜ **提交** `answers/D12-D.cj`

按数组表示读入一棵二叉树，先判定它是不是二叉搜索树；若是，再回答 q 个查询。

## 输入

```
第一行：n
第二行：n 个整数 a₁…aₙ（单个空格分隔）
第三行：q
接下来 q 行：每行一个整数 x
```

数组表示约定（全关统一）：

- **下标从 1 起**：`a₁` 是根，`aᵢ` 的左孩子是 `a₂ᵢ`，右孩子是 `a₂ᵢ₊₁`；
- `aᵢ = 0` 表示**该位置是空节点**，且它的子孙位置也一定是 `0`；
- 下标大于 n 的位置一律视为空。

BST 的定义：空树算 BST；对任意节点，其左子树所有值都**小于**它、右子树所有值都**大于**它（严格，不允许重复）。

**数据范围**：1 ≤ n ≤ 2×10⁵；0 ≤ aᵢ ≤ 10⁹（非空节点的值 ≥ 1）；1 ≤ q ≤ 2000；0 ≤ x ≤ 10⁹。

## 输出

1. 第一行：`isBST=YES` 或 `isBST=NO`。
2. **只有** `isBST=YES` 时才继续输出 q 行，每个查询一行：
   - 命中（存在值为 x 的节点）：`F` + 空格 + **从根到该节点的值序列**（空格分隔，含根与自身）。
   - 未命中：`N` + 空格 + **前驱值** + 空格 + **后继值**；前驱/后继不存在时对应位置输出 `-`。
     前驱 = 中序序列中比 x 小的最大值，后继 = 中序序列中比 x 大的最小值。
3. `isBST=NO` 时**只输出第一行**，不要输出任何查询结果。

## 样例

**样例 1**

```
输入：
7
8 3 10 1 6 0 14
3
6
7
15
输出：
isBST=YES
F 8 3 6
N 6 8
N 14 -
```

**样例 2**

```
输入：
1
0
2
5
100
输出：
isBST=YES
N - -
N - -
```
