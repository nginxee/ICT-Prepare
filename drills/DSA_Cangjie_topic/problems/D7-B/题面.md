# D7-B · 切分最大化（二分答案）

**关卡** D7 · 二分查找 ｜ **提交** `answers/D7-B.cj`

把一条正整数序列切成恰好 k 段连续的非空段，输出所有切法中「最小段和」的最大值。

## 输入

第一行两个整数 n、k。
第二行 n 个正整数，单个空格分隔。

**数据范围**：1 ≤ k ≤ n ≤ 2×10⁵；1 ≤ aᵢ ≤ 10⁹。

## 输出

一个整数：切成恰好 k 段连续非空段时，所有方案中最小段和的最大值。

## 样例

**样例 1**

```
输入：
5 2
7 2 5 10 8
输出：
14
```

**样例 2**

```
输入：
3 3
1 2 3
输出：
1
```
