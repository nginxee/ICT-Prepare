# D15-D · ★ DAG 最长路（关键路径）

**关卡** D15 · 最短路与拓扑排序 ｜ **提交** `answers/D15-D.cj`

给一张带权的有向无环图，求 1 号点到 n 号点的最长路径长度，以及这样的最长路径条数。

## 输入

第一行两个整数 n 和 m（点数、边数），单个空格分隔。
接下来 m 行，每行三个整数 u v w，表示一条有向边 u → v，权为 w。

**数据范围**：2 ≤ n ≤ 10⁵；0 ≤ m ≤ 2×10⁵；1 ≤ u < v ≤ n（输入保证是 DAG）；1 ≤ w ≤ 10⁹。

## 输出

两行：第 1 行从 1 号点到 n 号点的最长路径长度，不可达输出 `-1`；第 2 行这样的最长路径条数对 `1000000007` 取模的结果，不可达输出 `0`。

条数按路径计：只要边序列不同就算两条。

## 样例

**样例 1**

```
输入：
5 5
1 2 3
1 3 1
2 4 2
3 4 5
4 5 1
输出：
7
1
```

**样例 2**

```
输入：
3 1
1 2 5
输出：
-1
0
```
