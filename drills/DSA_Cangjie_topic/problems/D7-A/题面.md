# D7-A · 首次/末次位置与个数

**关卡** D7 · 二分查找 ｜ **提交** `answers/D7-A.cj`

给一个非降序数组和 q 次查询，对每次查询 x 输出它第一次出现的下标、最后一次出现的下标、出现次数。

## 输入

第一行一个整数 n。
第二行 n 个整数，非降序排列，单个空格分隔。
第三行一个整数 q。
接下来 q 行，每行一个整数 x。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ aᵢ ≤ 10⁹；1 ≤ q ≤ 10⁵；-10⁹ ≤ x ≤ 10⁹。

## 输出

q 行，每行三个整数，用单个空格分隔：`first last count`。

`first` 是 x 第一次出现的下标，`last` 是最后一次出现的下标（都从 1 开始），`count` 是出现次数。
x 不存在时输出 `-1 -1 0`。

## 样例

**样例 1**

```
输入：
7
-5 1 1 2 4 4 4
4
1
4
0
-5
输出：
2 3 2
5 7 3
-1 -1 0
1 1 1
```

**样例 2**

```
输入：
1
7
3
7
6
8
输出：
1 1 1
-1 -1 0
-1 -1 0
```
