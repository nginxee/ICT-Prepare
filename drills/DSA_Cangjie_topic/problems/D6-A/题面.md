# D6-A · 升序/降序/自定义比较器

**关卡** D6 · 排序 ｜ **提交** `answers/D6-A.cj`

同一组整数，按四种口径输出四行：值升序、值降序、按绝对值升序、以及按值升序时各元素的原始下标。

## 输入

第一行一个整数 n。
第二行 n 个整数，单个空格分隔。

**数据范围**：1 ≤ n ≤ 10⁵；-10⁹ ≤ 每个整数 ≤ 10⁹。

## 输出

四行，每行 `名字=` 后接 n 个整数，单个空格分隔，行末不要多余空格：

- `asc=` 按值升序
- `desc=` 按值降序
- `abs=` 按 `|x|` 升序；`|x|` 相同时按 `x` 升序
- `idx=` 按值升序时各元素的**原始下标（0 基）**；值相同的元素按原始下标升序（即稳定排序的口径）

## 样例

**样例 1**

```
输入：
5
3 -1 4 -1 0
输出：
asc=-1 -1 0 3 4
desc=4 3 0 -1 -1
abs=0 -1 -1 3 4
idx=1 3 4 0 2
```

**样例 2**

```
输入：
1
-1000000000
输出：
asc=-1000000000
desc=-1000000000
abs=-1000000000
idx=0
```
