# D14-B · BFS 求无权最短路

**关卡** D14 · 图的遍历 ｜ **提交** `answers/D14-B.cj`

求起点 s 到所有点的最短边数，并给出 s 到 t 的一条最短路。

## 输入

第一行四个整数 n m s t（点数、边数、起点、终点），单个空格分隔。
接下来 m 行，每行两个整数 u v，表示 u 与 v 之间有一条无向边。

**数据范围**：1 ≤ n ≤ 10⁵；0 ≤ m ≤ 2×10⁵；1 ≤ s, t, u, v ≤ n；u ≠ v；允许重边。

## 输出

两行：第 1 行 n 个整数，s 到 1..n 每个点的最短边数，不可达输出 `-1`，s 自己为 `0`；第 2 行一条从 s 到 t 的最短路，按路径顺序用单个空格分隔顶点编号，t 不可达输出 `-1`，s == t 时输出 `s`。

多条等长最短路时按下面的约定取唯一：BFS 中每个点的邻居按编号升序处理，记下每个点**第一次被访问时**的前驱，路径由 t 顺着这些前驱回溯到 s。

## 样例

**样例 1**

```
输入：
4 3 1 4
1 2
2 3
3 4
输出：
0 1 2 3
1 2 3 4
```

**样例 2**

```
输入：
3 1 3 1
1 2
输出：
-1 -1 0
-1
```
