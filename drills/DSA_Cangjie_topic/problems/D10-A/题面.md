# D10-A · 词频统计并按 key 排序输出

**关卡** D10 · 哈希表与集合 ｜ **提交** `answers/D10-A.cj`

给 n 个单词，统计每个单词出现的次数，按单词升序逐行输出。

## 输入

第一行一个整数 n。
第二行 n 个单词，由小写字母组成，单个空格分隔。

**数据范围**：1 ≤ n ≤ 10⁵；每个单词长度 1～8，只含 `a`~`z`。

## 输出

每个**不同**单词输出一行：`单词 出现次数`（单词在前，单个空格，次数在后）。

行的顺序：单词按字典序**升序**（`a` < `aa` < `ab` < `b`，即前缀短的在前）。

## 样例

**样例 1**

```
输入：
5
banana apple banana cherry apple
输出：
apple 2
banana 2
cherry 1
```

**样例 2**

```
输入：
1
z
输出：
z 1
```
