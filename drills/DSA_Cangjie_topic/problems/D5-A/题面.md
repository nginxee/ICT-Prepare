# D5-A · 链表表示与遍历

**关卡** D5 · 链表 ｜ **提交** `answers/D5-A.cj`

按"值与下一个节点下标"读入一条单链表，从 head 出发沿 next 走一遍，输出链上节点个数与各节点的值。

## 输入

第一行一个整数 n，节点下标为 0 … n-1。
接下来 n 行，每行两个整数 `val nxt`：该节点的值，以及下一个节点的下标（`-1` 表示没有下一个）。
最后一行一个整数 head：首节点下标（`-1` 表示空链表）。

保证：从 head 出发沿 next 走不会成环（可能提前结束，此时有节点不在链上）。

**数据范围**：1 ≤ n ≤ 2×10⁵；-10⁹ ≤ val ≤ 10⁹；nxt ∈ {-1} ∪ [0, n-1]；head ∈ {-1} ∪ [0, n-1]。

## 输出

两行：

- `len=` 链上节点个数 L
- `seq=` 从 head 开始沿 next 输出的各节点值，单个空格分隔；L = 0 时输出 `seq=none`

## 样例

**样例 1**

```
输入：
4
10 2
20 -1
30 1
40 0
3
输出：
len=4
seq=40 10 30 20
```

**样例 2**

```
输入：
3
5 1
6 2
7 -1
-1
输出：
len=0
seq=none
```
