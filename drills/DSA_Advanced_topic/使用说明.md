# 数据结构与算法题 · 使用说明

## 日常流程（双击就行）

1. **双击 `自助判题.cmd`**
2. 提示出现后，**输入关卡号，回车**（例如 `7`）
3. 它会自动做两件事：
   - **先同步草稿**：把 `answers\default\src\*.cj` 复制到 `answers\`
   - **再判题**
4. 判完会再次提示，可以继续输入；**直接回车 = 退出**

```
请输入关卡号（如 7），或题号（如 L7-E），a = 全部；直接回车退出 > 7
```

### 可以输入什么

| 输入 | 作用 |
|---|---|
| `7` | 判关卡七全部题目 |
| `L7-E` | 只判单题 |
| `a` | 判**全部**题目（慢，约 1 分钟，适合总检查） |
| 直接回车 | 退出 |

## 目录

```
drills\DSA_Advanced_topic\
├─ 自助判题.cmd          ← 双击这个
├─ judge.ps1            ← 判题脚本本体（纯 ASCII 源码，见下）
├─ messages.json        ← 所有中文提示（UTF-8，由脚本显式解码）
├─ problems\            ← 题库（不要改）
│  ├─ L1-A ... L7-E     题面.md + in\ + out\
│  └─ _hidden\          模拟一的隐藏评测数据（考试期间不要打开）
└─ answers\
   ├─ default\src\      ← ★ 你写代码的地方
   └─ L*.cj             ← 判题时自动同步过来的
```

**你只需要在 `answers\default\src\` 里写 `.cj`，文件名 = 题号**（如 `L7-A.cj`）。
判题前会自动同步，不用手动拷贝。

## 命令行方式（可选）

```
自助判题.cmd -Level 7
自助判题.cmd -Problem L7-A
自助判题.cmd -Problem L7-A -ShowInput
```

带参数时**不会** `pause`（方便脚本调用）；双击（无参数）才暂停等你看结果。

**交叉测试**：判题不检查题号与文件名是否匹配，可以把任一解法喂给任一题的数据：

```
自助判题.cmd -Problem L2-S -Source answers\default\src\L3-D.cj
```

## 判题说明

- 单用例**上限 5 秒**，超时判 `超时`
- 只比较 stdout，忽略每行行尾空格和末尾空行
- 编译**警告**会显示但**不影响判分**
- 只告诉你「输入 / 期望输出 / 你的输出」+ 差异表，**不给参考实现**

## 编码上的两个坑（都已处理，别去"修"）

| 坑 | 处理方式 |
|---|---|
| `cmd.exe` 按 **OEM 代码页(936)** 读 `.cmd`，UTF-8 中文会被当命令执行 | `自助判题.cmd` 保持**纯 ASCII**，中文全在 `messages.json` |
| PowerShell 5.1 按 **ANSI 代码页** 读无 BOM 的 `.ps1`，UTF-8 中文会变成语法错误 | `judge.ps1` 同样保持**纯 ASCII** |
| `cjc` 的诊断信息用 **ANSI 代码页** 输出 | 脚本显式按 ANSI 解码，所以中文路径不乱码 |
| `chcp 65001` 会让 `[Console]::ReadLine()` 立即返回 EOF | **不要**在 `自助判题.cmd` 里加 `chcp`，交互提示会直接失效 |

> 一句话：**`judge.ps1` / `自助判题.cmd` 里不要出现任何非 ASCII 字符。**
> 要改提示文案，改 `messages.json`（UTF-8）。
