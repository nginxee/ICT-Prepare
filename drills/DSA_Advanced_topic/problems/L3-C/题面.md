# L3-C · 两行式：和与最大值

**关卡**：三 · 一行 N 个数（读法①）
**提交文件**：`answers/L3-C.cj`

## 输入

**第一行**一个整数 n（1 ≤ n ≤ 1000）。
**第二行** n 个整数，单个空格分隔，每个绝对值 ≤ 10⁹。

## 输出

两行：
第一行输出这 n 个数的**和**；
第二行输出这 n 个数的**最大值**。

> 注意：n 个数**可能全是负数**。

## 样例

**样例 1**

```
输入：
5
3 -1 4 1 5
输出：
12
5
```

**样例 2**

```
输入：
1
7
输出：
7
7
```

**样例 3**

```
输入：
4
-5 -2 -9 -3
输出：
-19
-2
```

**样例 4**

```
输入：
3
0 0 0
输出：
0
0
```

**样例 5**

```
输入：
6
-1000000000 1000000000 0 1 -1 5
输出：
5
1000000000
```
