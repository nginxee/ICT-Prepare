# L2-S · ★挑战：夹空行的多组数据

**关卡**：二 · 读到 EOF（命门） ★挑战
**提交文件**：`answers/L2-S.cj`

## 输入

**若干行**，每行一个整数，读到输入结束为止。
⚠️ **输入中可能夹有若干空行（不含任何字符的行）**。
空行必须被**忽略**，不计入数据、也不影响结果。

## 输出

一行，所有**非空行**整数之和。

> 本题专门考察：空行与“输入结束”是不是同一件事。

## 样例

**样例 1**

```
输入：
4

6
-1

9
输出：
18
```

**样例 2**

```
输入：
1


2
输出：
3
```

**样例 3**

```
输入：

5
输出：
5
```

**样例 4**

```
输入：
7
输出：
7
```

**样例 5**

```
输入：
5

输出：
5
```
