# L6-A · 成绩统计（基础）

**关卡**：模拟一 · 60 分钟 2 题
**提交文件**：`answers/L6-A.cj`
**时限**：本场共 60 分钟，2 题（`L6-A` + `L6-B`）

## 输入

第一行一个整数 n（1 ≤ n ≤ 10⁴）。
接下来 n 行，每行 ``姓名 分数``，单个空格分隔。
姓名只含小写字母、长度 ≤ 20、**互不重复**；分数 0..100。

## 输出

三行：
1. **最高分**学生的 ``姓名 分数``（**并列最高分时，输出字典序最小的姓名**）
2. 全体**平均分**，保留 **2 位小数**，该行不许有前导空格
3. **及格人数**（分数 ≥ 60）

> 平均分要打印小数；最高分有并列规则，别只比分数。

## 样例

**样例 1**

```
输入：
5
tom 88
amy 95
bob 88
cat 70
dan 95
输出：
amy 95
87.20
5
```

**样例 2**

```
输入：
1
q 60
输出：
q 60
60.00
1
```
