# L5-D · ★词频 Top-1（并列取字典序最小）

**关卡**：五 · W2 集合与排序（用库，别手写） ★挑战
**提交文件**：`answers/L5-D.cj`

## 输入

第一行一个整数 n（1 ≤ n ≤ 1000）。
第二行 n 个单词，单个空格分隔，只含小写字母、长度 ≤ 20。

## 输出

一行：出现次数**最多**的那个单词。
**并列时输出字典序最小的那个。**

> 先计数，再在计数结果上挑 —— 别把「最大」和「最小」两个方向搞混。

## 样例

**样例 1**

```
输入：
5
b a b a c
输出：
a
```

**样例 2**

```
输入：
1
z
输出：
z
```

**样例 3**

```
输入：
4
x y y x
输出：
x
```

**样例 4**

```
输入：
3
c c c
输出：
c
```

**样例 5**

```
输入：
6
m m n n o o
输出：
m
```
