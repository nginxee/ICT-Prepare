# L6-B · 词频榜 Top-3（综合）

**关卡**：模拟一 · 60 分钟 2 题
**提交文件**：`answers/L6-B.cj`
**时限**：本场共 60 分钟，2 题（`L6-A` + `L6-B`）

## 输入

**若干行**，每行若干个小写单词，单个空格分隔，读到输入结束为止。
⚠️ 两个规格：
- 输入中**可能夹有空行**（空行不含单词，必须忽略）；
- 行数、每行单词个数**都不固定**。

单词只含小写字母、长度 ≤ 20；单词总个数 1..10⁴。

## 输出

**至多 3 行**（不同单词不足 3 个时，就输出实际个数）。
每行 ``单词 次数``。
排序规则：**次数降序**；次数相同时按**单词升序**。

> Top-K 的边界：如果只有 2 个不同单词，只能输出 2 行。

## 样例

**样例 1**

```
输入：
the cat sat
on the mat

the cat ran
输出：
the 3
cat 2
mat 1
```

**样例 2**

```
输入：
hello
输出：
hello 1
```
