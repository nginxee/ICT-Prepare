# L7-D · 首次出现位置（二分查找）

**关卡**：七 · 新概念：从编排到算法
**提交文件**：`answers/L7-D.cj`

## 考察概念：**二分查找 / 下界**

本机知识库**不含算法专题**（计划 §0-B）—— 这一关开始，题目要你自己**想出做法**，
而不是"读进来排个序"。判题**单用例上限 5 秒**。

**朴素做法**（每个查询从头扫描）是 O(n·m) ≈ 2×10¹⁰ —— **必然超时**。
注意：因为要找**第一次**出现的位置，扫描**不能提前退出**。
**思考方向**：数组有序 → 每次可以把查找范围**砍掉一半**。
关键是：找到 x 之后，怎么确认左边**没有**更早的 x？

## 输入

第一行两个整数 ``n m``（1 ≤ n, m ≤ 2×10⁵）。
第二行 n 个整数，**已按升序排列**，**可能有重复**。
接下来 m 行，每行一个整数 x。

## 输出

m 行：x 在数组中**第一次出现**的位置（从 1 开始计数）；若不存在输出 ``-1``。

## 样例

**样例 1**

```
输入：
5 3
1 3 3 5 7
3
1
4
输出：
2
1
-1
```

**样例 2**

```
输入：
4 4
2 2 2 2
2
1
3
-5
输出：
1
-1
-1
-1
```
