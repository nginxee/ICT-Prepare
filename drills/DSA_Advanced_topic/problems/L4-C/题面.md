# L4-C · 综合：变长行 + 空行 + EOF ★

**关卡**：四 · 组结构与合流 ★挑战
**提交文件**：`answers/L4-C.cj`

## 输入

若干行，每行若干个整数，读到输入结束为止。
⚠️ 两个规格叠加：
- **空行必须被忽略**（空行不算一行数据）；
- 每行**整数个数不定**。

行数 1..1000，每行个数 1..100。

## 输出

两行：
第一行输出**有效数据行数**（不含被忽略的空行）；
第二行输出**所有整数的总和**。
    
> 把你 L2-S 学到的「空行 ≠ 结束」和关卡三的「变长行」合起来用。

## 样例

**样例 1**

```
输入：
1 2

3
输出：
2
6
```

**样例 2**

```
输入：


5
输出：
1
5
```

**样例 3**

```
输入：
7
输出：
1
7
```

**样例 4**

```
输入：
1 1
2 2

3 3
输出：
3
12
```
