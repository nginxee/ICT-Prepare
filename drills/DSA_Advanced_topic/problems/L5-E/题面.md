# L5-E · 缺字段容错：分数可能不存在

**关卡**：五 · W2 集合与排序（用库，别手写）
**提交文件**：`answers/L5-E.cj`

## 输入

第一行一个整数 n（1 ≤ n ≤ 1000）。
接下来 n 行，每行**可能**是 ``名字 分数``，也**可能**只有 ``名字``（分数缺失）。
名字只含小写字母、长度 ≤ 20；分数 0..100。

## 输出

输出 n 行，每行 ``名字 分数``。
**分数缺失的输出 0。**

> 行的「形状」不固定 —— 你不能假设第二段一定存在。

## 样例

**样例 1**

```
输入：
3
tom 88
amy
bob 70
输出：
tom 88
amy 0
bob 70
```

**样例 2**

```
输入：
1
solo
输出：
solo 0
```

**样例 3**

```
输入：
2
a 100
b 0
输出：
a 100
b 0
```
