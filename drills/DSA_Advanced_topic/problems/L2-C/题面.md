# L2-C · 计数与求和（读到 EOF）

**关卡**：二 · 读到 EOF（命门）
**提交文件**：`answers/L2-C.cj`

## 输入

**若干行**，每行一个整数，读到输入结束为止。
行数 1..1000，每个整数绝对值 ≤ 10⁹。

## 输出

两行：
第一行输出整数的**个数**；
第二行输出它们的**总和**。

## 样例

**样例 1**

```
输入：
7
-2
0
15
3
输出：
5
23
```

**样例 2**

```
输入：
1
输出：
1
1
```

**样例 3**

```
输入：
-5
输出：
1
-5
```

**样例 4**

```
输入：
2
4
6
8
10
12
输出：
6
42
```
