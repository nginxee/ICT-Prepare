# L5-A · 数组统计：和 · 最大 · 平均

**关卡**：五 · W2 集合与排序（用库，别手写）
**提交文件**：`answers/L5-A.cj`

## 输入

第一行一个整数 n（1 ≤ n ≤ 10⁵）。
第二行 n 个整数，单个空格分隔，每个绝对值 ≤ 10⁴。

## 输出

三行：
1. 这 n 个数的**和**
2. 这 n 个数的**最大值**
3. 这 n 个数的**平均值**，保留 **2 位小数**，且该行**不许有前导空格**

> 平均分要打印小数 —— 整数除法在仓颉里会截断。

## 样例

**样例 1**

```
输入：
5
1 2 3 4 5
输出：
15
5
3.00
```

**样例 2**

```
输入：
1
7
输出：
7
7
7.00
```

**样例 3**

```
输入：
4
-1 -2 -3 -4
输出：
-10
-1
-2.50
```

**样例 4**

```
输入：
3
0 0 0
输出：
0
0
0.00
```

**样例 5**

```
输入：
6
1 2 3 4 5 6
输出：
21
6
3.50
```
