# L3-D · 多组一行数据（①+③ 合流）★

**关卡**：三 · 一行 N 个数（读法①） ★挑战
**提交文件**：`answers/L3-D.cj`

## 输入

**若干行**，每行**若干个整数**（每行个数不定，≥ 1），读到输入结束为止。
行数 1..1000，每行个数 1..100，每个整数绝对值 ≤ 10⁹。

## 输出

**每行输出一个数**：该行所有整数之和。共输出与输入行数相同的行数。

> 这是「行数不定」× 「每行个数不定」的组合 —— 真实考试最常见的形状。

## 样例

**样例 1**

```
输入：
1 2 3
10
-1 1
7
输出：
6
10
0
7
```

**样例 2**

```
输入：
5
输出：
5
```

**样例 3**

```
输入：
1 2
3 4
5 6
输出：
3
7
11
```

**样例 4**

```
输入：
-1 -1 -1
0 0 0 0
输出：
-3
0
```
